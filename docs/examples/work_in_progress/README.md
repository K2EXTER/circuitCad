# 仕上げ待ちの基板

`arduino_mega_usb_open.pcbjson` は、Arduino Mega 2560 互換ボード (`../arduino_mega_usb.schjson`) を、自動配置と、グリッド 0.1mm の自動配線で、通るところまで配線した基板です。**18 本の接続 (18 ネット) が、未配線 (黄色の線) で残っています。** DRC の違反は 0 件です。基板エディタで、手で引いて仕上げる練習の素材です。

## 開く

```
cargo run -p app -- docs/examples/work_in_progress/arduino_mega_usb_open.pcbjson
```

回路図も開くなら、先に `docs/examples/arduino_mega_usb.schjson` を開き、「基板パターン」の画面で、「ファイル」から基板を開きます。

## 残っているネット

DTR・MOSI・PA0・PA1・PA7・PB0・PB4・PC1・PE7・PF0・PG0・PG1・PG2・PG3・PG5・PH4・PH7・PL0

## 仕上げ方のヒント

- 左パネルの「未配線」の表示と、基板上の黄色の線を手がかりにします。
- 「配線」ツールで、パッドからパッドへクリックして引きます。通れないときは、「ビア」ツールで裏面へ渡します。
- 通り道がない線は、邪魔をしている別の線を、一度消して、先に通してから、消した線を引き直します (自動配線の「選んだネットだけ」も使えます)。
- 部品 (ヘッダ) を少し動かすだけで、通ることもあります。
- 引き終わったら、「DRC を実行」で違反が 0 件のままか確かめます。

## なぜ自動で通らないのか

0.5mm ピッチの 100 ピン IC (ATmega2560) から、82 本の短い配線を、2 層で出す問題だからです。線を細くする・格子を細かくする・部品を広げる・配線の順番を変える、のどれでも、最良で 18〜21 本が残りました (`docs/quality-bench.md`)。
