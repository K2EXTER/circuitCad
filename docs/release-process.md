# 配布の手順

依存クレートを変えたら `python tools/gen_third_party_licenses.py` で `THIRD_PARTY_LICENSES.txt` を作り直す(CIが `--check` で古さを検査、リリースのzipに同梱)。`.github/workflows/release.yml` がタグ `v*` でWindows用のzip(`circuitCad.exe` と `ccad.exe` と docs)を作り、プレリリースとして公開する(本文は `docs/release-notes/<タグ>.md` を読むので、タグを打つ前に必ず置く)(macOS/Linuxは動作確認ができるまでmatrixでコメントアウト中)。日本語フォントは `startup.rs` の `install_japanese_font` がOSごとの候補パスから読み、無ければ `assets/fonts/BIZUDGothic-Regular.ttf`(OFL)を使う。

READMEの画像(`docs/images/*.png`)は `powershell -File tools/gen_screenshots.ps1` で作り直す(`cargo build -p app` のあと。1枚だけなら `-Only waveform`。画像を増やすときはスクリプトの `$shots` に1行)。READMEの操作録画 `docs/images/demo-live.gif` は `powershell -File tools/gen_demo_live.ps1` で、README.en.md の英語の画面の録画 `docs/images/demo-live-en.gif` は `-Lang en` で作り直す(座標の表は言語ごと (語の幅でボタンの位置が違う)。最後に 2 つ目のサンプル `arduino_blocks` を別の窓で開き、ブロックを置いて戻し、電源を入れてボタンを押す。英語では見本のスケッチの文も英語にした写しを `target\demo\` に作って開く。`target` の新しい方の exe を一時フォルダに写して起動・1920×1080 で最大化・実際のマウスを使う。台本は `pot_dimmer` のサンプルで 4 つのタブを回る。座標は画面全体の絶対座標で、パネルの配置を変えるとずれる。仕組みは `tools/screenrec.ps1`。GIF は全体で 1 つのパレット・ディザなしで、変わった所だけが入るので軽い)。紹介ページを SNS で共有したときの絵 `docs/images/og.png`・`en/og.png` は `python tools/gen_icon.py` (ロゴと、4 つのタブの小さな絵。絵は `gen_screenshots.ps1` と通し解説の画像から切り出す)。
