# コンデンサ・コイル・抵抗の特性をデータシートから決める

部品作成フォームの「コンデンサ」「コイル」「抵抗」を選ぶと、「① 基本」の一番上に「かんたん作成」が出ます。
データシートのグラフから読んだ数点で、実物に近いモデルを作れます (ダイオードの手順は [diode-model.md](diode-model.md))。

## 1. 周波数特性 (インピーダンス)

実際の部品は、理想の素子に「余計な部品」がくっついています。高い周波数では、これが効きます。

| 部品 | 余計な部品 | 見え方 |
|---|---|---|
| コンデンサ | 直列に ESR (抵抗) と ESL (コイル) | インピーダンスが下がって、谷で底を打ち、そのあと上がる |
| コイル | 直列に DCR (巻線の抵抗)、並列に容量 | インピーダンスが上がって、山 (自己共振) で頂点を打ち、そのあと下がる |
| 抵抗 | 直列にコイル、並列に容量 | 高い周波数で、上がったり下がったりする |

手順:

1. データシートの「インピーダンス - 周波数」のグラフから、いくつかの点を読み、表に「周波数 インピーダンス」で入れます (谷や山の前後も入れると確かです)。
2. 「表から求める」を押すと、2 つの値 (ESR と ESL / DCR と並列容量 / 寄生インダクタンスと並列容量) が決まります。
3. 絵で、点 (赤) とモデルの曲線 (青) が重なれば成功です。スライダーで自分で動かして、曲線がどう変わるかを見ることもできます。
4. 「部品を作る」を押すと、モデル (`.subckt`) が入ります。

メモ: 自己共振周波数 (SRF) だけが載っているデータシートでは、その欄に入れると、ESL や並列容量を逆算します。

## 2. 温度による変化

温度で値が変わる部品を、「解析 → 温度スイープ」(や回路の温度設定) で確かめられます。

- **抵抗**: データシートの TCR (温度係数、ppm/℃) を入れます。+100ppm/℃ は、温度が 100℃ 上がると 1% 増える、という意味です。金属皮膜抵抗は ±50〜100、厚膜チップ抵抗は ±100〜200 ほどです。
- **コンデンサ**: 温度特性のグラフ (縦軸は容量の変化率 %) から「温度 変化率」を読んで表に入れ、「表から温度係数を求める」を押します。
  - C0G (NP0) は ±30ppm/℃ ほどでほぼ一定、X7R・X5R は数 % 〜 十数 %、Y5V は大きく動きます。
- **コイル**: DCR は銅の温度係数 (1℃ で約 0.4%) が自動で入ります。インダクタンスの温度係数は、あれば入れます。

温度の変化は、**27℃ を基準にした 2 次式** (`1 + TC1×ΔT + TC2×ΔT²`) で近似します。実物の曲線 (とくに X7R の曲がり) とは少し違います。表との差は、求めたときに出ます。
モデルの中には、SPICE の標準の書き方 (`R1 1 2 1k TC1=100u`) で入ります。

## 気をつけること

- 表の値と、「値」の欄の値は、同じ条件のものを使います (DC バイアスの表なら、そのときの容量)。
- 表の周波数が、自己共振より十分低いと、求めた値は目安になります。共振を過ぎた高い周波数の点も足してください。
- 基本部品 (回路図の抵抗・コンデンサ・コイル) は、温度で値が変わりません。温度の影響を見たいときは、ライブラリ部品として作ります。
- 扱わないもの: 電圧による変化 (DC バイアス特性の曲線。1 つの低下率として入れます)、電流による変化 (コイルの磁気飽和)、自己発熱。
