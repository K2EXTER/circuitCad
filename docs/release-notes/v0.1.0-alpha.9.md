## v0.1.0-alpha.9

アルファ版です。動作確認は Windows のみで、基板の発注の実績はまだありません (README の「現在の状態と既知の制限」を参照)。

今回は、**回路図の階層設計 (同じ回路を何回も使う)**、**デジタル回路のシミュレーション (ゲート・フリップフロップ・遅延・セットアップ/ホールド)**、**レッスンの大幅な追加 (86 本)と用語集**、**部品作成フォームのデータシート窓**、**画面の見た目と操作の統一**が大きく変わりました。

### 回路図の階層設計
- **シートの記号**: 1枚のシートを、1つの部品 (記号) として別のシートに置けます。子シートの「ポート」が、記号のピンになります。同じ子シートを何回でも置け、中を直すと全部に効きます。部品番号は `R1_CH1` のようになります。
- 記号をダブルクリックで中のシートへ入り、「親へ戻る」で戻れます。コピーごとに値を変える表もあります。
- タブに **(親)・(子)** の目印 (色つき)、記号には青い塗りが付き、親子が見分けられます。ピンの上のポートは、部品を動かす・回すときに一緒に動きます。
- ERC は、自分を含む記号・ポートのない子シート・同名のポート・つながらないポート・**出力のポートどうしが同じネットにつながっている**ことを点検します。
- 基板へは、コピーがそのまま取り込まれます。基板で入れ替えたピンは、コピー側は回路図へ戻さず、知らせるだけにしています。
- レッスン 86「同じ回路を何度も使う」と、3段の RC のサンプル (`hierarchy_rc_stages`) があります。CLI は `sheet port` / `sheet place` など。
- 回路図の**バス** (`D[0..7]` のラベルと太い線、ERC の点検、ラベルの連番) も入りました。

### デジタル回路のシミュレーション
- ゲートとフリップフロップを、回路の方程式の外で評価する「デジタルセル」にしました。大きな回路 (512 ビットの加算器など) が軽くなります。
- 出力の有効 (3ステート)・オープンドレイン・共有ネット、**伝搬遅延**、**セットアップ/ホールドの点検**に対応しました。
- 部品が増えました: 74HC161 (カウンタ)・138・151・595・244・245・373・574・125・126・4017・14・74、ROM/LUT、ADC/DAC。サンプル `counter_decoder`・`shift_register_leds` など。
- 過渡解析で、必要な信号だけ記録する (`tran record=`)。スライダーで値を動かすと、短い解析を再計算して波形が更新されます。

### 部品作成フォーム
- **データシート (PDF) の窓**: ページを絵にして、語の検索・見出しのボタン・型番や分類の候補。囲んだ表からピンを取り込み、図面の数字をクリックして寸法の欄へ入れ、ピンと寸法をデータシートと突き合わせられます。
- ピンの表、パッケージの整理 (パッド・本体・3D)、定格のタブ、種類の選び方の整理、KiCad のレガシー記号とメーカーの zip (Ultra Librarian / SnapEDA) の取り込み、部品の編集と削除。

### 学習
- レッスンが **86 本**になりました。部品を1つずつ学ぶ「部品」の学習パスが増え (コンデンサ〜フォトカプラ、ヒューズ・バリスタ・ホールセンサ・電池・EEPROM・ダイオードブリッジなど)、電解コンデンサの寿命・MOSFET の損失・リニアとスイッチングの比較・スルーレートも加わりました。
- **用語集・索引**: 電子回路とこのソフトの言葉 (読み・別名・説明つき。基板側の言葉も)。レッスンの窓に「このレッスンの用語」が出ます。
- 最初のレッスンは「はじめに 1」(電圧・電流・抵抗)。初学者の目で全体を読み直して直しました。

### 画面
- 左のパネルを整理しました (帯と枠、つなぎ合わせたボタン、折りたたみ、最小の高さ、全体の色と余白の統一)。DC の結果とネットリストは検索・並べ替え・クリックで飛べる窓になりました。
- 元に戻す・やり直しのボタンを左のパネルに、設計の要件の表の入口を「編集」メニューにも置きました。

### 基板・ほか
- ネットクラスに、ネットあたりのビア数の上限 (`max_vias`) と、細く絞った配線 (`max_neck`)。DRC に、未配線とベタから切れたグランドのビアの指摘。
- 書き込み用のピンがヘッダまで届くかの点検 (ERC)。
- 他の電気 CAD との機能比較 (`docs/competitor-comparison.md`)。公式のドキュメントで確認した範囲を、確認していない部分と分けて載せています。

### 画面なしで動かす `ccad`
- zip には、画面つきの `circuitCad.exe` のほかに、画面なしで動かす `ccad.exe` も入っています。1行1コマンドのスクリプトで、回路を作る・ERC・解析・基板・製造データの書き出しまでを実行し、答えを1行1個の JSON で返します (`ccad script.ccad`)。AI エージェントや自動化向けで、`ccad mcp` で MCP サーバーにもなります。使い方は `docs/cli.md`。
- 今回、階層のコマンド (`sheet port` / `sheet place` など) とデジタル解析の記録の指定 (`tran record=`) が増えました。

### 既知の制限
- 動作確認は Windows のみです。macOS / Linux の配布はまだありません。
- 基板の発注の実績はありません。発注前に、発注先の仕様と発注前チェックを必ず確かめてください。
- メーカーの SPICE モデルは再配布できないため同梱していません。自分でダウンロードしたものを使ってください。
- 階層設計では、入力のポートを誰も駆動していない点検や、記号から子シートを作る機能は、まだありません。
