## v0.1.0-alpha.5

アルファ版です。動作確認は Windows のみで、基板の発注の実績はまだありません (README の「現在の状態と既知の制限」を参照)。

### 保存と作業の流れ
- **プロジェクトファイル (`.ccproj`)**: 回路図と基板を1つのファイルに保存して、まとめて開けます (ファイル → プロジェクトを開く / 保存)。
- **未保存の変更を確認します。** 新規作成・ファイルを開く・ウィンドウを閉じるときに、保存していない変更があれば「はい / いいえ / キャンセル」で聞きます。
- **スペック表 (合否の表) が保存されます。** `.schjson` と `.ccproj` に入るので、閉じても目標値が消えません。目標値を書き換えただけでも「未保存の変更」になります。古いファイルは、そのまま開けます。
- **回路図を変えたあとの基板の ● 表示**: 基板が回路図とずれると、基板のタブに ● が付き、基板パネルに追加・削除・値の変更の件数が出ます。

### 基板
- **押しのけ配線のプレビュー**: カーソルに合わせて、押しのけられる配線の今の位置 (細い線) と動く先 (太い線) を橙色で表示します。違反になるときは赤です。配線が多い基板では、計算を間引いて軽くします。
- **サーマルビア**: 放熱パッドの下に足りない分を自動で置くボタンを追加しました。同じネットの大きなベタが接していれば、必要な数が半分になります。
- **ベタ**: どこにもつながらない銅の島を捨てるオプションを追加しました。
- **自動配線**: パッドの上にビアを置かなくなりました。電流を宣言したネットは、必要な太さで配線します。
- **シルク**: スルーホール部品の本体の外形と極性の印 (ラジアルコンデンサの +/−、ダイオードの帯、LED の平らな側など) を出します。
- 選択ツール以外のツールを選ぶと、選択が外れるようになりました。R・B・Delete キーは選択ツールのときだけ働きます。
- BOM の値から、シミュレーション用の値 (`ESR=…` など) を除きました。

### 3D 表示
- 部品の向きの印を追加しました (IC の 1 番ピンの点、ダイオード/LED のカソード、電解コンデンサの−側の縞)。部品の高さは、部品データの値を使います。
- 選択した部品への寄り、選んだネットの銅を光らせる表示、画面の PNG 保存を追加しました。
- ケース高さを超える部品を赤くして知らせます。回す・動かす・拡大している間は、粗い絵で軽く描きます。

### 回路図と部品
- ダイオード・トランジスタ・オペアンプなどを、JIS/IEC の標準的な記号で描きます (新しく作る部品は小さめの形)。
- **部品作成フォームを作り直しました。** 最初に部品の種類 (IC・トランジスタ・ダイオード・チップ・コネクタ) を選び、タブ (基本・ピン・基板の形・シミュレーション・定格) で入力します。右側に、記号と基板の形が実寸比で常に見えます。データシートの本体の大きさ・高さ・放熱パッドを入れると、シルクと 3D 表示に反映されます。
- コンデンサ (セラミック・電解・タンタル・フィルム)・抵抗・コイルの種類を追加しました。電解コンデンサは、**リップル電流と寿命**を定格に入れておくと、過渡解析の結果と比べて、許容を超えていないか・推定の寿命を表示します。
- 部品一覧は、コンデンサ・ダイオード・トランジスタをフォルダに分けました。フィルムとタンタルのサンプル部品を追加しました。
- リード付きのコンデンサは、スルーホールとして扱います。

### 学習
- **レッスン 23「可変電源」** (商用電源 → トランス → ブリッジ → LM317 とダイヤル) を追加しました。レッスンは全 23 本、「作ってみよう」は 9 本です。
- 「作ってみよう」の開始画面で、GND の記号がツェナーダイオードに重なっていた問題を直しました (ツェナー、エミッタフォロワ、直列レギュレータ)。
- 部品作成フォームのエラーを、原因と直し方が分かる日本語にしました (例: 部品名が空のとき)。

### 互換性について
- スペック表の保存のため、`.schjson` と `.ccproj` の回路図の部分に `specs` という項目が増えることがあります。**古いバージョンで開くと、スペック表は無視されます** (読み込みは失敗しません)。
- 以前から入っている部品ライブラリの一部は、起動時に一度だけ更新されます (変更していない部品だけ。リード付きコンデンサの形など)。
