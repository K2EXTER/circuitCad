## v0.1.0-alpha.13

> **English:** the Prototype tab grows past the breadboard. **Stripboard and perfboard** layouts are made for you: which strips to cut, tinned-wire links (also at 45°), the view from the solder side, sections built and powered one at a time, and a printable full-size drawing; switch the power on and they run like the breadboard, with the meter and the scope. An **Arduino** now runs together with the circuit: write a sketch for a Nano, Mega or ATtiny85 as code or **by stacking blocks** (the blocks are the Arduino code: change one and the other follows, and the running block lights up), with a serial monitor, servos and an I²C sensor. With arduino-cli installed, the compiled program itself runs on a simulated ATmega328P. Also new: tidying a schematic (signals left to right, supplies up, ground down), net highlighting, a design review, a power budget, inrush current, ADC readings and noise, rounded pads and teardrops, cable drawings, and a browser version of the learning parts. The English UI covers all the new screens, and the README has an English demo recording. Still an alpha: tested mainly on Windows.

アルファ版です。動作確認は Windows が中心です (README の「現在の状態と既知の制限」を参照)。

今回は、**ストリップ基板・ユニバーサル基板**と、**Arduino を回路と一緒に動かす** (コードでもブロックでも) のが主な変更です。

### 試作: ストリップ基板・ユニバーサル基板
- 試作のタブの上の帯で、ブレッドボード・**ストリップ基板・ユニバーサル基板**を切り替えます。部品の並べ方を自動で作り、切る帯の穴・すずめっき線 (ななめ 45° も)・表の線 (被覆線) を出します。
- **裏 (はんだの面) から見る** (F キー)、**区画ごとに組む順と各段の通電**、**印刷用の図** (表と裏、実寸の SVG)。
- 部品の並べ方は手で直せます (ドラッグ・回す・揃える・固定して残りを並べ直す・区画の箱を置く)。元に戻す・やり直すも使えます。
- **電源を入れると、銅の帯とすずめっき線でつながったとおりに動きます**。テスターとオシロも当てられます。
- IC をソケット・変換基板に載せる、チップ部品を裏に付ける、モジュールをメスのピンヘッダに差す、四隅の取り付け穴、設計の要件の表 (近くに置く組・パスコンの距離) を守る並べ方、などにも対応しました。
- 絵の拡大縮小と移動、回路図と同じ部品の選び方、回路図の小窓、未接続の線 (ラッツネスト)。抵抗・ダイオード・LED・コンデンサは実物に近い見た目に。電流の流れを**動く点**で見せます。

### 試作: Arduino
- **Arduino Nano にスケッチを書くと、電源を入れたときに回路と一緒に動きます** (pinMode・digitalWrite/Read・analogRead/Write・delay・millis・Serial)。`analogWrite` は本物と同じパルスで、LED はその割合の明るさで光ります。
- **ブロックで書けます**: 「コード | ブロック」で、命令のブロックを積み重ねて書きます (Scratch のように)。並べたブロックがそのまま Arduino のコードになり、コードを書き換えるとブロックも変わります。電源を入れると、今動いているブロックが光ります。サンプル「Arduino をブロックで書く」。
- スケッチのエディタ: 色分け、誤りの行の印、整形、行番号つきの大きな別窓 (ブロックとコードを左右に)、元に戻す・やり直す。シリアルモニタは端末の見た目で、文字を送ることもできます。
- **ATtiny85** と **Arduino Mega** (ボードの横に置いてジャンパー線でつなぐ)、**サーボ**、I²C の温湿度センサー **SHT31** の部品。
- **本物のマイコンの命令で動かす**: arduino-cli があれば、スケッチをコンパイルして、Nano のマイコン (ATmega328P) の命令を 1 クロックずつ回路と一緒に動かします (simavr)。ライブラリ・割り込み・EEPROM・Servo・Wire も動きます。
- 回路図のマイコンボードのピン定義を書き出してファームと照合し、外部のツール (arduino-cli・Pico SDK・iCE40 の道具) でビルドと書き込みができます。

### 回路図
- **回路図を整える**: 信号は左から右、電源は上、GND は下に並べ直します。
- **ネットのハイライト**: 線・ピン・ラベルにカーソルを当てると、同じネットが全部光ります。つながっていない線の交差は、半円の飛び越しで描きます。
- 選んだ部品の役割 (分圧・RC・LED の抵抗・プルアップ・パスコン・帰還) を吹き出しで説明します。
- **設計レビュー** (推奨の部品の付け忘れ・水晶の負荷容量・出力に直接つないだ LED など)、**電源の予算表** (あと何 mA・レギュレータの発熱)、**突入電流** (電源を入れた瞬間のピークと、通り道の部品の定格)。
- ピンヘッダの形 (ピンの数・1 列か 2 列・オスかメス)、複数ユニットの部品、付箋 (レビューのコメント)、色覚に配慮した配色、計算中の表示と止めるボタン。

### 測る
- **ADC の読み**: DC の動作点で ADC が読むコードと、データシートの雑音の表からの揺れ・実効の分解能。**ADC で測る量の表** (読み・誤差・温度係数・漏れ)。
- 実測を回路図のネットのそばに出す、長い時間の記録からドリフトと温度係数を出す、実機のタブでテスターの値を入れて予測と比べる。
- 波形を音で聴く (WAV)、WAV を電源の波形にする。

### 基板と 3D
- **角を丸めたパッド**、ティアドロップ、パッドの辺からの肉づけ。部品を横・縦に詰めて並べる、つながる順に並べる。
- 伝送線路として扱う長さの点検、原寸の確かめの図 (パッドと穴を 1:1 で印刷)。
- **ケーブル・ハーネスの図**、複数の基板の全体を過渡解析・AC 解析。ケースの設計の続き、SolidCraft で開く、STEP の読み込みの続き。

### 部品
- 同梱の部品を足しました: ルネサス RL78/G14 (R5F104LHA)、REF5025・LT3045・ADR4525、TPS62933、Panasonic FK の電解コンデンサ、Yageo RT の精密抵抗、TDK CGA の積層セラミック、ADS124S08、リレー など。部品のモデルに温度による変化も入れました。

- 作った部品を 1 ファイルで渡す、データシートの版の記録、置いた部品をライブラリの今の版にする。

### 既知の制限
- 画面 (UI) は、改善の途中です。分かりにくかった所を教えてもらえると助かります。
- 動作確認は Windows が中心です。Linux は WSL2 で確かめただけで、macOS の配布はまだありません。データシートの絵の文字認識は Windows だけです。
- 基板は、このソフトの Gerber で発注したものが届き、パターンに不備がないことまで確かめました。部品を載せて動かす確認はまだです。
- 「本物の命令で動かす」には arduino-cli (Arduino IDE 2 に入っているものでも可) が要ります。I²C の相手の部品は SHT31 だけで、SPI の相手の部品はまだありません。
- メーカーの SPICE モデルは再配布できないため同梱していません。自分でダウンロードしたものを使ってください。
