## v0.1.0-alpha.6

アルファ版です。動作確認は Windows のみで、基板の発注の実績はまだありません (README の「現在の状態と既知の制限」を参照)。

今回は、**基板まわり (自動配置・自動配線・配線の仕上げ・GND ベタ)** と、**メーカーの SPICE モデルを読む力** が大きく変わりました。

### 基板: 自動配置
- **IC を中心に、つながる部品を周りに集める配置**を追加しました。つながりの強い順に1つずつ、すでに置いた部品のパッドにピンが近づく位置へ置きます。従来の「段に並べる配置」も作り、ネットの長さが短いほうを採ります。段に並べる配置のほうは、部品の順番を入れ替えて、ネットが短くなる順番を探します (結果は毎回同じです)。
- 部品の隙間を 1.6mm から 2.4mm に広げました。同梱サンプルを自動配置→自動配線して比べると、通らなかった線が 8 本から 2 本に減りました (今回の変更をすべて入れると 0 本です)。
- 73 部品の基板で、自動配置が 1.4 秒から約 0.15 秒になりました。

### 基板: 自動配線
- **通らなかったネットを先に引き直す**再試行を入れました (最大 3 回、時間の上限つき)。同梱サンプル 40 個は、自動配置のあとの自動配線で、未配線が 0 本になります。
- **パッドの出入りがきれいになりました。** パッドから垂直に出る短い区間 (リード) の先が、格子とずれて短い斜めの段差や出っ張りになっていたのを直しました。IC のように間隔が狭くてリードを置けないパッドも、水平・垂直・45° の線でつなぎます。
- **GND ベタのボタン** (左パネル「② 配線」): 裏面ぜんぶを GND の銅箔にして、表面の GND パッドを短い線とビアで裏のベタにつなぎます。GND の長い配線が要らなくなります。自動配線の前に押します。四角い外形の基板で使えます。
- **速くなりました。** 73 部品の基板で、自動配線の1回が 13.5 秒から約 0.9 秒、整えた形の計算が 0.59 秒から 0.013 秒になりました。配線の結果は変わりません。
- **自動配線は、パッドの上に垂直に出入りします** (「パッドに垂直に出入り」のチェック)。手で引くときも、パッドの両端に吸い付き、垂直な区間が付きます。
- **配線ツールの自動経路**: 始点からカーソルまでの経路を、障害物を避けて、その場で探して見せます。
- 押しのけ配線は、両端が固定された配線も、45° の折れで脇へよけます。

### 基板: 配線の仕上げ (「③ 仕上げ」)
- **整えた形で表示・出力**: 配線そのものは変えずに、角丸め・太さの段差・パッドの涙型・分かれ目と T 字の凹みを、表示・ガーバー・DRC のときだけ計算します。「配線に確定する」「選んだ配線だけ確定する」もあります。
- 涙型は、自動配線の短いリードにも付きます。根元は、パッドの幅にそろえて、配線が横にずれても、はみ出しません。
- **整えないネット**を選べます (差動ペアや形が特性を決める線を守ります)。3D 表示の銅の光り方も、整えた形に従います。
- **長さ合わせ (蛇行配線)**: ネットを目標の長さに合わせます。山の形は、四角・面取り・丸から選びます。

### SPICE モデル
- **メーカーが配っている実際のファイルを読めます。** 順序によらない `.param` と `{式}`、ネストした `.subckt`、`TABLE`・`VALUE`・`POLY`、パラメータ付きのモデル行など。読めない書き方は、部品作成フォームの「試し読み」ボタンが、小さな回路で試して、理由を説明します。
- **トランジスタ・ダイオード・コイル・MOSFET の精度が上がりました。** BJT のアーリー効果・コレクタとエミッタの抵抗・接合容量・拡散電荷・リーク、ダイオードの電荷蓄積と再結合、コイルの飽和 (`ISAT`/`LDROP`)、MOSFET の W/L/M。過渡・AC・ノイズ解析で使われます。
- **部品作成フォームの「かんたん作成」**: ダイオードの IS/N/RS を、データシートのグラフの点から求めます。チップ部品 (コンデンサ・コイル・抵抗) は、インピーダンスの表から、ESR・ESL などを当てはめます。リード付き部品は、データシートの図面の寸法から、穴・パッド・ピッチ・本体の目安を出します。

### 部品
- **18650 リチウムイオン電池の部品** (`LIION_18650`、`LIION_18650_CHG`) の基板の形を、電池ホルダー用 (パッド間 77mm) から、**配線やコネクタをはんだ付けする 2 穴 (2.54mm ピッチ)** に変えました。サンプル `tp5100_cell_charge` と `li_ion_cell_charge` も、これに合わせて作り直しました。

### 互換性について
- **自動配置の結果が、前のバージョンと変わります。** 保存した基板 (`.pcbjson`、`.ccproj`) は、そのまま開けます。「自動配置」を押し直すと、配置が変わります。
- 基板の保存ファイルに、整えた形の設定 (`finish`)、整えないネット (`finish_exclude`) などの項目が増えます。**古いバージョンで開くと、それらは無視されます** (読み込みは失敗しません)。
- 以前から入っている部品ライブラリのうち、**手を加えていない 18650 の 2 つの部品だけ、起動時に一度だけ更新されます。** 手を加えた部品は、そのままです。
- **以前に 18650 を使って保存した回路図・基板も、そのまま使えます。** 古い基板の形 (`BatteryHolder_18650`、パッド間 77mm の電池ホルダー) は、組み込みの形として残してあります。回路図から基板へ取り込み直しても、電池ホルダーの形のままです。新しい 2 穴の形にしたいときは、部品を置き直してください。
