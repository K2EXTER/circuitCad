## v0.1.0-alpha.10

アルファ版です。動作確認は Windows が中心で、基板の発注の実績はまだありません (README の「現在の状態と既知の制限」を参照)。

今回は、**Linux 版の zip が付いた**こと、**コンデンサの直流バイアスと部品ごとの店の型番**、**階層設計の ERC の追加**が主な変更です。

### Linux 版 (確認は限定的です)
- `circuitCad-linux-x64.zip` を付けました。展開して `circuitCad` を起動します (画面なしの `ccad` も入っています)。
- 確認したのは、WSL2 の Ubuntu 26.04 (GPU なし) で、ビルド・起動・画面の描画・日本語の表示 (OS の日本語フォントがない状態でも、同梱フォントで表示)・基本の操作だけです。他のディストリビューションや実機は未確認です。
- GTK などの実行用ライブラリが足りないと、起動しないことがあります。動かないときは、Issue で教えてください。
- macOS 用はまだありません (CI でのビルドとテストだけです)。

### シミュレーション
- **コンデンサの直流バイアス**: 値に `BIAS=61` のように書くと、動作電圧で残る容量 (%) で計算します。16 V のセラミックが定格の近くで容量の多くを失うことを、初学者が体験できます。SPICE の書き出しにも反映され、ばらつき解析・最悪ケース解析もそのまま使えます。
- **AC 解析**: 交流が届かないノード (電源など) が最初に選ばれて、グラフが -318 dB まで伸びてしまう問題を直しました。AC 電源に応答する電圧を先に選びます。

### 回路図・部品
- 階層設計の ERC に、**入力のポートを誰も駆動していない**ときの警告が増えました (電源・部品・別の記号の出力から、抵抗やコイルを通ってつながるものは駆動と見なします)。
- **店の型番**: 抵抗やコンデンサ (ライブラリ部品でないもの) にも、DigiKey・秋月・LCSC の型番を部品ごとに持たせられます (部品パネルの「買える店の型番」)。基板への取り込みと購入リストに使われます。
- 1N4148 と AMS1117-3.3 に DigiKey の型番を入れました。

### 基板
- **フットプリント**: リフロー用の 0805 (`R_0805_Reflow` / `C_0805_Reflow`。YAGEO の推奨ランド) と、タンタルのケース B (`CT_3528-21`。KEMET T491 のランド、極性の印つき) を足しました。
- 部品 `T491B226K016AT` (22 µF 16 V のタンタル。ESR はデータシートの最大値。ESL は記載がないため入れていません) を足しました。AMS1117 系の LDO の出力向けです。
- シルク: ランドの間にすき間のあるダイオード (DO-35 など) に、カソードの帯を描くようにしました。

### 画面なしで動かす `ccad`
- `footprint REF NAME` で、スクリプトから部品のフットプリントを指定できます。
- `shop` で店の型番を指定できます。
- `value` / `add` が、`ESR` / `ESL` / `IC` / `BIAS` / `DCR` の指定を受け付けるようになりました。

### 紹介ページ・GitHub
- 紹介ページ (<https://k2exter.github.io/circuitCad/>) に、SmartScreen の注意と、使い方の紹介を足しました。
- Issue のテンプレート (不具合・要望) を足しました。

### 既知の制限
- 動作確認は Windows が中心です。Linux は上のとおり限定的で、macOS の配布はまだありません。
- 基板の発注の実績はありません。発注前に、発注先の仕様と発注前チェックを必ず確かめてください。
- メーカーの SPICE モデルは再配布できないため同梱していません。自分でダウンロードしたものを使ってください。
- 階層設計では、記号から子シートを作る機能は、まだありません。
