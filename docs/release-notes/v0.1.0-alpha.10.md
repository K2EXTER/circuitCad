## v0.1.0-alpha.10

> **English:** this release adds an **English UI**. Choose **Settings → Language / 言語 → English** (or start with `--lang en`). Menus, hover help, error messages, the operation guide (F1), the glossary, the learning paths and all lessons and challenges are translated. The English text was translated with AI help from the Japanese original; please report awkward wording in an issue. Also new: a Linux zip (checked on WSL2 only), opening KiCad schematics, DXF/SVG export for case design, autosave and crash recovery, keep-out areas, a rule check while you work, and silkscreen editing. Still an alpha: tested mainly on Windows, and no board made with it has been manufactured yet.

アルファ版です。動作確認は Windows が中心で、基板の発注の実績はまだありません (README の「現在の状態と既知の制限」を参照)。

今回は、**英語の画面**、**Linux 版の zip**、**KiCad の回路図を開く・ケース設計のための DXF/SVG**、**自動保存と復旧**、**基板の作業を助ける道具 (禁止領域・作業中の点検・寸法線・距離を測る・シルクの手直しなど)** が主な変更です。

### 英語の画面
- メニュー「設定」→「Language / 言語」で、日本語と英語を切り替えられます (すぐ切り替わり、次の起動でも残ります)。起動のときに `--lang en` を付けても英語になります。
- メニュー・ボタン・ホバーの説明・エラーや ERC/DRC の指摘・発注前チェック・操作ガイド (F1)・用語集・学習パス・レッスン 51 本・チャレンジ・基板のレッスン・実機の案内まで、英語で出ます。英語のときの用語集は英語名の ABC 順に並び、英語でも探せます。
- 英訳は、日本語の原文から AI (Claude) が訳したものです。おかしな言い回しがあれば、Issue で教えてください (`crates/i18n/en/*.tsv` の1行を直すだけで直せます)。
- 日本語の画面は、これまでと変わりません。

### Linux 版 (確認は限定的です)
- `circuitCad-linux-x64.zip` を付けました。展開して `circuitCad` を起動します (画面なしの `ccad` も入っています)。
- 確認したのは、WSL2 の Ubuntu 26.04 (GPU なし) で、ビルド・起動・画面の描画・日本語の表示 (OS の日本語フォントがない状態でも、同梱フォントで表示)・基本の操作だけです。他のディストリビューションや実機は未確認です。
- GTK などの実行用ライブラリが足りないと、起動しないことがあります。動かないときは、Issue で教えてください。
- macOS 用はまだありません (CI でのビルドとテストだけです)。

### ファイル・ほかのソフトとのやりとり
- **KiCad の回路図を開く**: 「ファイル」→「KiCad の回路図を開く…」で、KiCad 6 以降の `.kicad_sch` を取り込みます。部品はこのソフトの記号で並べ直し、つながりはネットの名前で表します (図の形・位置は引き継ぎません)。極性つきのコンデンサ、VSIN / VPULSE の電源も読みます。
- **ケースの設計のために**: 基板の外形・穴・部品の箱を DXF で書き出せます。ケースの DXF から外形と穴を読み込めます。3D 表示で、基板と部品がケースの中に収まるかを確かめられます。
- **SVG / PDF**: 基板の片面を Gerber から SVG に、回路図を SVG と PDF (1 ページ) に書き出せます。
- **自動保存と復旧**: 保存していない作業を 1 分ごとに保存し、落ちたあとの起動で戻すかを聞きます。
- 回路図に**図枠** (タイトル・版・日付・作者・メモ) を付けられます。

### 基板
- **禁止領域**: 配線・ビア・ベタ・部品を置かない場所を、層ごとに描けます。DRC が点検し、自動配線とベタがよけます。
- **作業中の点検**: 編集しながら設計ルールを別のスレッドで点検し、違反の印と数を画面に出します。
- **寸法線**と**距離を測る道具** (パッドやビアに吸い付き、距離・縦横・角度・mil を表示)。
- **シルクの手直し**: 自由な文字、部品番号の大きさ・向き・非表示、線の太さを、発注先の下限を守って変えられます。部品番号の位置は、重なりをよけて決まります。
- **ネットの一覧**の窓 (クラス・層ごとの長さ・遠回り・ビア・線幅・ベタ・未接続)。
- **GND のビアの縫い付け** (ベタの重なりに並べる / 縁に沿って柵にする)、**テストポイント** (BOM・実装・購入リスト・3D から外れる部品) と**フィデューシャル**。
- **部品番号を位置の順に振り直す** (回路図と設計の要件の表もそろいます)。**スニペット**: 選んだ部品を配線・ビアごと保存して、別の基板へ部品番号で置けます。
- **自動配置**: ロックした部品はそのままにして、残りをまわりに置きます。水晶とその負荷コンデンサを、IC のクロックのピンの前に置きます。
- 表示のパネルを、まとまりごとに整理しました (禁止領域・寸法線・点検の印の目のボタン)。
- 回路図・基板・3D で、選んだ部品とネットが連動して光ります (設定でオフにできます)。
- 3D: TO-220 のタブ、TO-92、USB やジャックの殻、端子台のネジ、トランス、ブザーの形と、実物に近い高さ。

### シミュレーション
- **コンデンサの直流バイアス**: 値に `BIAS=61` のように書くと、動作電圧で残る容量 (%) で計算します。16 V のセラミックが定格の近くで容量の多くを失うことを、初学者が体験できます。SPICE の書き出しにも反映され、ばらつき解析・最悪ケース解析もそのまま使えます。
- **AC 解析**: 交流が届かないノード (電源など) が最初に選ばれて、グラフが -318 dB まで伸びてしまう問題を直しました。AC 電源に応答する電圧を先に選びます。

### 回路図・部品
- 階層設計の ERC に、**入力のポートを誰も駆動していない**ときの警告が増えました (電源・部品・別の記号の出力から、抵抗やコイルを通ってつながるものは駆動と見なします)。
- **店の型番**: 抵抗やコンデンサ (ライブラリ部品でないもの) にも、DigiKey・秋月・LCSC の型番を部品ごとに持たせられます (部品パネルの「買える店の型番」)。基板への取り込みと購入リストに使われます。
- フットプリント: リフロー用の 0805 (`R_0805_Reflow` / `C_0805_Reflow`。YAGEO の推奨ランド) と、タンタルのケース B (`CT_3528-21`。KEMET T491 のランド、極性の印つき)。部品 `T491B226K016AT` (22 µF 16 V のタンタル)。
- シルク: ランドの間にすき間のあるダイオード (DO-35 など) に、カソードの帯を描くようにしました。

### 画面なしで動かす `ccad`
- `import_kicad` (KiCad の回路図)、`board dxf` / `board dxf_import` / `board svg` / `board case`、`footprint REF NAME`、`shop` (店の型番) が増えました。
- `value` / `add` が、`ESR` / `ESL` / `IC` / `BIAS` / `DCR` の指定を受け付けるようになりました。

### 既知の制限
- 動作確認は Windows が中心です。Linux は上のとおり限定的で、macOS の配布はまだありません。
- 基板の発注の実績はありません。発注前に、発注先の仕様と発注前チェックを必ず確かめてください。
- 英語の画面は新しく、言い回しのおかしな所や、日本語のまま出る文が少し残っているかもしれません。
- メーカーの SPICE モデルは再配布できないため同梱していません。自分でダウンロードしたものを使ってください。
- 階層設計では、記号から子シートを作る機能は、まだありません。
