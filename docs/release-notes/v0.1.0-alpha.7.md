## v0.1.0-alpha.7

アルファ版です。動作確認は Windows のみで、基板の発注の実績はまだありません (README の「現在の状態と既知の制限」を参照)。

今回は、**学習パスが 3 本・レッスン 46 本に増えたこと**と、**画面なしで動かせる `ccad`**、**配線した基板の銅の抵抗・インダクタンスまで含めたシミュレーション**が大きく変わりました。

### 学習
- **学習パスが 3 本になりました**: 安定化電源を作ろう / Arduino 互換ボードを作ろう / Arduino Mega 互換ボードを作ろう。2 本目と 3 本目は、レッスンの関係を**樹形図 (学習の地図)** で見られます。順番は強制ではなく、先に済ませると分かりやすいものが線でつながります。
- **レッスンが 46 本になりました。** 新しいもの: 水晶とクロック・リセット・バイパスコンデンサ・プルアップ・ピンの LED・レベル変換・シリアル・データシートの読み方・USB の電気 (VBUS・速度の見分け・信号線)・PWM・フライバックダイオード・ボタンのチャタリング・温度/光/電流センサ・LDO・TL431、Mega 向けの ADC の入力・電源ピン 5 組・水晶の負荷容量・CH340G と USB のノイズ。どれも、サンプル回路を動かして数値を確かめ、「実物との違い」と「実機で確かめよう」の注意がつきます。
- **基板のレッスンが 6 本になりました**: 配線の太さと電圧降下 / 発注前チェックを通す (チャレンジ) / マイコンの基板の置き方 / USB の差動ペア / 100 ピンの基板を手で仕上げる (Mega)。
- **「実機の作業」のチェックリスト**: 表面実装のはんだ付け・ブートローダの書き込み・100 ピン (0.5mm ピッチ) のはんだ付け。アプリが判定できない作業を、安全の注意と「うまくいかないとき」の表つきで見せます。
- 「学ぶ」メニューは、学習パスごと・段階ごとのサブメニューになりました。学習パスの窓は、画面の大きさに合わせて開きます。

### 画面なしで動かす `ccad` (AI エージェント・自動化向け)
- 1 行 1 コマンドのスクリプトで、名前ベースの回路作成・ERC・DC/過渡/AC 解析・基板・製造データの書き出しを実行し、答えを 1 行 1 個の JSON で返します (`cargo run -p cli -- script.ccad`、使い方は `docs/cli.md`)。
- `ccad mcp` で MCP サーバーにもなります。`--strict` で、ERC にエラーがあるときは解析を拒みます。値の計算 (14 種)・周波数応答・スペックの合否・発注前チェックも使えます。

### 基板
- **配線した基板の銅を含めたシミュレーション (レイアウト後シミュレーション)**: 配線の抵抗・インダクタンス・配線どうしの磁気結合・ベタの上の配線の容量・ビアのインダクタンス・表皮効果の警告を、解析に入れられます。数式は FastHenry2 との比較テスト (自己 1.0% 以内、相互 0.7% 以内など) で確かめてあります。
- 発注前チェックに、回路図と基板の食い違い・配線の電圧降下・発注先の料金の枠 (基板の大きさ) を追加しました。
- 自動配置はバイパスコンデンサを電源ピンのそばへ寄せます。自動配線は、手で引いた配線の遠回りやビアを引き直す「配線を短くする」と、一直線の配線のまとめ、パッドの垂直な出入りを備えます。GND ベタは表面にも広がります。
- 基板エディタの左パネルを「手で引く」と「手順」に分け、数字キーでツールを選べます。ツールの設定は、そのツールのボタンの下に出ます。

### SPICE モデルと解析
- メーカーのモデルを読む力が上がりました (デジタルのゲート・フリップフロップ、結合インダクタ、伝送線路、`.func`・TABLE・POLY、LTspice の A デバイスなど)。同梱の検証用の集まりで、読める割合が 8 割台から 9 割強になりました。
- ngspice との照合を、AC 解析にも広げました (CI で保存した答えと比べます)。結果は `docs/accuracy.md` に載せています。
- **CH340G の仮のモデル**と、**学習用の電圧制御スイッチ** (`SW_SAMPLE_DEMO`) を同梱しました。どちらも「学習用の仮のモデル」です。USB のプロトコルは扱いません。
- 過渡解析の刻みの制御と、故障シミュレーション (全コアで並列、進行表示と中止ボタン) が速く、止まらなくなりました。

### サンプル・部品
- Arduino 互換ボード (ATmega328P) と、Mega 2560 互換ボード (ATmega2560 + CH340G。シールドなし) の回路図。Mega の基板は、自動配線が 18 本残した「仕上げ待ち」の状態で `docs/examples/work_in_progress/` にあります (手で仕上げる練習用)。
- 大きな混合信号のサンプル (電源・555 とカウンタ・温度アラーム・アンプ)、3 相電源の部品、センサ (LM35・TMP36・NTC・LDR・フォトダイオード・INA180・ACS712) などの部品を追加しました。

### 既知の制限
- Windows のみ動作確認です。実機で作った・発注した実績はありません。
- Mega の基板は、自動配線では通らない線が残ります。手で通しきれるかは、確かめていません。
- 「実機で確かめよう」の内容は、文章だけです (実際に作って確かめてはいません)。
