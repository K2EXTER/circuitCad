## v0.1.0-alpha.8

アルファ版です。動作確認は Windows のみで、基板の発注の実績はまだありません (README の「現在の状態と既知の制限」を参照)。

**ライセンスが AGPL-3.0-or-later になりました** (v0.1.0-alpha.7 までは MIT OR Apache-2.0 のまま)。

今回は、**設計の要件の表 (回路図と基板で共有する、配線と配置の約束事)**、**基板の見た目と配線の仕上げ**、**解析の追加 (極と零・ループゲイン・最悪ケース・インピーダンス・自己発熱)**、**レッスンの追加 (51 本)**、**部品を動かすときの軽さ**が大きく変わりました。

### 設計の要件の表
- 回路図に「設計の要件」の表を持てます: ネットの役割・太さ・電流、近くに置く部品の組、離す組、バイパスコンデンサとICの対応、配線の道筋の測定 (抵抗・電圧降下・ビアの数・並走・分かれ目の長さ・ガードの被覆など)、承知した例外 (理由つき)。
- 基板に取り込むと、自動配置は組を1つの塊として置き、自動配線は役割の順番に引きます。基板のパネルに行ごとの結果 (満たした・取り込めなかった理由) が出て、回路図と基板の図の上に枠と線で示せます。
- 配線の道筋の測定 (`board req`) や、役割の説明は `docs/routing-guidelines.md` にあります。

### 基板
- **配線の仕上げ**: 角丸め・涙型・パッドの首 (細いパッドに太い線で入るとき)・分かれ目の凹み・並走する同ネットのすき間埋めが、常に効きます。ネットクラスごとに上書きできます。
- **ネットをクリックすると窓が開きます**: 流れる電流・推奨の線幅・ネットクラス・仕上げ。線幅のスライダーで、そのネットの配線をそろえて変えられます。区間ごとの例外の幅も付けられます。
- **ベタを図形で編集**: 直線・円弧・3点円弧・接線円弧で描き、頂点や辺をポインタで直せます。穴 (切り抜き) の図形も使えます。
- 長さ合わせ (蛇行)・差動ペアの長さ合わせと、片方を押しのけるともう片方もついてくる配線。ガード (敏感な線の両側の配線とベタ)。
- 自動配置の改善: バイパスコンデンサと IC を1つの塊に、同じ構造を同じ向きで並べる、ピンヘッダの向きの自動調整、シートごとの塊。自動配線は細かいピッチの IC の足から先に出口を引く (ブレイクアウト)、使う層を限る、ビアを禁止する、など。
- 基板に故障を1つ仕込んで直す練習 (基板レッスン8)、配線の見た目の数字 (`board quality`)、画像での確認 (`board picture`)、部品の3D形状をメーカーの STEP から読む、購入リスト (店の型番・検索リンク)。
- 選択に Ctrl+クリックと Ctrl+範囲選択、部品番号の文字をドラッグで動かす、文字を配線からよける、Rで選んだ組を回す。
- **部品を動かすときが軽くなりました**: 実基板 (196 部品) で 1 フレーム 57ms → 8ms。つかんだ瞬間・離した瞬間の引っかかりも小さくなりました (離した直後の未配線の線と銅の端の計算は別スレッドで行います)。

### 回路図
- 複数のシート (タブ)、選んだ部分の保存と再利用 (スニペット)、コピー・貼り付け・複製、部品を動かすと配線が付いてくる、意図して未接続のピンの印 (NC)、描きかけの範囲を ERC の対象外にする。
- 基板で入れ替えたゲート・ピンを回路図へ戻す。

### 解析
- **極と零**、**ループゲイン** (位相余裕)、**最悪ケース解析**、**ネットから見たインピーダンス**、**ひずみ率 (THD)**、**抵抗の自己発熱**と**温度の時間変化**、シミュレーションが仮定していること (モデルの前提) の一覧。
- 直流・過渡が収束しにくい回路への対策 (段階の自動切り替え・原因の表示)、大きな系の解法の高速化、独立な計算を全コアで並列に。
- メーカーのモデル (村田・日本ケミコン・ニチコンなど、自分でダウンロードした zip) の索引と読み込み、メーカーの STEP の3D形状。

### 学習
- レッスンが 51 本になりました。新しいもの: 極と零 (48)、位相余裕 (49)、トランジスタ増幅のノイズ (50)、**故障を仕込んだ回路を直す (51)**、データシートだけで IC のモデルを作る (47)。
- 学習パスが増えました: 基板の作法・スイッチング負荷・電池で動く機器・信号 (フィルタ・増幅・発振)。
- 手順の前に**予想を答える問い**が出ます (答えは、あとでシミュレーションした数字に一番近い選択肢)。詰まった手順は、足りないもの (解析の結果など) を教えます。
- 初学者向けの通し確認で見つかった小さな問題の修正、文字の大きさと色の統一、ボタンの見た目の統一。

### 画面なしで動かす `ccad`
- 基板・解析・要件の表・ベタ・ガード・購入リストなどのコマンドが増えました。`ccad mcp` では基板の画像が MCP で返ります。使い方は `docs/cli.md`。

### 既知の制限
- 動作確認は Windows のみです。macOS / Linux の配布はまだありません。
- 基板の発注の実績はありません。発注前に、発注先の仕様と発注前チェックを必ず確かめてください。
- メーカーの SPICE モデルは再配布できないため同梱していません。自分でダウンロードしたものを使ってください。
