## 実マウスでの確認 (同じ日の2回目)

実際のマウスで、空の画面から「部品を置く → 線を引く → DC解析 → 値を変える → 基板に取り込む → 並べる → 自動配線 → DRC → 発注の準備 → プレビュー」と、レッスン1の最初の2手順を通した(リリース版、1920×1080、設定は空の一時フォルダ)。通ったもの: 部品の配置、配線(ピンからピンへ、右クリックで確定)、DC解析、値の書き換えと再計算、取り込み、自動配置、自動配線、DRC、発注の準備のチェック、レッスンの自動チェック。

見つかって、その場で直したもの:

| 見つかったこと | 直し方 |
|---|---|
| 「未配線を全部つなぐ」のあと、ツールが「配線」に切り替わり、左パネルが伸びて、手順の欄 (DRC・3D・発注の準備) が画面の外に出る(案内文は「DRC を実行」を押すよう言う)。原因: 自動配線は先に回路の電流を取り、その結果の欄 (配線の太さ) を開くため | 自動配線のために電流を取ったときは、その欄を開かない(`main.rs`、`width.rs close_width_panel`)。欄は「高度な配線」から今までどおり開ける |
| 「発注の準備」の出来上がりプレビューが、細い緑の帯(約35px)にしか見えない。原因: 窓の中のスクロール枠が、既定の最小の高さ (64px) に縮む | 最小の高さを 380 にした(`order.rs`) |
| 起動直後は「抵抗を置く」状態で、レッスンやサンプルの回路をクリックすると、抵抗が1個増える(回路の上に抵抗の影が出る) | レッスン・サンプル・開いたファイルは、選択ツールで始める(`lessons/mod.rs`、`file.rs adopt`) |

あとで直したもの(同じ日): 左パネルの幅が、部品を選ぶ・タブを切り替えるたびに変わって回路が約20px横にずれた → 初期の幅を400pxにして、どの状態でも回路の左端が同じ位置になった(`main.rs` の `PANEL_WIDTH`)。取り込みで部品が追加されたとき、表示を全体に合わせ、右上の「物の表示とロック」をよけて、基板と部品が見えるようにした(`file.rs`、`view.rs fit_view`)。

レッスンの窓が回路の右端にかぶる → レッスンの回路は、窓の左に合わせて表示する(`symbols.rs fit_view`)。ステータスの行で、状態の文が長いと豆知識が消える → 状態の文は行の3分の2まで、豆知識を残し、全文はポインタを合わせると読める(`main.rs`)。

見つかって、直していないもの(F6、`docs/candidates.md`): 基板のパッド名が、ネット名 (`N$1`・`GND`) で出る。

やり方の注意(次にやる人へ): 道具は `tools/screenrec.ps1`(実際のマウスを使う。動かしている間は、マウスとキーボードに触らない。デバッグ版は遅くてクリックが抜けるので、リリース版を使う)。複数の呼び出しで1つのアプリを操作するときは、画面全体の座標 (`FullShot` と `ClickAbs`) を使う。ウィンドウの基準位置 (`Client`) が、呼び出しごとにずれた。PowerShell では、関数名 `ac` が `Add-Content` の別名と衝突して、マウスが動かないまま、数字の名前のファイルができる(`AC`・`AR` は使わない)。
