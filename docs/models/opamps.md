# 同梱のオペアンプのモデルとデータシートの比べ

`crates/cli/tests/opamp_models.rs` が作る表(`cargo test -p cli --test opamp_models -- --ignored write_opamp_model_report`)。方針と表の読み方は `docs/model-policy.md` の 5 節。

- データシートの値は、各表の上に書いたデータシートから写した(2026-11-11)。モデルの値は、データシートの条件に近い回路で circuitCad のシミュレータが測ったもの。
- 「差」は typ と比べた差(typ が無い行は max と)。開ループ利得と位相余裕は dB・度の差。
- モデルは 1 回路だけ。電源電流は 1 回路あたりに直したデータシートの値と比べる。
- モデルはデータシートの typ に合わせて作った(2026-11-11)。typ が無い項目(MCP600x のオフセット)は 0。
- 合格の幅(`opamp_models_match_their_data_sheets`): 開ループ利得 ±1 dB、位相余裕 ±5°、GBW・オフセット・バイアス電流・電源電流・短絡電流 ±10%、スルーレートと雑音 ±20%、出力の振れ幅は typ(無ければ max)以下。
- pA 以下の電流は、シミュレータが各ノードに置く小さなコンダクタンス(1 pS)の分が混ざるので、正確でない(MCP600x のバイアス電流。10 pA 未満は判定しない)。
- 入力オフセット電圧の行のモデルの値には、有限の利得による小さな差(出力 ÷ 開ループ利得)も入っている。
