# 同梱のダイオードのモデルとデータシートの比べ

`crates/cli/tests/integration/diode_models.rs` が作る表(`cargo test -p cli --test integration -- --ignored write_diode_model_report`)。方針は `docs/model-policy.md`、モデルを作るのは `ccad fit`(データシートから読んだ値は `crates/part-lib/fits/` にある)。

- データシートの値は、各表の上に書いたデータシートの表と、描画したグラフから読んだ(2026-11-12。1N5817・1N5819 は 2026-11-14)。グラフの読み取りは 1% ほどの誤差がある。
- モデルの値は、データシートの条件に近い回路で circuitCad のシミュレータが測ったもの。接合容量は、100 kΩ と組んだローパスの利得から求めた。
- 「差」はモデル − typ(typ が無い行は max)。合格の幅はテストの各行(順方向電圧は ±15〜20 mV、接合容量は ±15%)。逆電流は比べるだけ(モデルは IS の分しか流れない)。
