# 同梱のコンパレータのモデルとデータシートの比べ

`crates/cli/tests/integration/comparator_models.rs` が作る表(`cargo test -p cli --test integration -- --ignored write_comparator_model_report`)。方針は `docs/model-policy.md`、モデルを作るのは `ccad fit`(`kind: comparator`、データシートの typ の値は `crates/part-lib/fits/` にある)。

- モデルの値は、データシートの条件に近い回路で circuitCad のシミュレータが測ったもの (VCC = 5 V)。
- 応答時間は、表は向きを分けないので、出力が下がる向きと上がる向きの両方を並べた。オーバードライブは、モデルのオフセット 2 mV を足した本当の切り替わり点から測る。
- 「差」はモデル − typ(typ が無い行は max)。合格の幅はテストの各行(応答時間は ±20 %)。
