# デモ GIF の台本: 回路図から基板まで (約 35 秒)

README の先頭近くに載せる、操作の流れを見せる GIF の撮り方です。使う回路は `docs/examples/regulator_led.schjson` (12V → LM7805 → 抵抗 → LED)。基板レッスンと同じ流れなので、手順どおりに押せば最後まで通ります (取り込み → 自動配置 → 自動配線で未配線 5 本が 0 本、DRC は違反なし)。

## 準備

1. **最新の main をビルドする**: `cargo build --release`。起動は `target\release\circuitCad.exe` (デバッグ版より軽い)。
2. **見せたくないものを消す**: ライブラリの「最近使った部品」や、個人のフォルダ名が画面に出ないようにする。まっさらな状態で撮るなら、PowerShell で次のように起動する。
   ```powershell
   $env:APPDATA = "$env:TEMP\demo_appdata"
   .\target\release\circuitCad.exe docs\examples\regulator_led.schjson
   ```
   (回路を引数で開くので、ファイルを開くダイアログは映らない。ウェルカムカードも出ない)
3. **録画ソフト**: ScreenToGif (無料) が扱いやすい。アプリのウィンドウだけを枠で囲んで録る。
   - 画面は 1920×1080 のまま録り、書き出し時に**幅 960〜1280 px** へ縮める (文字が読める下限は 960 px 前後)。
   - **10〜12 fps**。**10 MB 以下**を目安にする (README で重くならない)。
   - 動きが少ないので、フレームが同じ所は ScreenToGif の「重複フレームを削除」で詰める。
4. **マウスの動かし方**: ゆっくり、まっすぐ。ボタンの上で 0.5 秒止めてから押す。結果が出たら 1〜2 秒は動かさずに見せる。説明は文字 (後で字幕) に任せ、録画中は何も入力しない。

## 場面と操作

| 秒 | 場面 | 操作 | 見えるもの | 字幕案 |
|---|---|---|---|---|
| 0〜3 | 回路図 | 何もしない。マウスは LM7805 の上でゆっくり動かす | 12V → LM7805 → 抵抗 → LED の回路図 | 回路図を描く |
| 3〜9 | 動かして確かめる | 左パネルの「解析」タブ → 「DC動作点を解析」 | 配線が電圧で色づき、電圧 (5.000 V など) と電流 (9.2 mA) が出る | 動かして確かめる |
| 9〜12 | 基板へ | 上のメニュー「基板パターン」をクリック | 基板エディタの空の画面 | 基板にする |
| 12〜16 | 取り込み | 左パネル「① 部品の取り込みと配置」→「回路図から取り込み」 | 部品がまとまって現れ、黄色い未配線の線が見える | 回路図から部品を取り込む |
| 16〜20 | 配置 | 「部品を並べて外形を決める」 | 部品が並び、基板の外形が決まる | 自動で配置 |
| 20〜24 | 配線 | 「③ 配線」→「全部」 | 赤い配線がつながり、黄色い線が消える | 自動で配線 |
| 24〜28 | 検査 | 「④ チェックと発注」→「DRC を実行」 | 下のバーに「DRC: 違反 0 件」 | ルール違反を検査 |
| 28〜35 | 発注の準備 | 「発注の準備…」 | チェックの緑のチェックが並ぶ。最後の 2 秒は動かさない | 発注用データまで |

- 「書き出し先のフォルダを選んで書き出す」は**押さない** (ダイアログが映って流れが切れる)。
- 最後に 2 秒止めてから、ループの頭に戻る (GIF は自動で繰り返す)。

## うまくいかないとき

- **「回路図と違います」と橙色の文が出る** → 回路図を読み込んでいない。引数に `docs\examplesegulator_led.schjson` を付けて起動し直す。
- **途中で押し間違えた** → 基板の左パネルの「元に戻す」で戻せる。取り込みからやり直すなら、いったんアプリを閉じて起動し直すのが早い。
- **録画が重い・カクつく** → デバッグ版で撮っていないか確認 (リリース版で撮る)。
