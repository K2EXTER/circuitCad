# 回路図の階層設計(B8)の設計

目的: 同じサブ回路(チャンネル)を、1枚のシートに描いて、何度も使えるようにする。直すのは1か所で、全部に効く。
いまの複数シートは、`flat()` で横に並べるだけ(`sch-core/sheets.rs`)。ネットラベルは全シート共通で、同じ回路を繰り返すには、部品のコピーが要る。

## 方針: 展開は `flat()` の中で済ませる

ネットリスト・ERC・シミュレーション・基板取り込みは、31か所が `flat()` を通っている。階層も **`flat()` の中で、子シートを実体に展開する** ことにして、下流は変えない。

- 親のシートに「シートの記号」(部品の一種)を置く。子シートを指す。
- `flat()` は、記号を取り除き、代わりに子シートの中身を、記号1つにつき1回、コピーして入れる。
- 子シートを指す記号が1つも無いシートは、いまと同じ、独立したシートのまま。

## データ

- 記号は `Component` に `sub: Option<SubRef { sheet, instance }>` を足したもの。`custom`(部品作成の記号)のしくみが、ピンの描画・配線・ERC をすでにやっているので、そのまま使う。記号のピンは、子シートのポートから自動で作る(辺に並べる)。
- ポートは、ラベルの一種。`Label` に種類(普通 / ポート入・出・双方向)を足す。子シートに書くと、旗の形で描く。
- 古いファイルは、足した項目を `serde(default)` にするので、そのまま開ける。

## 展開のきまり (`flat()`)

| もの | 展開後 |
|---|---|
| 部品番号 | `R1_CH1`(元の番号 + `_` + 記号の名前)。先頭の文字を変えない(SPICE は先頭の文字で素子の種類を決めるため。`CH1/R1` だと C になる) |
| 子シートのラベル | `CH1.NAME`(記号ごとに別のネット)。電源記号(VCC・GND)は全体で共通のまま |
| ポート | 親側の記号のピンと、子側のポートのラベルに、同じ一時の名前を付けて、つなぐ。ネットリストの側は何も変えなくてよい |
| 位置 | いまの `SHEET_STRIDE` の考えを、シート + 記号ごとに1枠ずつ振る。枠 → (シート, 記号)の表を持つ(ERC の場所から開くシートを決めるため) |

入れ子(子シートの中にも記号)は、同じ展開を再帰する。自分自身を指す輪は、ERC で止める。

## 画面

- 記号を置く: クイック追加に「シートを部品として置く」。ダブルクリックで子シートに入る。上に「親へ戻る」の道筋を出す。
- ポート: ラベルツールに「ポート」の切り替え。向き(入・出・双方向)は、記号のピンの名前と形に出す。
- 子シートを直すと、全部の実体に効く。ホバーとヒントに、そう書く。

## 点検

- 親でつながっていないポート、子に無いポート、同じ名前のポートが2つ、ポートの無い子シート、輪になった参照。どれも `Problem{message,at,hint}` で、原因と直し方を書く。

## 下流

- シミュレーション: 展開後の名前(`CH1.OUT`)でそのまま動く。波形のラベルも展開後の名前。
- 基板: 展開後の部品番号で取り込む。**実体ごとを1つの配置の組(`place_groups`)にする**と、チャンネルのまとまりが保たれる。2チャンネル目以降に、1つ目の配置を写す機能は、あとの段階。
- バックアノテーション(基板で入れ替えたピンを回路図へ戻す): 展開後の番号 → 子シートの部品への逆引きが要る。実体が複数あると、1つの子に戻すと全部が変わるので、実体ごとの入れ替えは、はじめは「戻さない」と知らせる。

## 段階

1. **モデルと展開**(`sch-core`): `SubRef`・ポート・`flat()` の展開・部品番号とラベルの規則・テスト。CLI: `sheet place`(子シートを記号として置く。`sheet use` は編集中のシートの切り替えで先にあるので別の名前にした)と `sheet port`。**済(2026-11-06)**。
2. **画面**: 記号を置く・入る・戻る・ポートのラベル・記号の描画。**済(2026-11-06)**(`app/schematic/hierarchy_ui.rs`。置くのはシートのタブの右クリック、ポートはラベルツールの「ポートにする」)。
3. **点検・サンプル・説明**: **点検・サンプル・ヘルプは済(2026-11-06)、レッスンと用語集は未(用語集は、語が出るレッスンと一緒に足す決まり)**。 上の点検、4チャンネルのサンプル(`docs/examples/`)、レッスン、`help.rs`、用語集(階層・ポート)。
4. **基板**: 実体ごとの配置の組、1つ目の配置を写す。バックアノテーションの扱い。

## 決めたいこと(私の案つき)

- 部品番号の形 → `R1_CH1`(案)。`R101` のように振り直す方式もあるが、元の部品との対応が消える。
- 実体ごとに値を変える(チャンネルごとに別の抵抗値) → **はじめは無し**。同じ回路の繰り返しに絞る。必要なら、実体ごとの上書きの表を足す。
- 入れ子の深さ → 制限なし(輪だけ止める)。
- 電源記号は全体で共通のまま。子シートの中だけの電源ネットは、ポートで渡す。

## 限界(はじめの版)

- 回路図の上に重ねる電圧・電流の表示、解析結果の回路図への戻しは、1つ目の実体だけ。
- 実体ごとの部品の値の違いは扱わない。
