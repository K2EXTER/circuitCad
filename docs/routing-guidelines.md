# 配線の考え方(役割ごとのルール)

どの基板にも使える、配線の考え方のメモ。ネット名ではなく**役割**で書く。設計ごとに「どのネットがどの役割か」と数値を決めて(`microohm-meter` の例は末尾)、その表に沿って引く。
ここに書いたことのうち、ソフトが調べてくれるのは「いま使えること」の欄だけ。残りは、人が守る約束(DRC への取り込みは今後の候補)。

## 1. 手順

1. **要件を数字にする**(電流、電圧、周波数、精度、リーク、雑音、大きさ、部品の大きさと手はんだ)。
2. **ネットに役割を付ける**(下の表)。1 つのネットに役割は複数付いてよい。
3. **基準の構造を決める**(電源・グランドが何種類あるか、どれが電流を運ぶか、つなぎ目はどこか)。
4. **層構成を決める**(2 層か 4 層か、ベタはどのネットか)。
5. **区画に分けて配置する**(大電流 / アナログ / ロジック / スイッチングノード)。
6. **役割ごとのルールで引く**(下の順番)。
7. **確認する**(DRC → 未配線 0 → 電流 → 実機)。

## 2. 役割とルール

| 役割 | どんなネットか | ルール |
|---|---|---|
| **大電流** | 負荷電流・モータ・電源の主経路(目安 0.5 A 以上) | 線幅は電流から決める(「配線の太さ」の計算)。短く直線的に。ビアは複数並べる。電流の戻りも同じ太さ。熱をもつ部品には銅を広げる |
| **電源** | 電源ピンにつながる線 | 太め(0.3〜0.5 mm)。IC ごとに枝分かれ(星形)。バイパスコンデンサは電源ピンの近く(目安 5 mm、遠くても 8 mm)。コンデンサの GND 側は、その IC の GND ピンの近くでベタへビア |
| **スイッチングノード** | 降圧・昇圧の SW、ゲートドライブ、クロック | 面積を最小に。ループ(入力コンデンサ → スイッチ → グランド)を最小に。感度の高い部分(基準・ADC・センス)から離す(目安 20 mm 以上、または別の区画) |
| **高インピーダンスの検出** | 基準抵抗や微小電流を受ける線(入力インピーダンスが MΩ 級、電流が nA〜pA 級) | 短く。**ビアなし**。ベタの上を通さないか、ガードで囲む。ガードは両側に 0.2〜0.3 mm の間隔で、検出線と同じ電位のバッファで駆動。ガードの外側に、電源・ロジック・スイッチを置く。はんだマスクで覆う。**表面のリーク(汚れ・湿気)が誤差になる**ので、洗浄とコーティングも |
| **ケルビン(4 端子)** | 力と検出が別の経路になる線 | 力と検出を**測る点(パッド)で初めて合流させる**。検出線に電流を流さない。検出線は並べて(ペア)、短く。電流検出抵抗は、パッドの内側の端から検出線を取る |
| **アナログ信号** | 増幅・フィルタ・基準・ADC の入力 | 短く。ロジックやスイッチングの線の下を通さない。基準の戻りは同じ領域で完結させる |
| **ロジック** | デジタル信号、ゲート信号 | アナログの区画に入れない。信号と戻り(グランド)を近く。長い線は直列抵抗(数十 Ω)で立ち上がりを緩める |
| **熱** | 発熱の大きい部品 | 銅の面積を確保(目安: 1 W あたり 約 650 mm² で温度上昇 数十 ℃)。熱に敏感な部品(基準抵抗・電流検出)から離す。放熱パッドにはビアを複数 |
| **差動ペア** | USB・LVDS など | 長さをそろえ、間隔を一定に。ソフトの「差動ペア」を使う |

## 3. 基準(グランド)の構造

- 電源・グランドが何種類あるかを書く。電流を運ぶのはどれか、IC の GND ピンが何本どれにつながるか。
- **ベタは、パッドが一番多く、基準に使うネット**にする。ほかは線かベタの一部で引く。
- 戻り電流の通り道を考える。**ベタを切らない**(切れ目をまたぐ信号は避ける)。
- グランドが複数あるときは、**つなぎ目を 1 か所**にする(星形)。ほかでつなぐと、電流がグランドの上を回って、感度の高い部分を通る。
- バイパスコンデンサのループ(IC の電源ピン → コンデンサ → GND ピン)を最小にする。

## 4. 層構成の選び方

| 状況 | おすすめ |
|---|---|
| 単純な回路、電流が小さい | 2 層(裏をベタ) |
| ベタが 2 種類以上要る、感度の高い線とスイッチングが同居、部品が密 | 4 層(表: 部品と信号、内 1: 基準のベタ、内 2: 電源のベタ、裏: 信号) |
| 高周波・インピーダンスの管理 | 4 層、層構成からインピーダンスを計算(`ccad board impedance`) |

4 層は試作の値段が 2 層の 1.5〜3 倍。手配線の面は変わらないが、ベタが連続するので配線しやすく、戻りが短い。

## 5. 配線の順番

1. 大電流の経路。
2. 電源(入力 → 変換 → 出力)。
3. スイッチングノード(短く、先に決める)。
4. 高インピーダンスの検出とガード。
5. アナログ信号。
6. ロジック。
7. ベタの充填、バイパスのビア、シルク。
8. DRC。

## 6. 確認

| 項目 | いま使えること |
|---|---|
| 間隔・線幅・穴・ビア | `board drc` |
| 未配線 | `board check`、`board status` |
| 電流・電圧降下 | `board currents`、「配線の太さ」の窓 |
| 配線の抵抗を入れた動作 | `board postlayout on` のあと `dc` / `tran` |
| バイパスコンデンサの距離 | `board check`(GND 名のネットのコンデンサだけ数える。電源のネット名が普通でないときは、手で確かめる) |
| ランドが概算の部品 | `board check`(`land_unverified`) |
| 高インピーダンス線のビアなし・ガード・スイッチングノードからの距離 | **人が確認**(今後の候補: ネットの役割ごとの DRC) |
| 実機 | 既知の抵抗、ショート、開放で読みを見る |

## 7. 設計ごとの割り当て

設計ごとに、下の表を作る(短い表だけ)。数値は、その設計の要件(電流・精度・リーク・周波数)から決める。

| 役割 | ネット | 数値(線幅・間隔・距離) |
|---|---|---|
| … | … | … |

例: 作者の手元のマイクロオームメーターの設計(リポジトリの外のメモ)は、この表と、設計固有の数値(1 A、3 MΩ、1.2 MHz に合わせたもの)だけで書いてある。
