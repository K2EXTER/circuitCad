# データシートからダイオードのモデルを決める (IS・N・RS)

メーカーのデータシートには、SPICE のモデルが載っていないことが多くあります。
でも、「順方向特性 (Forward Characteristics)」のグラフがあれば、そこから読んだ数点で、実物に近いモデルを作れます。
部品作成フォームの「ダイオード」→「① 基本」→「かんたん作成」で、この手順をそのまま試せます。

## ダイオードの式

順方向の電圧 V と電流 I の関係は、次の式で近似できます。

```
V = N × 26mV × ln(I / IS) + I × RS
```

3 つの数が、曲線の形を決めます。

| 数 | 意味 | グラフでの見え方 |
|---|---|---|
| **N** (理想係数) | 電流を 10 倍にしたとき、電圧が何 mV 上がるか (約 N × 60mV) | 曲線の**傾き**。10mA と 100mA の電圧の差を読むと分かる。1〜2 ほど |
| **IS** (飽和電流) | 流れ始める電圧の高さ | 曲線の**左右の位置**。小さいほど右へ寄る。シリコンはピコアンペア、ショットキーはナノアンペア以上 |
| **RS** (直列抵抗) | 大電流での電圧の上がり | 大きい電流で、曲線が**急に立ち上がる**所 |

## 手順 (1N4007 の例)

使うデータシートの例: Diodes Incorporated「1N4001-1N4007」(秋月電子で配布されている PDF)。

1. **グラフを探す。** 「Fig. 2 Typical Forward Characteristics」が、電流 (縦軸、対数) と電圧 (横軸) のグラフです。
2. **3 点を読む。** 電流は 10 倍ずつ離して、小・中・大の 3 点 (たとえば 10mA、100mA、1A) で、曲線の電圧を読みます。
   大きい点は、定格電流 (1N4007 は 1A) に近い所にします (RS が決まります)。
3. **フォームに入れる。** 1 行に「電流 電圧」で、`10m 0.70` のように入れます。m は 1000 分の 1 です。
4. **「点から IS・N・RS を求める」を押す。** 下の絵で、点 (赤) とモデルの曲線 (青) が重なれば成功です。差が mV で出ます。
   スライダーで、自分で合わせることもできます。N を動かすと傾き、IS を動かすと左右、RS を動かすと上の方の曲がりが変わります。
5. **表から VRRM と IR を写す。** 「絶対最大定格」の Peak Repetitive Reverse Voltage (1N4007 は 1000V) と、「電気的特性」の Peak Reverse Current (25℃ で 5μA) です。
   型番ごとに列が分かれているので、**自分の型番の列**を読みます。
6. **「このモデルを ④ に入れる」を押す。** ④ のシミュレーションの欄に `.model` が入ります。「試し読み」で確かめます。
7. **保存してライブラリに追加。** 部品を置いて、DC 解析で 1A のときの電圧が、読んだ点に近いか確かめましょう。

## 高い周波数で効く値 (接合容量 Cj と逆回復時間 trr)

整流の速い切り替えやスイッチング電源では、ダイオードの容量と逆回復が効きます。データシートの数字から入れられます。

- **接合容量 Cj:** 「Typical Junction Capacitance」(1N4007 は 8〜15pF、逆電圧 4V、1MHz)。測った逆電圧もセットで入れます。モデルの CJO (電圧 0V での容量) は、`CJO = Cj × (1 + VR/VJ)^M` で求めます (VJ=0.7、M=0.5 と仮定)。逆電圧が大きいほど容量は小さくなります。
- **逆回復時間 trr:** 「Reverse Recovery Time」。測定条件の電流 (IF から IR へ切り替え) も、データシートの注にあるのでセットで入れます。モデルの TT (拡散の遷移時間) は、`TT = trr / ln(1 + IF/IR)` で求めます (目安です)。ショットキーは trr がほとんど無いので、空で構いません。
- 入れたあと、「試し読み」と AC 解析で、容量が効く周波数 (1/(2π·R·C)) を確かめられます。

## 気をつけること

- **表の Vf と、グラフは別物です。** 表の「Forward Voltage 1.0V @ 1A」は**最大値** (これ以下に収まる保証) で、グラフは**典型値**です。
  モデルは典型値で作ります。回路は、最大値のときも動くように設計します (電圧の余裕を見る)。
- **点は 2 つでも作れますが、RS は 0 になります。** 3 点以上で RS が決まります。
- **電流が近い点は使えません。** 傾きが決まらないので、10 倍ほど離してください。
- **N が 0.5〜3 から外れたら、読み取りを疑います。** 縦軸が対数目盛りであることを確かめましょう。
- **扱わないもの:** 温度による変化の細かい形、逆方向の漏れ電流の電圧依存、容量の温度変化。

## 実機で確かめよう

テスタの抵抗レンジではなく、ダイオードの電圧を実際に測って、作ったモデルと比べます (ダイオードの回路は `docs/examples/diode_iv.schjson` と同じ)。

1. 3V の電源、150Ω と 1.5kΩ の抵抗を用意します (電流は約 15mA と約 1.6mA)。
2. ダイオードの両端の電圧を測ります。抵抗の両端の電圧 ÷ 抵抗値が電流です。
3. 読み取った点 (たとえば 10mA で 0.70V) と比べます。個体差と温度で、±0.1V ほどずれます。

## 部品作成フォーム以外の使い方

- 同梱の 1N4007 のモデル (`IS=76.9p N=1.45 RS=0.042`) は、この考え方で決めたものです。
  フォームの「1N4007 の例を入れる」を押すと、同じ値が求まります。
- ショットキー (1N5819 など) は、同じ手順で IS が大きく、N が小さい値になります。
- ツェナーダイオードは、逆向きの特性 (ツェナー電圧) が主役なので、この手順の対象外です。同梱の 1N4733A のモデルを例にしてください。
