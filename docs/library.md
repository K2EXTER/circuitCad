# 同梱のライブラリ部品

初回起動時(と、新しい部品が増えた更新のあと)に、`%APPDATA%\circuitCad\library` へコピーされます。
削除した部品は復活しません。自分で編集した部品は上書きされません。
(手を加えていない旧版の部品は、新しい版に更新されます。)

**どの部品も、ピン表・ランドパターン寸法・シミュレーションモデルの数値は概算です。**
設計に使う前に、必ずメーカーのデータシートで確認してください。

## モデルでできること・できないこと

- **MOSFET**: レベル1(Shichman-Hodges)。しきい値 `VTO`、`KP`(W/L込み)、`LAMBDA`、ゲート容量 `CGS` / `CGD`(一定値)。
  基板効果・容量の電圧依存・飽和速度は扱いません。大電流では、実際より電流が大きく出ます。
- **ダイオード**: `IS` `N` `RS` に加えて、降伏 `BV` / `IBV`(`-BV` で逆電流が `IBV`)を扱います。接合容量・逆回復は扱いません。
- **オペアンプ**: 開ループ利得と1次の極(GBW)、入力抵抗、出力抵抗、出力の振れ幅(電源からの余裕)。
  出力は高精度に電源の範囲に制限されます。電源ピンをつながないと出力は0Vに張り付きます。
  オフセット・スルーレート・入力バイアス電流・電源電流・位相余裕の詳細は扱いません。
- **レギュレータ**: 出力電圧、ドロップアウト(入力が低いと出力が追従して下がる)、出力抵抗、負荷電流が入力電流になること。
  リップル除去・過渡応答・静止電流・過電流保護・熱は扱いません。

- **ロジックIC (74HC)**: 入力のしきい値は電源電圧の半分(74HC14 はヒステリシスつき)で、2〜6V で動きます。
  出力は、High 側が約 80Ω、Low 側が約 40Ω の抵抗を通して電源・GND につながります(スイッチ素子 `S` で作った簡易モデル)。
  入力には電流が流れません。使わない入力は GND か電源につないでください (つながないと 0V として扱い、警告が出ます)。
  **伝搬遅延・入力容量・電源電流・ホールド/セットアップ時間は扱いません。** そのため、インバータをリング状につないだ発振器は動きません
  (遅延がないと発振しない)。発振させたいときは、シュミットトリガ (74HC14) と抵抗・コンデンサを使います。
  発振回路は、電源を `PWL(0 0 2m 5)` のように立ち上げると確実に始動します (電源を最初から 5V にすると、DC動作点が不安定な釣り合い点になって止まったままになることがあります)。

## 同じピン番号のパッドが複数あるパッケージ

SOT-223 のタブのように、同じ部品の同じピン番号のパッドが複数ある場合は、基板上でも1つの接続として扱います。
回路図から取り込むと、すべてのパッドに同じネットが付き、ラッツネスト(未配線の線)も要求されません。
