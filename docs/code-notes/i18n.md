# 英語の画面 (`crates/i18n`)

画面の文字の英訳。日本語の文はコードにそのまま残し、それを鍵にした表 `crates/i18n/en/*.tsv` で英語にする(gettext と同じ考え方)。

## 仕組み
- 言語は全体で1つ(`i18n::set_lang`)。既定は日本語で、日本語のときは何も変わらない。
- 決め方: 起動引数 `--lang en` → 環境変数 `CCAD_LANG` → 設定ファイル `settings.json` の `"lang"`。メニュー「設定」→「Language / 言語」で切り替えると、すぐ変わり、保存もされる。
- `i18n::tr("…")`: 決まった文。表に無ければ日本語のまま。
- `i18n::trf!("…{n}…", …)`: `format!` と同じ書き方。表の鍵は format 文字列そのもの。英語の側も同じ置き場所(`{n}` `{:.2}` `{}`)を使う。並びを変えたいときは `{@2}` (日本語の2番目の置き場所)。
- `i18n::tr_dyn(&text)`: どこかで作られた文(ERC・DRCの指摘、ステータス行、解析の警告)。まず完全一致で探し、無ければ置き場所のある鍵すべてと突き合わせる(固定の文字の長い鍵から。固定の文字が2文字未満の鍵は使わない)。結果は覚えておく。複数行の文は、行ごとに訳せるときだけ訳す。core クレートの `format!` は変えずに済む。
- 置き場所に入った値も、表にあれば訳す(「抵抗」→ "resistor" など)。
- `{}{}` のように置き場所が隣り合う鍵は、文字だけでは分けられない。英語の側でも同じ順に隣り合っていれば、ひとまとめの置き場所として扱う。
- `tr_dyn` は、前に記号の付いた文(`⚠ ① 基本`)を、記号を残して後ろだけ訳す。
- 同じ日本語でも場所で英語が変わる語は `i18n::tr_ctx("回路図", "配線")` と書き、表 `context.tsv` に `回路図|配線<TAB>Wire` を置く(無ければふつうの訳)。
- 英語のときは、ラテン文字を比例幅のフォント(Windows は Segoe UI)で描く(`startup.rs install_japanese_font`。言語を切り替えると入れ直す)。
- 共通の部品(`widgets.rs`・`icons.rs` のボタン・見出し・(?)・タブ・警告の行)は中で `tr_dyn` を通すので、呼ぶ側は日本語のままでよい。

## 表の書き方 (`crates/i18n/en/*.tsv`)
- 1行に `日本語<TAB>English`。`\n` `\t` `\\` は改行・タブ・バックスラッシュ。`#` で始まる行は注記(どのファイルの文かを書いておく)。
- 英語が空の行は「まだ訳していない」。ファイルを足すとビルドが自動で拾う(`build.rs`)。
- `cargo test -p i18n` が、置き場所の食い違いと、同じ日本語に別の英語がついていないかを調べる。

## 道具 (`tools/i18n.py`)
- `wrap crates/app/src`: egui に渡す日本語(`label` `button` `on_hover_text` … の引数、そこに直接渡す `format!`、`if`/`match` の枝)を `tr` / `trf!` で包む。何度かけても同じ。新しい画面を書いたらかけ直す。
- `todo OUT.tsv crates/app/src …`: まだ英語のない鍵を、表の行の形で書き出す。
- `stats crates/app/src`: ファイルごとの訳の進み具合。
- `terms OUT.tsv`: 用語の辞書 (訳済みのボタン・メニュー・タブ・用語集の名前)。長い文を訳すときに、名前の訳をそろえるために使う。
- 実際に画面に出たのに訳の無かった文は、`CCAD_I18N_MISSING=<ファイル>` を付けて起動すると、終了時にそのファイルへ書き出される(`--lang en --screenshot` と組み合わせると画面ごとに調べられる)。変数を渡している表示(`ui.label(&x)` など)は `wrap` が包まないので、そこは手で `tr_dyn` を通す。

## 段階
1. 第1段: メニュー・ボタン・ホバー説明・パネル・エラー・ERC/DRC の指摘(`crates/app/src` のうち下の2・3以外と、`sch-core`・`pcb-core`)。
2. 第2段 (済): F1 ガイド `help.rs`、用語集 `glossary.rs` (英語のときは英語名の ABC 順に並べ、英語名でも探せる。読みと日本語の別名は出さない)、豆知識 `tips.rs`、サンプルの説明 `samples.rs`、学習パスの窓と7本の道すじ `learn/`、`sim-core` (解析の警告・値の決め方の手順)・`part-lib`・`datasheet`・`design-spec` の文。
3. 第3段: 残りのレッスン・チャレンジ・学習パス・実機の案内。
レッスンの中で出てくる用語は、`python tools/i18n.py terms OUT.tsv` で作る「用語の辞書」(訳済みの短い名前 約2,300) を訳す人に渡してそろえる。

## 訳し方の決まり
- 初学者向けの、やさしく短い英語。ボタンとメニューは短く(sentence case: "Open project…")、説明文は普通の文。
- 「」は "…"(二重引用符)にする。全角の括弧・記号は半角に。`…` はそのまま残す。
- 置き場所 `{…}`、キーの名前(Ctrl+Z, F1)、単位、ファイルの拡張子、`--option`、製品名(KiCad, JLCPCB, ngspice)はそのまま。
- 画面に出ない文(ファイルの中身・照合用の語・正規表現・内部の名前)は訳さない(英語を空のままにする)。
