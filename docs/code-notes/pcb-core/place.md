# pcb-core: 自動配置・コピー(繰り返し構造)・向き・入れ替え・GND ベタ

(`docs/code-notes/pcb-core.md` の目次から分けた。内容は元のまま)

- `autoplace.rs` 自動配置(`autoplace(board)`)。
  - 部品を、ピンの多いものから、つながりの強いもの順に並べ(部品どうしのつながりの表 `tie` を、ネットの一覧から一度だけ作り、点数を足し込みながら選ぶ。73部品で1.1秒→数ミリ秒)、段(行)に詰める(`pack`)。
  - そのあと、順番の入れ替え・移動を焼きなましで繰り返して、ネットごとの外接矩形の長さ(HPWL。ピンの多いネットは `1/(ピン数-1)` の重み)の合計が短い順番を探す(`improve_order`。乱数は固定で、同じ基板は毎回同じ結果。`4000〜60000` 手)。
  - もう1つの配置 `attach_layout`: 段をやめて、同じ並び順で1つずつ自由な位置に置く(すでに置いた部品のパッドに自分のピンが重なる位置が理想で、0.5mm格子の重ならない近い所から、候補12か所のうちネットが最短になる所を選ぶ。置いた部品の真ん中へ寄せる力 `PULL`=0.1。ICの周りにつながる部品が集まる)。
  - 段+焼きなましと `spots_cost` を比べて、ネットが短いほうを採る。
  - そのあと半回転で未配線が短くなる部品を回す(`turn_to_shorten`)。
  - ベタが先にある基板(`zones` にネットのあるゾーン): `Tuning::for_board` が、ベタのあるネット(GND)を配置の計算(`nets`・`tie`・`degree`)から外し(配線が要らないので部品を引き寄せない)、隙間を `POURED_GAP`=1.2mm・ラベル欄を `POURED_LABEL`=1.6mm に詰める(`PlaceReport.poured` に外したネット名)。
  - 同梱サンプル43個に表面GNDベタを置いて自動配置→自動配線すると(2.4/2.4でベタを無視しない場合と比べ)、占有面積 -23%・配線長 -27%・ビア 37→23 で、全部の接続が通りDRC違反0(隙間と欄の組を総当たりで測った。1.0/1.6は面積 -29% だが部品が近すぎて手はんだしにくい)。
  - 総合デモの手動配置(配線 368mm・ビア3)に対し、旧い自動配置は 557mm・ビア6、これは 379mm・ビア5。
  - 配置のあと、基板全体を覆っていたベタ(長方形で、旧い外形から0〜2mm内側)は新しい外形に同じ余白で合わせ直す(`refit_pours`。ほかの形のベタはそのまま)。
  - `autoplace_with(board,&Tuning)` で数値を指定できる。
  - バイパスコンデンサ(`Tuning.bypass`、既定オン): `C` 部品の一方のパッドが電源ネット(`drc::is_supply_net`)・もう一方がGNDで、同じ電源ネットに5パッド以上の `U` 部品のパッドがあるとき、そのコンデンサのパッドとICの電源パッドを結ぶ2点のネットを3本ぶん足す(`bypass_nets`。`is_supply_net`/`is_ground_net` は `drc` の公開関数で、`V5`・`V12`・`V3V3` も電源とみなす。配置はネットの長さの和を縮めるので、普通の接続の3倍の力で寄せる)。
  - IC 2個+コンデンサ2個の試験で、コンデンサのパッドから電源ピンまでの距離は、引き寄せ無しで約20mm・有りで約5mm(`tests` の `bypass_capacitors_sit_by_their_ic_supply_pin`、`drc::decoupling_checks` の上限8mm内)。
  - 同梱サンプルにはバイパスコンデンサが無いので、サンプルの配置は変わらない。
  - 総合デモの手動配置(整列の指標: x 37/41・y 34/41・同じ部品の向き 28/41)に対し、回路図から「ベタ→配置」した結果は x 36・y 37・向き 31 と、同じくらい整っている。
  - 「GND ベタ」(`groundpour`)を置いたあとの基板も並べ直せる: トラックとビアが全部ベタのあるネットのもの(`pour_wiring`。`drc::connectivity` のネットで判定)なら、それを外して並べ、並べたあとに `ground_pour` で同じ線幅・ビアの大きさで置き直す(`PlaceReport.repoured`)。
  - ほかの配線があれば断り、途中で失敗しても基板は元のまま(`place` が複製を持つ)。
  - 配置のあと `align_parts`(`Tuning.align`、既定オン): 中心の y(行)・x(列)が `ALIGN_TOL`=2.0mm 以内の部品を、真ん中の部品の線に `SNAP`(0.5mm)単位で寄せる(ほかの部品の端パッド枠まで `ALIGN_SPACE`=0.9mm を保てない動きはしない=`crowded`)。
  - 全部まとめて、未配線の長さが1%(+0.5mm)を超えて伸びる・DRC違反が増えるなら元に戻す。
  - 43サンプル+総合デモで、中心の行が 17/41→40/41(手動 25)・列 21→25/41(手動 34)、配線長 1751→1737mm・ビア 23→22(全接続・DRC違反0)。
  - 部品の隙間 `GAP`=2.4mm(ベタが無い基板)(同梱サンプルを自動配置→自動配線して、未配線の合計が最小だった値。1.6→8、2.0→6、2.4→2、3.0→3)。
  - `tests_quality.rs` は73部品のLED基板(`large_led_board`、`--ignored --release`)で、配置・配線の時間と未配線・ビア・配線長・斜めの段差を測る(LEDは `K`/`A`、抵抗は `1`/`2` のピン名で結ぶこと。LEDをつなぎ間違えると未接続になり、成績が実際より良く出る)。
  - 132本の未配線で、段+焼きなましは5本、IC中心の配置は1〜3本が通らない(LED基板をつなぎ間違えていた間の数字は無効)。
  - 同梱サンプル40個では未配線0、面積 +3.7%、配線長 -5%、ビア 73→57。
- `nudge.rs` 全部配線したあとに残った接続の近くの小さい部品を動かして引き直す(`route_with_nudging`。1〜4 mm の 24 通り × 近くの 8 部品を、スレッドで並べて試す。ベタのネットは足の短い線とビアだけ消してベタに付け直す。時間の予算つき。画面は「通らない接続を通す」ボタン=`BoardEditor::nudge_parts`、最長 40 秒)。ルーターの格子は `RouteOptions.grid`(0.5 mm ピッチの IC の足の間は 0.1 mm が要る)。
- `groundpour.rs` GNDベタ(`ground_pour(board, opt)`)。 `PourOptions.side` でベタの層を選べる(`Side::Bottom` が既定、4 層以上なら `Side::Inner(n)`。表面のパッドごとにビアを置くのは同じ。CLI は `board layers N` と `board pour layer=inner1`)。内層のベタを引き取る `ground_pour` は、`top` の表面ベタは裏のときだけ。
  - 四角い外形の裏面に、外形の `edge_clearance+0.2`mm内側のゾーン(`remove_islands`)を置き、表面のSMDのGNDパッドごとに、パッドの中心から縦横にまっすぐな短い線(既定0.3mm幅)とビア(0.6/0.3)を、近い順(0.25mm刻み、5mmまで)にDRCが悪くならない所へ置く。
  - スルーホールと裏面のパッドはゾーンに直接つながる(`connectivity` はゾーンの内側に点がある同じ側のものをつなぐ)。
  - もう置いてあれば何もしない。
  - `PourOptions.top`(既定true。自動配置の置き直しは false)なら、`ground_pour` はビアの前に `top_pour` で表面も埋める。
  - 表面のGNDパッドはそのベタの上なので、パッドごとのビアは要らず、表裏をつなぐ道(スルーホールのGNDパッドか、ビア1個)だけ置く(表面が置けなければ、パッドごとのビア)。
  - `top_pour(board, net)` は(配線のあとにも使え)、表面の空いた所も同じネットのゾーン(`remove_islands`)で埋める(配線とは隙間があくので配線は変わらない。DRCの指摘かそのネットの未配線が増えるなら置かず、理由を返す。ゾーンがもうあれば `Ok(false)`)。
  - エディタの自動配線は、裏面にGNDベタがあれば、チェック「表面も GND のベタで埋める」(既定オン)のとき、配線のあとに呼ぶ。
  - CLIは `route` が同じことをし(`top_pour`、`top=0` で切る)。
  - GUIは `board_editor/actions.rs` の `ground_pour` と「② 配線」の「GND ベタ」。
  - 同梱サンプル40個で、自動配置→ベタ→自動配線すると、未配線0・DRC違反0(仕上げ後も)、GNDの配線は合計1145→91mm、ビアは57→119個。
  - ゾーンはパッドをつなぐ判定だけで、ベタが配線で分かれた島の連続性までは見ない(`connectivity` の仕様)。
- `footprints.rs` の `CT_3528-21`: モールドタンタル B ケースの形(KEMET T491 のデータシート 表 2 の Level B: パッド 1.80×2.23 mm・すき間 1.12 mm)。1 番ピンが +(左)で、シルクに + 側の縦線と「+」を描く(外形 `outline`)。ライブラリ部品 `T491B226K016AT`(KEMET、22µF・16V・ESR 最大 2.2Ω。LDO の出力コンデンサ向き)が使う。
- `shops.rs` の予備: チップ部品(フットプリントが `R_`・`C_`・`L_`・`LED`・`FB_` で始まり4桁の大きさ表記を持つもの)は `Line::spare` が「2個か全体の1割の多いほう」を足す。IC・コネクタ・リード付きには足さない(経験則であって、データシートの値ではない)。CSV の列は `Qty`(必要数)・`Spare`・`Buy`(合計)。アプリの「発注の準備」の窓の最後の「部品の購入リスト」(`board_editor/order.rs shopping_list`。枚数と予備の入れ切り、店のボタン=型番があればその店のページ・無ければ検索ページ、CSV保存)と `ccad board shopping` が使う。
- `swap.rs` ゲート・入力の入れ替え。74HC32 のように同じゲートが並ぶ IC(部品 JSON の `swap`: `gates`=同じゲートのピン列、`inputs`=ゲートの中で入れ替えられる入力の位置)は、ゲートの割り当てを変えても回路が同じ。取り込みで `Board.swap_specs` に入り(`netlist::import_swaps`)、`swap::run(board, dry)` が、パッドに配線もビアも付いていないゲートだけを対象に、未配線の長さ + 3mm × 交差数(`CROSSING_COST`)がいちばん小さい割り当てを探す(ゲート 6 個までは全部の順番、それより多いときは 2 個ずつの入れ替え。そのあと入力の入れ替えを 1 個ずつ。最大 4 周)。ベタのネットに乗るゲートと、ネットのないゲートは動かさない。結果はパッドのネットを入れ替え、`Board.pin_map`(パッドのピン→そのパッドがネットを受け取った回路図のピン)に覚える。`netlist::import` は `pin_map` のとおりにネットを付け、`diff` も入れ替えを「違い」に数えない。回路図は、そのままでは変えない(「入れ替えを回路図に反映」= CLI `board backannotate` で、`sch-core/backannotate.rs` の `apply_pin_trades` が、回路図の配線の端とネットラベルを入れ替えたピンへ動かし、反映した部品の `pin_map` を消す)。CLI は `board swap [dry=1]`、アプリは「ゲートを入れ替えて交差を減らす」。テスト `swap.rs`・`netlist.rs` の `a_traded_pin_keeps_its_trade_through_a_new_import`
- 74HC のゲート類の入れ替えの規則は、部品 JSON の `swap` のほか、部品名から決める組み込みの表(`part-lib` の `swap_for`)も持つ(ライブラリのコピーが古くても使える)。
- `orient.rs` 部品の向き(0/90/180/270°)の最適化。配線もビアも付いていない・ロックしていない部品ごとに、ほかの向きを試し(ほかの部品は動かさない)、未配線の長さ + 3mm × 交差(`swap.rs` と同じ物差し)がいちばん小さい向きを取る(0.5mm 以上の得があるときだけ。2 周。1 個回すごとに未配線を計算し直す)。ピンのネットは変わらないので回路は同じ。パッドが基板の外・ほかの部品のパッド・配線・ビア・穴にぶつかる向き、ほかの部品の本体(パッドとシルクの外接矩形)に新しく重なる向きは選ばない。CLI は `board orient [dry=1] [parts=U1,U2] [minpads=3]`、アプリは左パネルの「部品の向きを最適化」。**自動配置のあとに使っても得はほとんど無い**: 同梱 66 サンプル(`arduino_mega_usb` を除く)を「ベタ→配置→(向き)→配線」で比べて、全部の部品で配線長 2823→2827mm・ビア 55→61、4 パッド以上の部品だけで 2823→2823mm・ビア 55→56(DRC・未配線は 0 のまま)。自動配置がすでに向きを決めているため。手で並べた基板の、配線の前の相談役(`dry=1`)として使う。マイクロオームメーターの基板(配線の付いていない部品 15 個)で、3 個(CP2・CN2・CL3)を回すと未配線が少し減る。テスト `orient.rs`
- シートごとの塊の配置(`autoplace.rs` の `sheet_blocks`。`Tuning.sheets`、**既定オフ**(2026-10-27 に、マイクロオームメーターで従来の並べ方より面積 +37%・配線 +13% になるのでオフにした)。シートが 2 つ以上あるときだけ働く。`Board.part_sheets` から `sheet_groups` が部品を分ける。シートの無い部品は 1 つの群): シートごとに、そのシートの中のネットだけで、これまでと同じ順(足の多い部品から、つながりの強い順 → 入れ替えの焼きなまし)で詰めて長方形の塊にし(`layout(..., compact=true)`: 自由配置の `attach_layout` は使わない)、塊どうしを、シートをまたぐネット(シートごとにそのシートのピンの真ん中に 1 ピン)で同じ `layout` にかけて並べる。塊のまわりに `BLOCK_GAP`=2mm。`layout` は、これまでの 1 回の並べ方を関数にしたもので、1 シートの回路は結果が変わらない(テスト)。CLI は `board autoplace sheets=1` で塊(`arrays=0` で格子を使わない)、アプリは左パネルの「シートごとに塊にして並べる」。マイクロオームメーターの回路(6 シート・191 部品)を「ベタ→配置→配線」で比べると、従来 96×85 mm・交差 469・配線長 3500mm・ビア 299・通らない接続 12 本に対し、塊は 110×102 mm・交差 561・配線長 3774mm・ビア 213・通らない接続 22 本。見分けやすさと引き換えに、面積と配線が増える。テスト `the_parts_of_a_sheet_stay_together_in_a_block_of_their_own`
- バイパスコンデンサの引き寄せ(`bypass_nets`)は、片側が電源(正・負)のパッドで、反対側がほかのレール(GND・電源・負電源)のコンデンサを対象にする(以前は「電源と GND」だけで、IC の 0V が負電源の回路の VCC–VNEG のコンデンサが引き寄せられなかった)。電源の両側のパッドが、それぞれ同じネットの IC のパッドへ引かれる(DIP-14 の 2 つの電源ピンは 15mm 離れているので、コンデンサは間に落ちる)。マイクロオームメーターの自動配置で、電源ピンから一番近いコンデンサまでの距離の中央値 7.9→5.1mm(シートなしの並べ方で 3.3mm。手動の配置は 2.8mm)、8mm より遠い電源ピン 10→2 か所。テスト `a_capacitor_between_two_supplies_is_pulled_to_the_ic_that_runs_between_them`
- 繰り返し構造の配置(`replicas.rs` の `find` と `autoplace.rs` の `build_arrays`・`collapse`。`Tuning.arrays`、既定オン): ピンが 8 個以上の部品(IC・ヘッダ)と、6 個より多い部品につながるネット(GND・電源・バス)を外し、残りの小さな部品を「同じシートの、ほかの部品と専用のネットでつながるもの」ごとのグループ(2〜12 個)にする。2 回の細かい分類(部品の種類=識別子の英字+ピン数、各ピンが何につながるか)で同じ構造のグループを「コピー」とみなす(値と footprint は違ってよい。ミリオームメーターのレンジは抵抗・コンデンサの値が違う)。最初のコピーを小さな回路として並べ(`layout(compact)`。役ごとの場所は、全コピーの中で一番大きな部品に合わせ、格子の 0.5mm の整数倍に切り上げる)、全コピーに同じ並べ方を使い、識別子の番号順に、全体が 3:2 くらいになる列数の格子に並べる。配列は 1 つの項目として配置の問題に入れ(`collapse`)、並べたあと部品に戻す。配列の部品は、半回転(`turn_to_shorten`)と整列(`align_parts`)から外す。ミリオームメーターで、レンジ 4〜8(CF・DL・RL・RS・SC・SS・SW の 7 個)が 5 組、LED と抵抗が 4 組、入力フィルタが 2 組見つかる。テスト `copies_of_a_structure_are_laid_out_alike_in_a_regular_grid`・`replicas.rs`(`print_the_copies_of_a_real_board` は実物の基板で見る用の `--ignored`)
- シートごとの塊の並べ(`sheet_blocks`)の、塊を並べる `layout(..., fit=true)`: 塊の数が 7 個以下なら全部の順番と 7 通りの幅(行の幅 × 0.5〜1.5)で棚詰めを試し、面積(縦横比が 1.8 を超えると罰)+ 0.4 × ネットの長さがいちばん小さいものを採る(以前は 1 つの幅で焼きなましだけだったので、ミリオームメーターは 92×142mm と縦長になった)。塊の中は従来のまま。結果 106×100mm(基板 113×106mm)。
- コピーの検出で、IC(アンカー)のピンにつながるネットは、コピーの中のつながりに使わない(ポート扱い)。ミリオームメーターで、LED と抵抗が 10 組・コンデンサと FET が 8 組・抵抗とスイッチ 2 個が 6+2 組に分かれて見つかる(以前は、IC の出力のネット GN をたどって、レンジ回路と LED が 1 つの 7 個のグループにつながり、LED は 4 組だけ見つかっていた)。基板 99×88mm・電源ピンのコンデンサまで中央値 3.4mm・自動配線で通らない接続 18 本。
- コピーの向きの最適化(`autoplace.rs` の `turn_copies`・`template_cost`。`improve` と `Tuning.arrays` のとき、部品を並べる前に働く): コピーの組ごとに、最初のコピーの部品だけを専用の小さな基板に取り出し(部品どうしをつなぐネットだけ。外へのネットは外す)、部品ごとに 4 つの向きを 1 つずつ(2 周)試す。向きごとに、同じ並べ方(`layout(compact)`)で並べて実際に自動配線し(`layers=outer` 相当)、配線の長さ + ビア × 10 + 通らない接続 × 200 + 面積 × 0.05 の小さいものを採る。採った向きを役ごとに全コピーへ適用する(位置はこの段階では動かさない)。ミリオームメーターで、通らない接続 18→14 本・配線 3894→3827mm・ビア 266→304・折れ 963→1041(基板 99×88→97×89mm)。外へのつながり(ポート)の向きは評価に入っていない。
- コピーの外へのつながり(ポート)に向きを合わせる(`autoplace.rs` の `turn_copies_toward_ports`・`turn_about_centre`。`improve` と `Tuning.arrays` のとき、配置・半回転のあとに働く): コピーの組ごとに、役(コピーの中の同じ位置の部品)ごとに、3 つの回し方(90°・180°・270°)を、全コピーいっしょに試す(パッドの箱の中心を保つ)。盤全体の未配線の長さが 0.5mm 以上短くなり、回した部品がほかの部品に近づきすぎない(`crowded`)いちばん良い回し方を採る。IC に行くピンを IC の側へ向ける、など。`turn_copies`(小さな基板で単独に配線して向きを決める)が、コピーの中だけを見るのを補う。ミリオームメーターで、配置後の未配線の交差 685→625(−9%)、自動配線の結果(はしごあり)は通らない接続 12 本・ビア 270。テスト `the_role_of_a_part_in_every_copy_is_turned_to_face_what_it_is_joined_to`
- バイパスコンデンサを IC の電源ピンのそばに置き直す(`autoplace.rs` の `attach_bypass_caps`。`Tuning.bypass` と `improve` のとき、整列のあとに働く。`BYPASS_NEAR`=2.5mm、`BYPASS_REACH`=6mm、`BYPASS_STEP`=1mm): 電源(正・負)のパッドと、反対側にほかのレールのパッドを持つコンデンサのうち、IC の同じネットのピンから 2.5mm より遠いものを、ピンから 6mm 以内の 1mm 格子の場所と 4 つの向きの中から、「電源のパッドからピンまでの距離 + 0.5 × 反対側のパッドから、IC のもう一方のレールのピンまでの距離」がいちばん小さく、ほかの部品のパッドの箱から 0.9mm 以上離れ、配置した範囲の中にある所へ動かす(今より 1mm 以上良くならなければ動かさない。コピーの格子の部品は動かさない)。ミリオームメーターで、電源ピンから 8mm より遠いコンデンサ 4→0 か所・距離の中央値 3.5→2.3mm・配置後の交差 625→611。テスト `a_bypass_capacitor_left_far_from_its_ic_is_moved_to_the_supply_pin`
- IC どうしの結びつき(`autoplace.rs` の `ic_pair_nets`。`Tuning.arrays` のとき): ピンが 8 個以上の IC(`U`)の組が、パッド 8 個以下のネットを共有するとき、各 IC のそのネットのパッド 1 つずつの 2 ピンのネットを 2 本足す(共有するネットが多いほど近づける力が強い。以前は、6 つの部品がつながる GN などの重み 1/(ピン数−1) が小さく、5 本を共有する UC1 と UC3 が、UC2 を挟んで 27mm 離れていた)。ミリオームメーターで UC1–UC3 27→8.5mm・配置後の交差 611→552・通らない接続 15→13 本。
- シートの塊(`sheets=1`)の再測定(同じ回路、現在のコード): 95×149mm(縦長)・交差 569・通らない接続 7 本・配線 4251mm・ビア 250 / 塊なし 96×95mm・552・13 本・3804mm・281。塊のほうが通りやすいが、縦長になって面積が +49%。縦横比を直すのが次の課題。
- IC とそのバイパスコンデンサを 1 つの塊にして確定する(`autoplace.rs` の `ic_blocks`・`IcBlock`。`Tuning.bypass` と `arrays` と `improve` のとき。コピーの向きの最適化のあと、部品を測る前に働く): ピンが 8 個以上の IC(`U`、コピーの部品を除く)ごとに、それに属するバイパスコンデンサ(電源・負電源のパッドを IC の同じネットのピンに持ち、反対側がほかのレール)を決める(両方のネットを持つ IC を優先、次に、コンデンサの少ない IC)。IC とそのコンデンサだけの小さな基板で、コンデンサを 1 つずつ、IC の電源ピンから 6mm 以内の 1mm 格子の場所と 4 つの向きから、`attach_bypass_caps` と同じ評価(電源のパッド→ピンの距離 + 0.5 × 反対側のパッド→IC のもう一方のレールのピンの距離)がいちばん小さく、IC と先に置いたコンデンサのパッドの箱から 0.9mm 以上離れる所に置く。コンデンサの向きを本物の基板に反映してから部品を測り、IC とコンデンサのセルの角を、コピーの格子と同じ `Array` にして(`collapse`)1 つの項目として並べる(以降の半回転・整列・コンデンサの置き直しから外す)。ミリオームメーターで、配置後の交差 552→468(−15%)・電源ピンから 8mm より遠いコンデンサ 0 か所(距離の中央値 2.0mm)・自動配線(はしごあり)の結果が、通らない接続 11 本・配線 3570mm・ビア 246・折れ 991(前は 13 本・3804mm・281・1048)。Arduino レッスンのテストと説明は、自動配置がバイパスコンデンサをピンのそばに置くようになったので、「確かめる」形に直した。
- 樹形図(接続の強さによる階層的クラスタリング + スライス型の配置)も試した: 部品 135 項目で、箱が部品の面積の合計の 3.5〜4 倍(160×101mm〜187×120mm、いまの並べ方は 90×89mm)・ネットの長さが 2〜3 倍になり、採用されない。木の形(切り方)を接続の強さだけで決めると、大きさのばらばらな部品はすき間だらけになる。実装は戻した。
- 樹形図(階層的クラスタリング + スライス配置)を、シートの塊の中(塊の項目は 8〜26 個)の候補にも試した(2026-10-28): 塊の中の箱は、いまの並べ方と同程度か大きく、ネットの長さは 5〜40% 長い。シートの塊(`sheets=1`)で全体を通すと、樹形図あり 128×91mm・交差 631・配線 4385mm / なし 130×91mm・550・4275mm と悪くなるので採らない(実装は戻した)。同じ条件の `sheets=1` は、塊の縦長は直り(IC とコンデンサの塊・コピーの格子が項目になり、横長の 130×91mm)、通らない接続 9 本だが、`sheets=0`(99×93mm・配線 3570mm・通らない接続 11 本)より面積 +27%・配線 +20%。
- IC の衛星(`ic_blocks`、`SATELLITE_PADS`=3): 1 つの IC だけにつながり(ハブでないネットで、ほかの IC・ヘッダに会わない)、パッドが 3 個以下の小さな部品(コンデンサ以外の抵抗など)も、IC とバイパスコンデンサの塊に入れる。塊の中では、つながるピンのそばに、バイパスコンデンサと同じ方法で置く。ミリオームメーターで、通常 84×94mm(前 99×93)・通らない接続 11→8 本・配線 3570→3732mm・ビア 246→276、シートの塊 90×120mm・8 本。同梱サンプルは、面積 −0.9%・配線 +9%・問題 0。
- チャネル(`replicas::merge_channels`、`Tuning.channels`、**既定オフ**、CLI `board autoplace channels=1`): コピーの組(CF+SC、RS+SS+SW、DL+RL など)の、コピー k どうしが、少数の部品につながるネット(IC の出力のネットを含む)でつながるとき、それを 1 つの大きなコピー(レンジ 1 つぶん)にして、同じ構成のものを同じ並べ方で格子に並べる。一部のコピーしか塊に入らないグループ(LED 10 組のうち、レンジにつながる 5 組)は、塊から外して、グループを割らない(入っている割合がいちばん小さいグループから外し、残りで作り直す)。ミリオームメーターで、LED の 5 組を塊に入れると(割れる)配線 3139mm(−16%)・基板 75×113mm だが、LED を割らないと、チャネルの塊(5 部品 6+2 組)が配線 4178mm・基板 88×107mm・通らない接続 13 本と、使わないより悪い。LED を割らない A(オフ)が既定: 84×94mm・3732mm・8 本。
- シートの塊の箱詰め(`autoplace.rs` の `nest_blocks`・`Cells`。`sheet_blocks` が `improve` のときに使う): 塊の中は、中心の部品から育てる自由配置か行詰めのうちネットが短いほう(`layout(compact=false)`。以前は行詰めだけ)。塊の形は、部品のセルの四角を、まわりの余白(`BLOCK_GAP`)ぶん広げて 1mm(`NEST_PIXEL`)の格子に展開したもの。塊を 1 つずつ、すでにあるものに重ならない場所のうち、全体の箱(縦横比 1.8 を超えると罰)と、塊の間のネットの長さ(`BLOCK_NET_WEIGHT`)の点数が一番良い所(3 マスおき=`NEST_STEP`)に置く。順番は、面積の大きい順と 12 通りのランダム(`NEST_ORDERS`)から一番良いもの。ほかの塊の凹みに入りこめる。ミリオームメーターで、`sheets=1`: 127×86mm・交差 473・通らない接続 5 本・配線 3566mm・ビア 234・折れ 895(以前の長方形の塊: 90×120mm・714・8 本・4135mm・264・1044、通常: 84×94mm・470・8 本・3732mm・276・1017)。配線の成績は一番良いが、基板は通常より 38% 大きい(中央下・左上に空きが残る)。テスト `blocks_are_nested_as_the_shapes_they_are`
- バイパスコンデンサは、IC の信号ピンの出口をふさがない(`autoplace.rs` の `escape_zones`・`in_zones`。外周の信号ピンの前に、ピンの幅で `ESCAPE_LEN`=1.8 mm の帯を空け、`ic_blocks` と `attach_bypass_caps` の1回目の探索でそこを避ける。置き場がなければ2回目で外す)。ミリオームメーターの ADC(0.5 mm ピッチの QFN)で、シート別の配置の通らない接続が 5 → 3 本、同梱サンプル 67 件の `problems` は 24 → 19(`arduino_mega_usb` だけが残る)、面積 +2.5%・配線長 +2.7%。
- シート別の箱詰め(`nest_blocks`)は、並べたあとに全部の塊を左と上へ詰め直す(置く場所を `NEST_STEP` ごとに探すので、すき間が残るため)。ミリオームメーターで 127×86 → 97×104 mm(面積 −7.6%)、未配線 5 → 3、配線長 3599 → 3573 mm、交差 403。塊の左右・上下の反転(`NEST_MIRRORS`、既定 1=反転なし)も試したが、シート間のネットが長くなり(交差 403 → 638、未配線 9)不採用。順番を試す回数(`NEST_ORDERS`)を 12 → 40 にしても結果は同じ。
- `align.rs` 選んだ部品の整列(左右上下・中心・等間隔)。`autoplace.rs` の配置のあとの整列とベタ先の配置も
- `connectors.rs` 自動配置の最後に、ピンヘッダの向きと位置を決めて未配線の交差を減らす
- `orient.rs` 部品の向き(0/90/180/270°)を、未配線の長さと交差が最小になるように決める(配線の付いていない部品だけ。`ccad board orient`、パネルのボタン)
- `swap.rs` 同じゲート・同じ入力のネットの入れ替え(配置のあと、未配線の長さと交差を減らす。`ccad board swap`、パネルのボタン)
