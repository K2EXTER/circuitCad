# 試作のタブとブレッドボード (B6 ①、`app/src/breadboard/`・`sch-core/breadboard.rs`)

一番上のタブの 2 つ目「試作」(`main.rs` の `Mode::Proto`)。回路図 → 試作 → 基板パターン → 実機 の順。回路図の部品を、はんだ不要のブレッドボードのどの穴に差すかを並べて描く。

## データ (`sch_core::breadboard`)

- 穴 `Hole`: `Strip { col, row }`(row 0..5 = a〜e、5..10 = f〜j)か `Rail { rail, col }`(`TopPlus`・`TopMinus`・`BottomMinus`・`BottomPlus`)。名前は基板の印刷どおり (`a12`・`上+5`)。
- 中のつながり `Node`: 列ごとに上半分と下半分 (5 穴ずつ)、レールは全長。
- `Layout`: 部品ごとの足の穴 (`Placed`、見た目 `Look` = 2 本足・IC・1 列)、ジャンパー線 (`Wire`)、ブレッドボードの外の電源・電池・信号源 (`OffBoard`、ピンごとに線の先の穴)、レールの役 (`rails`)。
- **回路のデータは 1 つ** (candidates の方針): 並べ方は回路図のシートの設定 (`SheetSettings::breadboard`、ファイルの `"breadboard"`) に入る。別のファイルにしない。画面を見ただけでは入れない (未保存の印を付けない): 手で動かしたか「自動で並べ直す」を押したときだけ。それまでは回路図から毎回並べる (`BreadboardView::layout`、回路図の `rev` と部品の数で作り直す)。読めない形 (古い・新しい) は捨てて並べ直す。

## 自動で並べる (`auto_layout`)

1. 電源: GND は上下の − レール、電源 (直流の電圧源・電池の +、電源記号のネット。PWL で立ち上がる電源も、名前が VCC・VDD・VIN・VBAT・+5V・3V3 のようなら) は上下の + レール (左の端の線で上下をつなぐ)。電源が 2 つなら 2 つ目は下の +。
2. IC (偶数本の足、4 本以上): 中央の溝をまたぐ。1 番ピンが左下 (f 行)、右へ数えて、上の行 (e) を左へ戻る。1 列あけて次の IC。
3. 1 列の部品 (3 本足のトランジスタ・レギュレータ・ヘッダ): e 行に横に並べ、本体は溝の側に描く。
4. IC・1 列の部品の足が電源のネットなら、その列から近い側のレールへ短いジャンパー。同じネットの別の列は、空きのある最後の列へ鎖のようにつなぐ (星形だと最初の列が埋まる)。
5. 2 本足の部品 (`place_two`): 両方が電源 → レールをまたいで差す。片方が電源 → もう片方のネットの列の外側の穴 (a か j) から、隣のレールへ縦に。どちらも電源でない → 同じ半分にある両方のネットの列の組のうち、両方に空いた行がある一番近い組に、横に寝かせて差す。無ければ片方のネットの新しい列を作る (隣のジャンパーは溝の側の穴、外側は部品用に残す)。
6. 1 本のネットは、最後の 1 穴を新しい列へのジャンパー用に残す (`usable` / `free_count`)。これが無いと、ピンの多いネット (74HC の VCC、7 個の LED のアノード) の列が埋まってつなげなかった。
7. ブレッドボードの外: 電源・電池・電流源・シミュレーション専用の部品は左に置き、ピンから線でレールかネットの列へ。

## 照合 (`check`)

穴・ジャンパー・外の部品の線でつながる穴をまとめ (union-find)、回路図のネットと比べる: 2 つのネットが 1 つにまとまる → `Short`、1 つのネットが分かれる → `Open`、1 つの穴に 2 本 → `SameHole`、部品か足が無い → `Missing`。メッセージは原因と直し方。テスト `every_sample_lays_out_without_a_short_or_an_open` は `docs/examples` の全部の回路図 (133 件) を自動で並べて問題 0 を確かめる (最初は 4 件が開いていた: 列が埋まる・PWL の電源)。

## 画面 (`app/src/breadboard/mod.rs`)

- 左: 説明、照合の結果 (✔ か、違う所の一覧)、「自動で並べ直す」、部品ごとの足の穴、外の部品。
- 真ん中: 板 (ベージュ)、穴、上下のレールの赤と青の線とネットの名前、溝。ポインタの下の穴とつながっている穴 (その列かレール) を黄色に。抵抗は色の帯 (`bands`、2 桁・乗数・金)、LED は赤い丸とカソードの平らな側、ダイオードは黒い本体とカソードの帯、コンデンサは青、コイルは緑、IC は黒い箱と 1 番ピンの丸。ジャンパー線は電源が赤、GND が黒、ほかはネットの名前で 5 色。
- 部品のドラッグ: 穴の単位で動く (`moved`)。IC は行を変えない (溝をまたいだまま)、レールの足はレールの上だけを動く。放すとシートに入る。回路図と違う足は赤い丸。
- 連動: ブレッドボードで選んだ部品は回路図と基板の `linked` に入り、回路図で選んだ部品はブレッドボードで光る。
- 起動引数 `--proto [R1]`。CLI `breadboard`。

## 残り (候補)

ジャンパー線を手で動かす・足す、部品を回す、穴の行をまたいだ置き方の工夫 (密集を広げる)、ユニバーサル基板 (B5)、② 動かしながら見る・③ テスターとオシロ・④ 壊れる。
