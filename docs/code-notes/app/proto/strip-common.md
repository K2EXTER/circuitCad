# ストリップ基板・ユニバーサル基板の共通の仕組み (B5、`app/src/breadboard/strip_view.rs`・`sch-core/strip_edit.rs`・`strip_print.rs`・`mount.rs`・`section_plan.rs`)

どちらも結果は `StripLayout` (ユニバーサル基板は `perf: true`)。並べ方はそれぞれ [stripboard.md](stripboard.md)・[perfboard.md](perfboard.md)。

## 画面と切り替え

- 試作のタブの左の上に「ブレッドボード / ストリップ基板 / ユニバーサル基板」(`BreadboardView::kind`、`BoardKind`)。ストリップ基板・ユニバーサル基板は並べ方を見せるだけ (動かす・テスター・ドラッグは無い。切り替えると電源は切る)。撮影用 `--proto-kind strip|perf`。
- 絵 (`breadboard/strip_view.rs`): ベージュの板、ストリップ基板は銅の帯の片と赤い × の切る穴、ユニバーサル基板は片の中の使う穴の端から端の灰色の線 (`perf_wires`、すずめっき線)。左に帯の名前 (GND は灰色)。部品 (2 本足は縦の本体、IC と列の部品は黒い箱)、色の線 (電源は赤・GND は黒・ほかはネットで 5 色)、外の電源の箱。左のパネルは説明・照合・大きさ (mm)・部品と穴 (`C12` = 行 C・12 列)・切る穴・すずめっき線・表の線・外の部品。
- 裏で並べる (2026-11-20、`strip_view.rs` の `strip_shown`・`StripJob`): 自動の並べ方と、保存した並べ方を回路図に合わせる `synced` は別のスレッドで作る (ユニバーサル基板は打ち切りまで最長 1.5 秒試すので、前は画面が止まった)。作り始めて 40 ms で終われば (ストリップ基板の多く) そのフレームで見せ、終わらなければ、その間は保存した並べ方そのもの (足した部品はまだ無い。手で動かせる) か、同じ種類の基板の前の自動の並べ方 (古い回路図のもの。動かせない) か、何も見せず、左に「並べています…」と回る印。回路図・大きさ・基板の種類・保存した並べ方のどれかが変わると作り直す (前のスレッドは最後まで走って捨てられる)。スレッドが落ちたら保存した並べ方のまま (待ち続けない)。テストは `cfg!(test)` で結果を待つ。`--screenshot` は並べ終わるまで撮らない。
- 点検を毎フレーム計算しない (2026-11-21、`strip_view.rs` の `strip_checks`・`mod.rs` の `board_check`): 回路図との照合 (`strip_check`・ブレッドボードの `check`)・区画の決まり (`strip_rules`)・未接続の線 (`strip_unjoined`) は、回路図の編集の番号 `rev` と並べ方が同じ間は前の結果を使う。`rev` は回路図のタブで Undo の段にしたときだけ進むので、まだ段にしていない編集がある間 (`SchEditor::settled` が false) は毎回計算する。DMM の B 段 (デバッグビルド) で 1 フレームが ユニバーサル基板 10〜12 → 4.3 ms、ストリップ基板 7〜8 → 2.1 ms、ブレッドボード 4〜6 → 1.8 ms (ブレッドボードの照合はパネルと絵で 2 回ずつ走っていた)。残りの重いもの: 電源を入れたブレッドボードの過渡解析は 1 フレーム最大 40 ms (`live.rs` の `FRAME_BUDGET`、画面の処理の中)、ユニバーサル基板の自動の並べ方は最長 1.5 秒 (別のスレッド)
- 線を表にも裏にも (2026-11-26、B11、`stripboard::Link` の `back`・`tinned`): 線は 4 種類。表の被覆線 (今までの `links`)、表のすずめっき線 (`tinned`)、裏の被覆線 (`back`)、裏のすずめっき線 (今までの `StripLayout::bare`)。`Link` に 2 つの印を足しただけなので、動かす・回す・消す・端のドラッグ・区画の写しはそのまま印を運ぶ (保存の形も、印が無ければ前と同じ)。電気的には: 被覆線はどちらの面でも両端だけ。表のすずめっき線は `StripLayout::tinned_joins` で、通り道の穴に表から何か出ている (表の部品の足・表の線の端・基板の外の線。裏に付けたチップ・裏の線・裏のすずめっき線は触れない) と、表のほかのすずめっき線と重なる穴・45° で穴と穴の間で交わると、つながる (`joins` が足すので照合・テスター・つながる穴の光りがそのまま使う)。引く: `strip_edit::with_wire(s, l, a, b, back, tinned)` (表のすずめっき線は行・列・45° だけ、表のほかのすずめっき線と穴の間で交わると断る。`with_link` はその表の被覆線)、`link_end_moved` は表のすずめっき線を 45° から外す動かしを断る。画面: 面は見ている面で決まる。表から見て「線を引く」は表の被覆線・「すずめっき線」は表のすずめっき線 (ストリップ基板でも表なら引ける)、裏から見て「線を引く」は裏の被覆線・「すずめっき線」は裏のすずめっき線 (ユニバーサル基板だけ)。「消す」は見ている面の線。絵: 表のすずめっき線は灰色の細い線、裏の被覆線は裏で網の色に明るい芯、表からは薄く部品の下に。左の一覧は「表の線・表のすずめっき線・裏の線」に分ける。印刷の図 (`strip_print.rs`) も同じ分け方。自動: 並べ終わりに `perfboard::wire_sides` (ユニバーサル基板の `perf_layout_keeping` の最後と、ストリップ基板の `strip_layout_with` の最後): 表でチップの足の列に沿う線 (`links_along_pins`、ソケットの上に寝る) は裏の被覆線に、行か列に沿って通り道の穴に表から何も出ていない線で、ほかの網のすずめっき線と重ならないものは表のすずめっき線に。つながりは変わらない。サンプルの 40 個で、両方の基板の線のうち約半分がすずめっき線に・45 本が裏に、照合はすべてそのまま。後から部品を足す `synced` は、足した足や線の端が下に来た自動のすずめっき線を被覆線に戻す (`untinned_over_new`。人が足の上に通したものはそのまま)。`links_along_pins` は裏の線を数えない。テスト `wires_on_either_side_join_as_built`・`the_layouts_choose_each_wires_side`。
- 裏から見る (2026-11-21、`strip_view.rs` の `strip_back`・`strip_flip`、`StripState::back`): 「表 (部品の面) / 裏 (はんだの面)」の切り替えと F キー (絵の上にカーソルがあるとき)。裏は列を左右に反転して描く (`to` が `cols - 1 - 列`)。余白は右に移し、帯の名前を右に、列の番号は反転した位置に。描くもの: 銅 (ストリップ基板は帯の片と切る穴の ×、ユニバーサル基板は穴ごとの銅のランドとすずめっき線 `perf_wires`)、はんだ付けする穴 (`used()` の穴に銀の輪、表の線の端はネットの色の点、IC の 1 番ピンは四角)、部品は薄い輪郭と名前だけ、区画の枠、未接続の線。印刷用の図の裏 (`strip_print.rs` の `Face::Copper`) と同じ描き分け。カーソルの下の穴は、つながる穴の全部 (`StripLayout::joined_to`: 帯の片・`joins()` を union-find でまとめる) を光らせ、穴の名前・そこにある足・ネット (`stripboard::net_at`。回路図の編集の番号と穴で覚えておく) を出す。足をクリックするとその部品を選ぶ (部品の一覧の選択と同じ `picked`)。直すことはしない (`strip_interact` を呼ばない・道具のボタンは使えなくする): 反転した向きでドラッグすると迷うため。撮影用に `--proto-back`
- 組む順と通電 (2026-11-21、B5d。順は `sch_core::build_order`、計算と窓は `breadboard/build_steps.rs`): 部品は区画の箱の中に足が多い方の区画へ、どの箱にも無い部品は最後の段「区画の外」、区画が無ければ 1 段「全体」。区画の順は (1) 電源の区画 (名前に 電源・POWER・PWR・SUPPLY、または VOUT・VO の名前のピンが電源の名前のネットにつながる部品がある) (2) 電源の入口 (`supply_inputs`: 外の部品のネットと、コネクタ・モジュールに届く電源の名前のネット) から GND を通らずに何個の部品をたどるか (3) 表の順。区画の中は背の低い順 (`fit_rank`: 抵抗・ダイオード → IC とソケット → コンデンサ → トランジスタ・LED・水晶 → 半固定・スイッチ → リレー → コネクタ・モジュール)。表の線は、両端の区画のうち後の段 (箱の外の端は最後の段)。各段の計算は、後の段の部品を回路図から外して (`built_so_far`) `from_schematic` → `power_on` (許容差の範囲と電流制限) と `dc_op` (測る電圧)。回路図に電源 (`supply_sources`) が無いときは、入口のネットのうち名前に電圧がある (`rail_volts`: 5V・+3V3・12V) ものに GND との間の電源 `V_<ネット>` を足す (画面では「コネクタから入れる」)。測る所は、その段で初めて部品がつながる名前のネットのうち、電源の名前のものと 10 mV を超えるもの (何もつながっていない 0 V は外す)、8 個まで。1 µA 未満の電流は「ほぼ 0 (電流を流す部品のモデルが無い)」。範囲は 1 % 以上開くときだけ出す。直流の動作点なので、点滅・発振する回路は止まった状態の値 (説明に書いた)。別のスレッドで計算し (DMM の B 段はデバッグビルドで 6.8 秒)、回路図の編集の番号と並べ方で覚える。左のパネルは長くなって下が見えないので、一覧は窓に出し、ボタンは道具のすぐ下。段を選ぶと、その段の部品に緑の枠、後の段の部品に板の色を重ねて薄く (表・裏とも)。DMM の B 段: 電源 (U3、5V から AVDD 4.5 V、17.2 µA) → デジタル (3V3) → リレー (RB1〜5 が 4.5 V) → アナログ (ADRREF 2.50 V、2.6 mA)、表の線 0 / 20 / 27 / 33 本。撮影用に `--proto-build 2` (窓を開いて 2 段目を選ぶ。撮影は計算を待つ)
- 組む順の仕上げ (2026-11-21): 段を選ぶと、表の線も、その段の線は両端に緑の輪、後の段の線は板の色を重ねて薄く (`BuildMarks`。段を作った並べ方と画面の並べ方が同じときだけ)。窓の「印刷用の組み立て表を保存 (SVG)」は `build_sheet_svg`: A4 の幅、上に表の面の絵 (`strip_print::strip_svg` の `Face::Parts` を入れ子の svg で、幅に収まるよう縮める。実寸より大きくはしない)、続いて段ごとに見出しと、表の線 (両端の穴とネット)・部品 (値・足の穴・付け方) を付ける順に □ 付きで 1 行ずつ、電源ごとに電流制限と正常な電流と「測った電流: ____」、測る電圧ごとに「正常なら ○V　測った値: ____」
- 電源を入れて動かす (2026-11-21、B5d): 板のつながりは `stripboard::strip_board_nets` (穴の組 `StripLayout::hole_groups` は帯の片と `joins()` を union-find でまとめる。`joined_to` も同じものを使う)。組の名前の付け方は `breadboard::board_nets` と同じ (GND が先・回路図の最初のネット・分かれたら `~2`・ネットの無い組は `SB.<穴>`)。シミュレーションだけのピン (光センサーの光) は回路図のネットのまま。`BoardNets::from_pins` で作る (穴から引く `at` は空)。動かす仕組みはブレッドボードと共有: `mod.rs` の `RunBoard` (`Bread` / `Strip`) が `run_frame`・`live_frame`・ブザーに板のネット・外の部品・板の部品を渡す。パネルは `strip_power_ui` (電源のボタン・`live_frame`・`power_issues_ui`。最後のはブレッドボードと共有)。表の絵は `strip_draw_running` (LED の光り方はブレッドボードと同じ √(電流/20 mA)・スイッチの入切の札・焦げた印と橙の枠)。スイッチは `strip_switch_press` で、押している間は `strip_interact` を呼ばない。板の種類を替えると電源は切れる
- テスターとオシロ (2026-11-21): 道具の「テスター」「オシロ」(`StripTool::Meter`・`Scope`。表でも裏から見た絵でも穴をクリックして当てる。裏は直す道具が使えないが、この 2 つは使える: 実物も、はんだの面に棒を当てる)。読みの処理はブレッドボードと共有: `mod.rs` の `meter_panel` (電圧・電流・抵抗のレンジ) と `scope_panel` に、棒の当たった穴の名前とネット (`Probe`) と板 (`RunBoard`) を渡す。ストリップ基板の穴のネットは `stripboard::strip_hole_nets` (`strip_board_nets` の名前で、足のつながる穴だけ。動いている回路の名前と同じなので、電源を入れた回路の電圧がそのまま読める)、回路図の編集の番号と並べ方で覚える。電源を切ったテスターは回路図の DC 動作点を読む (ブレッドボードと同じく、最初の 1 回だけ DC 解析を走らせる)。読みの覚え (`meter_cache`) の鍵に板の種類を足した。撮影用の `--proto-meter` は、ストリップ基板では外の電源の 2 本の線の穴に棒を当てる
- チップ部品を裏に (2026-11-21、B5d。ストリップ基板は次の項): `StripOptions::chips_back` (画面は `SchEditor::strip_chips_back`、撮影用に `--proto-chips-back`)。対象は `mount_of` が `Leaded` (リード部品に替える) で `mount::back_size` が 0805・1206 の抵抗・コンデンサ (0603 以下は 2.54 mm の 2 つの穴に届かない。ダイオード・LED は向きがあるので外した)。`perf_layout_keeping` は対象を外した回路で置き方を試し、各置き方のあと `with_back` で裏に足してから全体を配線する (`route` には全部の部品)。`with_back`: 隣り合う 2 つの穴の組を全部試し、各端は「同じネットの足がある穴 (0)・空いた穴 (同じネットのいちばん近い穴までの距離)・別のネットの足がある穴 (不可)」、空いた端の隣に別のネットの足があると +1、合計が最小。裏のチップどうしは穴を共有しない。`strip_check` は、裏のチップと表の足が 1 つの穴にあるのを「2 つ入っている」としない (別のネットならネットの照合で出る)。描き方: 表は点線の輪郭と「R1 (裏)」、裏の絵はチップの形 (抵抗は黒・コンデンサは茶、両端は銀)、印刷用の図は裏のシートに。組む順では裏のチップが最初。サンプルで比べた (穴の数・表の線): adc_input 81→63・1→1、attiny_blinker 72→54・0→0、active_filter 208→162・1→2、seg7_counter 432→374・12→14、attiny_isp 90→90・4→4、arduino_minimal 504→598・26→25 (大きくなった)、DMM の B 段 2024→1254・91→82。どれも照合 0・つながっていないネット 0
- チップ部品を裏に・ストリップ基板 (2026-11-21、`stripboard/` の `strip_layout_with`・`with_back_strips`): 対象を外して並べ (`strip_lay`)、各チップを、2 つのネットの帯が上下に隣り合う列に縦にまたがせる (帯は端から端まで 1 つのネットなので列はどこでもよい。切る穴は不可・裏のチップどうしは穴を共有しない・空いた穴を先に (足の穴の上は +10)・そのネットの足に近い列)。置けないチップは表に戻して並べ直す (3 回まで)。並べ方は帯を隣り合わせることを考えないので置ける数が少なく、外したせいで基板が大きくなることもあるため、全部を表にした並べ方と「穴の数 + 表の線 × 10」で比べて小さい方を返す。サンプル (穴の数・表の線、裏に置けた数): adc_input 110→90・5→4 (1/3)、attiny_blinker 99→88・5→4 (2/3)、arduino_minimal 1350→1200・47→44 (5/8)、ne555 143→150・9→6 (3/5、点数では裏の方)、active_filter・seg7_counter は 0 個で全部表、DMM の B 段 8487→8569・248→244 (14/26、点数で全部表の方)。チップの帯を隣り合わせるように並べ方の側で考えれば増えるはず (候補に残した)
- チップ部品を裏に・帯を隣り合わせる (2026-11-22、B5d、`stripboard/` の `pair_up`・`strip_layout_with`): 裏に付けるチップを外さずに `Mount::Back` の印を付けて並べる。そのチップは、ピンの片から帯へ縦に差す線の代わり (`Via`) にしない (帯が要る)。帯の組の中の帯の順 (電源が上・GND が下・ほかは出てきた順) を、裏のチップの 2 つのネットが隣り合うように並べ替える (`pair_up`: 組を鎖にする。1 本の帯の隣は 2 つまで・輪にしない・GND を含む鎖は GND を端にして最後)。チップは、2 つの帯が隣り合えば、その 2 つの穴に縦にまたがせ (表には何も立てないので、隣の列をふさがない)、隣り合わなければ表のリード部品として立てる。行の相乗り (`share_rows`) が片方の帯を別の行へ動かしたチップも表に戻す (チップのある行を動かさない案は、相乗りが減って基板が大きくなり、DMM で裏が 0 個になったので見送った。ペアの帯を相乗りから外す案も DMM で 8 行増えて見送った)。この並べ方 (a)、前の並べ方 (外して並べ、隣り合う所を探す。b)、全部を表、の 3 つから、照合 0 で「穴の数 + 表の線 × 10 − 裏のチップ × 5」が小さいものを返す (前は照合を見ず、DMM の B 段で 5V が分かれた並べ方 (b) を返していた)。結果 (ストリップ基板、裏に置けた数・穴・表の線): サンプル全部 幅なし 118 → 248 個・31382 → 31107 穴・954 → 955 本、幅 40 119 → 247 個。DMM の B 段 幅 59: 14 個 (5V が分かれていた) → 16 個・57 × 81・163 本・照合 0。幅なしは全部表のまま (裏にすると 3 行増える)。active_filter も裏に置けるようになった。テスト `a_stripboard_chip_on_the_copper_side_sits_across_two_strips`・`the_pairs_of_a_band_sit_side_by_side`。比べ方は `strip_bench --strip --back`。
- 取り付け穴の立入禁止 (2026-11-25、L11): `StripOptions { rows, mount_holes }` と `keepout()` (四隅の 3 × 3 穴 `MOUNT_HOLE_HOLES`。右の隅は `cols`、下の隅は `rows` が要る)。ユニバーサル基板の並べ方 (`perfboard.rs`) は `Wants.keepout` を配置の `blocked`・`clear`・焼きなましの `taken` に入れ、配線 `route` は禁止の穴をどのネットのものでもない持ち主にする。候補の比べ方の鍵の先頭が `StripLayout::in_keepout` の数 (箱を詰める並べ方は禁止を知らないので、かかればここで負ける)。結果の `StripLayout.keepout` に残す。ストリップ基板の並べ方はまだよけない (パネルの警告だけ)。画面は「四隅に取り付け穴 (M3)」(`SchEditor.strip_mount_holes`、`.schjson` の `strip_mount_holes`、`--proto-mount-holes`)、灰色の丸、かかっている物の警告。

## 取り付け方 (ソケット・変換基板・モジュール)

- 取り付け (2026-11-19、`sch_core::mount`): フットプリントの名前から、部品をどう基板に付けるかを決める (`mount_of`)。`DIP-n` は丸ピン IC ソケット (`Socket`、`_W15.24` なら 0.6 インチ幅)。SOIC・SOP・ESOP・TSSOP・MSOP は DIP の変換基板 (20 ピンまで 0.3 インチ、それより多いと 0.6)、QFN・DFN・QFP・TQFP・LQFP は DIP の変換基板 (20 ピンまで 0.3・64 まで 0.6・それより多いと 1.0 インチ。4 辺の QFP の変換基板も 2 列に開いて描く)、SOT-23・SOT-23-5・SOT-143・SOT-223・SC-70・水晶 (XTAL) は SIP の変換基板 (`Adapter`、`width` 0)。どちらも変換基板のピンを丸ピンの連結ソケットに差す。0805 などの 2 本足のチップ部品は、R・C・L・D・LED ならリード部品に替える (`Leaded`)、ほかは 2 ピンの変換基板。**変換基板はチップのピンの番号をそのまま DIP の数え方で持つ**ので、ストリップ基板の並べ方はピンを記号の並び順でなく番号の場所に置く (`Mount::slots`): 記号が使わないピンを省いた QFN-16 (12 本) も、DIP-16 の変換基板のその番号の穴に来て、省いたピンの場所は空く。ピンの名前が番号でない部品 (`Kind::Npn` の C・B・E) は今までどおり並び順。2 列の幅は `right_pin = left_pin + width`。形はブレッドボードの `read` の `Look` を上書きする (2 列の取り付けは `Dip`、SIP は `Row`。ブレッドボードの並べ方は変えていない)。絵は変換基板を緑の板と真ん中の小さなチップとパッケージ名、ソケットは灰色の枠。左のパネルの部品ごとに取り付け方の 1 行 (リード部品に替えるものは下の一覧だけ)、「ソケットと変換基板」に買うものの数 (`shopping`: 変換基板 1 枚につき連結ソケット 2 本)。テスト `mounts_from_footprints` (フットプリントの表)、`chips_on_adapters_sit_by_pin_number` (QFN-16・TQFP-32・SOT-223)。
- モジュール (2026-11-21、`Mount::Module`): フットプリントにモジュールの名前 (ARDUINO・NANO・PICO・ESP・MODULE・DEVKIT・WEMOS・TEENSY・XIAO・STM32・BLUEPILL) と `DIP<n>` があるもの (`ARDUINO_NANO_DIP30`) は、基板にはんだ付けしたメスのピンヘッダ 1×(n/2) 2 本に差す (外せる・こての熱が当たらない)。列の間はフットプリントの `_W` (mm) から、無ければ Pico 0.7 インチ・ESP32 1.0 インチ・ほか 0.6 インチ (前は取り付けが「直接」で、列の間が IC と同じ 0.3 インチになっていた)。名前は「Arduino Nano」のように (`module_name`)。ピンは番号どおり DIP の数え方 (1 番から左の列を下へ、右の列を上へ)。部品と差す穴の表に「Arduino Nano を、基板にはんだ付けしたメスのピンヘッダ 1×15 2 本 (0.6 インチ幅) に差す」、買う物に「メスのピンヘッダ 1×15 ×2」、絵は青い板に部品番号とモジュールの名前、印刷用の図は薄い青。7 セグメント表示の `SEG7_0.56_DIP10` はモジュールの名前が無いので今までどおり (実物は列の間 0.6 インチだが、並べ方は 0.3 インチ。別の直し)。テスト `mounts_from_footprints`・`leads_sit_by_their_pin_numbers`・`an_arduino_nano_sits_in_female_headers`。

## 手で直す

- **選び方は回路図と同じ (2026-11-25、`strip_view.rs` の `StripState.chosen`・`strip_pick`、`strip_edit.rs` の `picked_moved`・`picked_turned`・`parts_touching_box`)**: 下の「四角に囲んだ中をまとめて動かす」「囲んだ所を回す」の四角は、放すと消えるようにし、選ぶのは部品にした (前は穴の四角が残り、中の部品は光らなかった)。「選択」で何も無い所から左ドラッグ = 青い四角で、足が全部中の部品 (`parts_in_box`)、右ドラッグ (か Shift + ドラッグ) = 緑の四角で、触れた部品 (足の箱が四角と重なる、`parts_touching_box`)。Shift を押して囲むと今の選択に足す。Shift + クリックで 1 個ずつ足す・外す (線の端が足の上にあっても部品を取る)。2 個以上は `chosen` (黄色の枠)、1 個だけなら今までどおり `picked`。選んだ部品のどれかをドラッグすると全部が動く (`picked_moved`: 選んだ部品の足の箱と 1 穴まわり、と囲んだ四角 `chosen_areas` の中の線の端・切る穴・すずめっき線・外の電源の線も一緒。選んでいない部品は、その中でも動かない)。R は `picked_turned` (同じ範囲を `area_turned` と同じく半回転か 90°)。揃えるボタンは `chosen` に効く。四角を回したり揃えたりしたあとは、囲んだ四角は捨てる (部品はもう別の所)。`--proto-sel A1:F10` は並べ方ができてから、その四角の中の部品を選ぶ (`pending_box`)。右ボタンのドラッグは、動かすの道具では選ぶのに使うので絵を動かさない (ほかの道具と裏の絵では動かす)。ブレッドボードも同じ選び方 (`BreadboardView.chosen`・`pick_box`、四角は画面の点で、部品の絵の箱 `part_rect` で判定、まとめて動かすのは `moved` を部品ごとに。線は動かない)。試験 `parts_are_picked_with_a_box_and_moved_together`・`breadboard_parts_are_picked_with_a_box_and_moved_together`・`a_right_click_lets_the_pick_go`、sch-core `picked_parts_move_and_turn_as_one`
- 手で動かす (2026-11-19、`sch_core::strip_edit`・`strip_view.rs` の `StripState`): 左のパネルの道具「動かす / 線を引く / 帯を切る」(帯を切るはストリップ基板だけ)。動かす: 部品 (`part_moved`)・線の端 (`link_end_moved`) を穴ごとにドラッグ、何も無い所からドラッグで四角に囲み、囲んだ中をドラッグすると、全部の足が中にある部品・中の線の端・切る穴・外の電源の線の端をまとめて動かす (`area_moved`。端が外の線は伸びる)。R で選んだ部品を回す (`part_turned`: 2 本足は 1 本目の足のまわりに 90°、IC と列の部品は真ん中のまわりに 180°)、Delete で選んだ線を消す。線を引く: 2 つの穴をクリック (`with_link`、色は片の上の足のネット `net_at`)。帯を切る: クリックで切る・もう一度で戻す (`cut_toggled`)。基板は上と左にははみ出せず、右と下へは広がる (`grown`)。ドラッグの間は基板の大きさと位置を始めたときのまま止める (`frozen`。広がると穴がポインタの下でずれるため)。ドラッグの始まりは押した所 (`press_origin`: egui は少し動いてから `drag_started` になる)。手で変えた並べ方はシートの設定 `stripboard` に入り (`SheetSettings`、ブレッドボードの `breadboard` と同じ)、「自動で並べ直す」で消える。回路図が変わったら `synced`: 消えた部品・ピンの変わった部品は外し、新しい部品は自動の並べ方での互いの位置のまま基板の右に足す (線は引かない。照合が「分かれています」と言う)。照合は表示のたびに。テスト `strip_edit` の 3 件、`a_part_dragged_on_the_stripboard_stays_and_is_checked` (ポインタでドラッグして保存・帯を切る)。
- 元に戻す (2026-11-20、`strip_view.rs` の `strip_set`・`strip_undo`・`strip_history_check`): 手の操作 (ドラッグ・線を引く・消す・帯を切る・回す・「自動で並べ直す」) は `sch.stripboard` を `strip_set` で変え、前の並べ方 (None は自動の形) を `StripState.undo` に積む (100 回まで。ドラッグは離したときに 1 回)。Ctrl+Z か「元に戻す」のボタン (`Icon::Undo`) で戻し、Ctrl+Y・Ctrl+Shift+Z か「やり直し」でやり直す (文字の入力中とドラッグ中は効かない)。回路図の Undo とは別の履歴 (並べ方はシートの設定で、回路図の比較の履歴に入っていない)。最後に置いた並べ方 `last` とシートの並べ方が違えば (別のファイルを開いた)、履歴を捨てる。テスト `a_part_dragged_on_the_stripboard_stays_and_is_checked` の後半。
- 回路図が変わったときの線 (2026-11-20、`strip_edit.rs` の `synced`): 手で動かした並べ方に、回路図に足した部品を加えるとき、自動の並べ方の位置のまま基板の右へ置き (間に全部の行で切る列 1 つと、両側に空いた穴 3 つ。帯の片に線の端を置く穴が要る)、その列の範囲の自動の並べ方の切る穴も写す (IC のピンごとの片)。そのあと、ラッツネスト (`strip_unjoined`) の線のうち端が足した部品にあるものを、両端の片のいちばん近い空いた穴どうしの線にする (`free_hole`)。片に空いた穴が無いときは、何もつながりを増やさずに片を伸ばす: 端の切る穴が 1 穴外へ動く (その穴が空いているとき。帯の行の相乗りで片が端どうしまでしかない)、外の片が空なら切る穴を消す、基板の右端なら列を足す。それでも無ければ、同じネットのほかの穴 (近い順) から引く。外の電源の線の端に余地が無ければ、その線を相手の片の空いた穴へ付け替える。照合のあるサンプル全部で部品を 1 つずつ抜いた並べ方に戻すと、890 件のうち 869 件が照合 0 (片を伸ばす前は 752 件)。残りはピンの多い IC など。テスト `a_saved_layout_follows_the_schematic` の後半 (555 の全部の部品)。
- 囲んだ所を回す (2026-11-20、`strip_edit.rs` の `area_turned`): 「選択」で四角に囲んだあと R で、中を囲みの真ん中のまわりに半回転 (行も列も逆に)。部品は足が全部中にあるものだけ、線は中にある端だけ (片端が外なら伸びる)、外の電源の線の端・切る穴・帯の名前 (`names`) も。すずめっき線は、片端が外で曲がってしまうならその場に残る。4 分の 1 回転にしないのは、帯が横のままでないと IC のピンが帯をまたいでつながってしまうから (部品の R も IC は半回転)。テスト `a_box_turns_half_a_turn` (サンプル 4 つの基板全体を回しても照合 0、2 回で元どおり)。 ユニバーサル基板 (`perf`、帯が無い) では 90° (時計回り、囲みの左上を軸。`turned_box` が回したあとの囲みで、画面の選んだ囲みもそれに)。部品の R も、IC・列の部品はユニバーサル基板では 90°。画面の DIP の本体は、ピンの列が縦 2 列なら左右を、横 2 行なら上下を細くして描く。テスト `a_perfboard_turns_a_quarter_turn`。
- 選んだ部品を揃える (2026-11-22、`strip_edit.rs` の `parts_aligned`・`parts_in_box`・`StripAlign`、画面は `strip_view.rs` の `strip_align`・`ALIGNS`): 「選択」で四角に囲んだ所に部品 (足が全部中) が 2 つ以上あると、左のパネルに「囲んだ N 個を (?)」と、基板のタブの整列と同じアイコンの 2 段 (「揃える」: 左・右・上・下揃え、「並べる」: 横に並べる・縦に並べる・文字付きの「つながる順に並べる」。名前と説明はホバー)。揃えは足の外接の端を、いちばん外の部品の端に。並べるは今の位置の順に、`ALIGN_GAP` (2) 穴ずつ空けて一列に (上か左の端をそろえる)。つながる順は、各部品の足と同じネット (電源・GND と、足が 5 つ以上のネットは除く) の、選んでいない部品の足の真ん中を見て (IC・ヘッダ (足が 3 本以上) の足があればそれだけ: 抵抗のもう片方の LED は順を乱す)、その真ん中が横に広がっていれば横一列、縦なら縦一列に、その順で並べ、列の真ん中を相手の足の真ん中に合わせる (基板の幅に収まる所まで戻す)。部品ごと穴の単位で動かし、線は動かさない。ぶつかり (足が別の部品の足の穴に、IC の外形に別の部品の足、外からの線の穴) があれば何も動かさずに理由 (「R1 を動かす先に D5 があります…」) を状態の行に。ユニバーサル基板は固定した部品だけをぶつかりに数え、揃えた部品を固定して、すぐ「固定した部品のまわりを並べ直す」(`strip_relayout`、別のスレッド) を走らせる (ほかの部品と線は置き直される)。ストリップ基板は並べ直しが無いので全部の部品とのぶつかりを見て、動いたあとは照合とラッツネストで確かめる。囲みの四角は揃えた部品に付いていく。元に戻すで戻る。撮影用の引数 `--proto-sel A1:Z30` (2 つの角の穴の名前)。DMM の B 段 (幅 59) で K1〜K8 をつながる順に並べると、U5・U6 の出力の順 (K4〜K1、K8〜K5) に 1 列に並ぶが、残りを並べ直すと表の線は全部自動の 80 本より多い (84 本、U5・U6・J3 も固定すると 87 本): 並べるだけでは足りず、どこに置くかは人が決める。テスト `picked_parts_line_up` (sch-core)、`picked_parts_line_up_and_the_rest_is_laid_out_round_them` (app)。

## 区画

- 区画とつなぎ方の決まり (2026-11-19、`strip_layout_with` の `sections`・`lay_sections`、`strip_rules`): 回路図の「設計の要件」→「近くに置く組」に「区画」の印 (`design_spec::PlaceGroup::section`。基板の自動配置の組と同じ表で、印の無い組は試作では区画にしない: 端子のそばの保護のような小さな組で基板が細切れにならないように)。印の付いた組ごとに部品を集め (2 つの組にある部品は先の組、どれにも無い部品は「その他」)、区画ごとに 1 枚の基板として並べ (`lay`。ほかの区画にも行くネットは外の電源と同じく上の帯の組に帯を持つ)、区画を横に並べて (幅を決めたら折り返す) 間の列で全部の行の帯を切る。外の電源は、ネットのいちばん多い区画に。ほかの区画にも行くネットは区画から区画へ線でつなぐ (帯の上の空いた穴、相手の区画に近い方から)。GND だけは、区画ごとに 1 本の線で、表のいちばん上の GND のある区画の GND の帯 (1 点) へ戻す (ほかの区画の電流がその区画の GND を通らない)。`StripLayout.sections` (名前と角) と `names` (区画ごとの帯の名前。区画があると `homes` は空) を、画面は枠と名前、印刷用の図も枠と名前で描く。`strip_rules`: 要件の表の「離す」(部品は足、ネットは足と線の端の、いちばん近い 2 つの穴の距離、1 穴 2.54 mm) と、区画があるときの GND の 1 点 (1 点の区画へ 1 本、ほかの区画への GND の線が無い)。左のパネルの「区画とつなぎ方の決まり」に ✔ / ▲。DMM の B 段を 3 区画 (アナログ・リレー・電源と制御) にすると照合 0 で並ぶが、帯の組が区画ごとに繰り返すので 205 × 65 (幅 59 で 73 × 196)。テスト `sections_are_cut_apart_and_ground_meets_at_one_point`。
- 近くに置く組の距離 (2026-11-25、L10、`stripboard/check.rs` の `group_spreads`): 設計の要件の表の組で `max_dist` > 0 のものは、基板の上の組の部品 (足の中心) のいちばん離れた 2 つの距離を `strip_rules` が判定する (「近くに置く「…」: いちばん離れた部品どうしが … mm」)。ユニバーサル基板の並べ方は、焼きなましの費用に組ごとの項 (距離を超えた分 × 4。`Wants.group_max`) を足し、候補の比べ方の鍵で離れたネットの数の次に距離を超えた組の数を見る。区画をまたぐ組 (DMM の B 段の「基準の温度」は U1・U2 がアナログ、J4・J5 がリレーの区画) は、組の部品のうち、ほかの部品が下の区画にあるものを自分の区画の最後 (箱の下)、上の区画にあるものを見出しのすぐ後 (箱の上) に並べ (`Wants::last`・`early`)、区画の箱の幅の組み合わせを、組の距離を超えた分 (`Wants::group_over`) が少ない順、その次に段の少ない順で選ぶ (`place_packed`)。DMM の B 段で 64 → 43 mm (幅 59 穴では 100 → 40 mm 以内)。代わりに基板が大きくなる (幅 59 穴で 59 × 39 → 58 × 49 穴、表の線 86 → 87): 組の決まりを、小さい基板より先に守る。箱を置く場所を組の距離で選ぶのも試したが、表の線が増えるだけだった (87 → 98)。`examples/strip_bench.rs` は守れていない決まりも出す。
- 点検の決まりの行の書き方 (2026-11-26): 「近くに置く「…」: いちばん離れた部品どうしが … mm」「離す「…」: いちばん近い所が … mm」は、近い・離れたが入り混じり、どの部品かも出なかった (分かりにくいと言われた)。「「名前」を N mm 以内に集める: A と B が X mm 離れています (Y mm 遠すぎ)。どちらかを相手の方へ寄せてください」「「名前」を N mm 以上離す: A と B が X mm しか離れていません (Y mm 足りない)。どちらかを遠ざけてください」(守れていれば「できています (いちばん遠い / 近い A と B で X mm)」) にし、`RuleCheck.parts` にその 2 つ。パネルの行をクリックすると、その 2 つを選ぶ (光る)。
- 足の列に沿う表の線を減らす (2026-11-25、L9、`perfboard.rs` の `route`・`ALONG_COST`): ユニバーサル基板の配線で、跳び (表の線) が 1 つの IC・ソケット・ヘッダの足を 2 本続けて越えるとき (`links_along_pins` と同じ形) は 30 高くし、裏のすずめっき線の回り道や、足の列を横切る跳びを先に選ぶ。候補の比べ方の鍵で、表の線の数にその線を 2 本ずつ足す (1 本を 3 本に数える)。DMM の B 段で 23 → 9 本 (幅 59 穴で 13 → 9 本)、表の線の合計は 94 → 103・87 → 92。Arduino Mega のサンプルで 50 → 40 本。罰を 60 にすると減らないまま表の線が 12 本増えた。効いているのは主に候補の比べ方 (`rank`) で、配線の罰だけでは 1 つの置き方ではほとんど変わらない。全体の並べ方は 1.5 秒で打ち切るので、何通り試せるかで数が変わる (CI の遅い機械では Mega で 49)。試験は決まった 8 通りの配線から `rank` が選ぶ形を見る (37 本、表の線の数だけで選ぶと 49 本)。
- つないだ基板のコネクタの穴の並び (2026-11-25、L4、`stripboard/mate.rs`・`app/breadboard/mate_ui.rs`): 複数の基板のプロジェクトで、この基板とつないだ基板ごとに、ユニバーサル基板の左のパネルに「つないだ基板のコネクタ」。「照合」は、つなぎのピンの組 (`system::pin_pairs`) の穴を両方の並べ方で取り、4 通りに回して (部品を上にして差す向き) 平行移動で全部が重なるかを見る (`mate_check`: `Fits { turn }`)。鏡に映すとだけ重なるなら `Flipped` (裏返して差すときだけ合う)、どれでもなければ両側の並び (穴の数・行 × 列) を言う。「相手に合わせて並べ直す」は、この基板のコネクタを相手の穴の並びどおりに左上 (左に 2 穴・上に 1 穴) へ置いて固定し (`mate_parts`)、ほかを固定した部品のまわりに並べ直す (`strip_relayout`、元に戻せる。置いた区画の箱は外す)。相手の並べ方は、保存した形 (ユニバーサル基板のもの) が無ければ自動の並べ方 (相手の基板の大きさ・取り付け穴の設定で) を作る。`App::update_mates` が、編集中の基板・基板の数・つなぎが変わったときに一覧を作り直す。撮影用 `--proto-mate`。
- 部品ごとの付け方 (2026-11-26、L12、`sch-core/mount.rs` の `MountChoice`・`mount_for`): 回路図の部品に `mount` (無し = フットプリントから `mount_of`)。`direct`・`leaded`・`wired` (新しい `Mount::Wired`: チップにリード線。並べ方はリード部品と同じ、買う物は「チップにリード線を付ける」)・`lands` (`Mount::Back`。全体の「チップ部品を裏に」が無くても、その部品だけ裏に: `perfboard::back_chips` の `all`。ストリップ基板では帯が隣り合わなければ表のリード部品に戻す)。部品に合わない選択 (`MountChoice::fits`: leaded・wired・lands は 2 本足のチップだけ、lands は抵抗とコンデンサ) は無視して自動。画面は部品のプロパティと試作のパネルの「部品と差す穴」の選択 (`breadboard/mate_ui.rs` の `mount_choice_ui`。そのまま差すだけの部品は出さない)。手で動かした並べ方には「自動で並べ直す」まで反映されない。ccad は `mount` と、試作の並べ方を出す `proto perf|strip` (`cli/src/protocmd.rs`。アプリが保存した基板の大きさ・取り付け穴を既定に。`.schjson` のアプリの鍵 `strip_size` などを `open`・`save` で落とさないようにした)。
- 手で直すときの 4 つ (2026-11-26): ① 範囲選択は基板の左・上の外から始めても、外へはみ出しても選べる (`strip_interact` の `hole_near`: ドラッグは基板の端の穴に寄せる)。② ユニバーサル基板の大きさは、手で動かすたびに中身 + 1 穴の余白に合わせる (`strip_edit::grown`。前は大きくなるだけで縮まなかった。ストリップ基板は帯が全幅なので今までどおり縮めない)。区画の箱の外へははみ出さない。③ 「選択」で表の線か裏のすずめっき線をクリックして Delete で消える (`picked_bare`・`bare_near`・`without_bare`)、囲んだあとの Delete は囲んだ中の線を全部 (`wires_in_boxes_removed`)。④ 区画の箱が中身に付いていく (`sections_followed`: 区画の部品がそろって同じだけ動けば箱も同じだけ、ばらばらに動けば部品の足を 1 穴の余白で囲む箱に。回すときも)。
- 裏での編集・表のネットの光・並べ直しの挟まり (2026-11-26): ① 裏 (はんだの面) でも銅を直せる (`strip_back_edit`): ユニバーサル基板はすずめっき線の道具で穴から穴へ引き、右クリックでその穴を通る手の線を消し、動かすの道具でクリックした線を Delete で消す。ストリップ基板は帯を切る道具。部品と表の線は表で (裏では「線を引く」は選べない)。② 表でも穴にカーソルを置くと、つながる足・線の端・すずめっき線・表の線が光り、ネットの名前が出る (裏と同じ `joined_to`)。③ 手で直すたびに「並べています…」が挟まっていたのは、保存した並べ方を回路図に合わせる `strip_edit::synced` が、毎回ユニバーサル基板の自動の並べ方 (最長 1.5 秒) を作っていたため。部品 (とピン) と基板の外の部品が回路図と同じなら作らずに、付け方だけ回路図に合わせて返す (`same_parts`)。
- 幅を守る (B5b、2026-11-22、`stripboard/` の `lay_within`・`strip_lay`): ストリップ基板は IC の段を幅で折り返すが、左の線の列と段の横に立てる部品で、決めた幅を数列はみ出していた (DMM の B 段 幅 59 で 60 列、区画を付けると 73 列)。区画ごと (区画が無ければ基板全体) に並べて幅を超えたら、超えた分だけ狭い幅で並べ直す (6 回まで)。区画の間の線で基板全体がまだはみ出したら、全体を同じように狭くして並べ直す (3 回まで)。区画は棚に左から並べ、幅を超えたら下の棚へ (上下に積む)。半分の幅で並べた区画を 2 つ横に置く案も試したが、DMM の区画は半分の幅に収まらず効かなかった。区画の間でネットが分かれる不具合も直した: 帯の行の相乗り (`share_rows`) で、ほかの区画へ続くネット (`external`) の帯が自分の足 1 つだけの片に切られ、ほかの区画からの線の端を置く穴が無かった (DMM の B 段を 3 つの区画にすると照合 3)。そのネットの片の横に空いた穴を 1 つ残すように、相乗りの間を 1 穴広げ、切れ目をその反対側に寄せる。`join_lines` も、端の片に空きが無いとき、その端とつながった穴 (線の先の帯) の空いた穴を使う。DMM の B 段 (区画 3 つ) 幅 59: 73 × 120 穴・照合 3 → 58 × 143 穴・照合 0、幅なし 205 × 42・照合 3 → 205 × 44・照合 0。区画なし 幅 59: 60 × 78 → 57 × 81。サンプル全部 (幅 40・59) は変わらない。テスト `sections_keep_to_a_narrow_board`。
- 区画の案を出す (B5b、2026-11-21、`sch_core::section_plan::propose_sections`): 基板の上の部品を、間をつなぐネットが少ない組に分ける。電源・GND のネットは数えない (全部の部品に届く)。2 つに分ける (FM 法: 1 回で全部の部品を 1 度ずつ、またぐネットがいちばん減るものから反対側へ、半分ずつの足の数が全体の 1/4〜3/4 のまま、その回のいちばん良い所まで戻す、8 回まで。始めは回路図の順と、混ぜた順 11 通り) を 2 段まで (区画は 4 つまで)。分けるのは、組の部品が 8 個以上・片側 4 個以上・またぐネットが 12 本以下で組の中のネットの 3 割以下のときだけ。名前は組のいちばん足の多い部品から「U1 のまわり」。結果: アクティブフィルタは 2 段 (U1 と R1・R2・C1・C2 / U2 と R3・R4・C3・C4)、arduino_mega_usb は マイコンとヘッダ / USB の変換と水晶 / パスコンとリセット、DMM の B 段は 範囲の抵抗とリレー K2〜K5 / 基準 U2 / 入力・保護・レギュレータ・バッファ / ADC U1 とリレーを動かす U5・U6・J3 (ADC とデジタルが同じ組: つながりだけで分けるので、役割の分け方とは違うことがある)。7 セグメント・555・電流センサは分けない (つながりが多いか部品が少ない)。役割で分ける (2026-11-21、本人の指摘: DMM で ADC とデジタルが同じ組): 部品が 8 個以上なら、先に役割で分ける (`roles`)。デジタル = IC とヘッダのうち、電源・GND 以外のネットの半分以上がデジタルの信号の名前 (`digital_net`: MOSI・SCLK・CS・SDA・RESET・DRDY・CLK・UART の CTS などの語、D22・GPIO3・PB1・TXD0 のような番号、USB_DP・XTAL、`_` で区切った語のどれか) のもの (ADC は SPI よりアナログの線が多いのでアナログ)、リレー = 部品名が K + 数字、電源 = 電源のネットに 2 つ以上つながり、信号が 2 本以下 (レギュレータ)、残りの IC はアナログ。2 本足の部品と 3 本以下の列 (保護のダイオード) は、信号のネットをいちばん多く共有する組へ、電源と GND だけのもの (パスコン) は回路図でいちばん近くに描いた IC の組へ。電源は回路図の電源の記号・外の電源のほか、名前でも見る (`supply_name`: 5V・+12V・3V3・AVDD・VCC・VDD_IO・VBAT。DMM の B 段は外の電源が無く、名前で決まる)。役割が 2 つ以上なら、それが案 (名前は「デジタル」「リレー」「アナログ」「電源」)。1 つなら上のつながりの分け方。始めはデジタルの線を切る重みを 1/4 にするだけを試したが、DMM でリレーを動かす IC が J3 から離れ、リレーが半分に割れたので、役割の分け方にした。結果: DMM の B 段は デジタル (J2・J3・U5・U6) / リレー (K1〜K8・範囲の抵抗 R11〜R15・R1・R4) / アナログ (U1・U2・U4・J1・D1〜D3 と周り) / 電源 (U3)。arduino_mega_usb は全部デジタルなのでつながりの分け方のまま、アクティブフィルタも同じ。テスト `digital_signals_and_supplies_by_name`。画面: ストリップ基板・ユニバーサル基板の左の「区画に分けるには…」の下に「区画の案を出す」、組と部品の一覧、「この案で区画にする」(設計の要件の「近くに置く組」に「区画」の印で入れる。回路図の変更なので回路図の元に戻すで戻る)・「やめる」。`--proto-plan` で案を出した画面を撮れる。テスト `the_two_stages_of_a_filter_are_proposed_as_sections`。

- 印刷用の図 (2026-11-19、`sch_core::strip_print`): 左のパネルの「印刷用の図を保存 (表と裏)」で、`<名前>_表.svg` (部品の面: 部品・線・外の電源のピン・行の文字と帯の名前・列の番号) と `<名前>_裏.svg` (銅の面を下から見た形で左右が逆: ストリップ基板は帯の片と切る穴の ×、ユニバーサル基板はすずめっき線、はんだ付けする穴に輪) を書く。SVG の単位は mm (`width="…mm"`) で、穴の間隔 2.54 mm、100 % で印刷すると実寸。右下に 10 mm の線。IC は変換基板なら薄い緑、1 番ピンに点。裏の列の位置は `hole_xy` (列 1 が右)。ユニバーサル基板のすずめっき線 `perf_wires` は画面と共有。テスト `the_copper_side_is_the_mirror_and_to_scale`。
