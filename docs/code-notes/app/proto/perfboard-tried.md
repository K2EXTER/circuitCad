# ユニバーサル基板: 試して見送った並べ方

表の線 (ジャンパー) を減らそうとして効かなかった案と数字。今の並べ方は [perfboard.md](perfboard.md)。

- 力で広げる置き方を試して見送った (2026-11-20、本人の提案): 部品を全部真ん中に重ねて置き (ヘッダは上の縁・外の電源の線は左の縁に固定)、足をネットの真ん中へ引き (電源・GND は弱く)、組を寄せ、重なり (IC は 2 穴・2 本足の部品は 1 穴の余白込み) と「離す」の組を押しのけて 300 歩、そのあと上から順にいちばん近い空いた穴の位置へ (2 本足の部品は寝かせる・立てる・向きも選ぶ)。線の引き方と比べ方は同じ。結果 (DMM の B 段 幅 59 / 照合のあるサンプル全部、arduino_mega_usb を除く): 今の棚の置き方 59 × 27 = 1593 穴・表の線 81 本 / 14206 穴・332 本、力だけ 36 × 49 = 1764 穴・87 本 / 21961 穴・337 本 (横の幅を使わず縦に伸び、10 × 15 cm の 39 行に入らない)、横に引く力を弱めても 43〜51 列 × 38〜46 行で 1938〜1980 穴・83〜98 本 / 2.2 万穴・329〜349 本、両方試すとサンプルの表の線は 275 本に減るが穴は 16381 (+15 %) で時間は倍、DMM は変わらない。照合はどれも 0。基板の自動配置で力で寄せる配置が負けたとき (2026-11-09) と同じで、棚に詰めて順に置く方が小さい。
- PathFinder 型の線引き (2026-11-21、試して見送った。コードは戻した): 3 つの形を試した。(a) 履歴だけ: 毎回は今の線引き (正しい答え) のまま、表の線が飛び越えたほかのネットの裸の線の穴に履歴 (4 か 10) を足し、次の回はその穴へ入る費用に足す。サンプルの表の線 155 → 151 本 (4)・154 本 (10)、DMM は 81 → 80 本 (基板 56 × 37 で大きい) か 81 本。(b) 交渉: ほかのネットの裸の銅 (足・表の線の端は除く) を「今の罰」(4 → 8 → 16) を払えば通れる回を 3〜5 回、2 つのネットが入った穴に履歴を足し、そのあと今の線引きに履歴を足して引く。サンプル 156〜162 本で照合 1 が出る (回の分だけ打ち切りまでに試せる置き方が減る)。DMM の置き方 16 個それぞれで線引きだけを比べると、今の線引きが合計 1223 本、交渉が 1360 本と悪く、交渉が勝つのは 6 個。(c) 罰を 1.5 倍ずつ上げて分け合いが無くなるまで (30 回まで) 繰り返し、その回をそのまま答えにする: 16 個のうち 2 個しか収まらず (89 → 86・81 → 88)。ユニバーサル基板では表の線が混み合いの逃げ道で、順に引く線引きはもうそれを使っている。交渉は道を長くして、かえって飛ぶ所が増える。
- 時間をかけて並べる (2026-11-21、試して見送った。本人が遺伝的アルゴリズムを尋ね、評価に線引きが要り 1.5 秒では数回しか評価できないので、先に時間の効き目を測った): DMM の B 段 (幅 59) で打ち切り 1.5 秒・5 秒は 81 本 (59 × 27 穴)、15 秒は 78 本 (56 × 37 穴、+30 %)、30 秒は 17.4 秒で全部試し終わり 78 本のまま。引き直しの回数 (`MORE_ROUNDS`) を 10・30 にしても 78 本。時間ではなく置き方の候補が限り。「じっくり並べる」ボタンは見送った。
- グローバル配置 → リーガライゼーション → 詳細配置の流れで、2 つを試して見送った (2026-11-21、本人の提案): (1) 広げるときの部品の場所に足の数 × 0.5〜2 穴を足す (混み合いを見る RePlAce の考え方。長方形の高さは足さない場所で決める): 表の線 158〜165 本・穴 +1〜5 % で良くならない。(2) 目標のある IC を目標の行・列の順に置く (前は棚の置き方の順): 右の端の列を直す前は 161 → 152 本だったが、直したあとは 155 → 160 本と悪くなる (前の良さは端の列との組み合わせかぶれ)。
- 二分割に FM 法 (min-cut、2026-11-21、試して見送った。コードは戻した): 最後の 10 回の広げ方で、面積の順に切ったあと、切り口をまたぐネット (電源・GND は 0.2) が減るように部品を 1 つずつ反対側へ動かす (Fiduccia–Mattheyses。1 回で全部の部品を 1 度ずつ、いちばん減るものから、半分ずつの場所が割り当てから「最も大きい部品か全体の 1/10」以内のまま。その回のいちばん良い所まで戻す。3 回まで)。範囲の外の部品と固定した足は、切り口のどちら側にあるかでネットを引く側に数える (terminal propagation)。片側が空になる分け方は使わない (無限の再帰になった)。結果: サンプルの表の線 161 → 153 本 (−5 %)、穴 15395 → 15612 (+1.4 %)。テストの小さい 3 つは表の線が同じ (0・1・1 本) で穴 442 → 469。ばねの置き方だけで比べると DMM の B 段 92 → 82 本 (56 × 33 → 57 × 28 穴)。全部の回で使う: 156 本・穴 +2.5 %、最後の 5 回: 165 本、最後の 1 回: 158 本、電源・GND を 0: 157 本、釣り合いを 3 %: 165 本 (どれもぶれの大きさに近い)。DMM は棚の 81 本のまま。効果がぶれと同じくらいで、DMM が変わらず、小さい基板が大きくなり、約 170 行増えるので見送った。
