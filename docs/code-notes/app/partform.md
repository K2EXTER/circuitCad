- 2026-11-15: IC の「かんたん作成」に「論理式からピンとモデルを作る (ロジック IC)」(`part_form/logic.rs`、候補 D の「`Y` 行を作る部品フォーム」)。入力ピンの名前と、1 行に 1 つ「出力 = 式」(名前・0・1・`!`・`&`・`^`・`|`・括弧、`not and xor or` も。強さは ! > & > ^ > |)、遅延 (ns)。`LogicInput::read` が式を読み (名前の重なり・VCC/GND・未知の名前・括弧・余りを原因つきで断る)、真理値表 (入力 5 本まで画面に) を出す。`apply_logic` がピン (入力は左、出力は右、GND・VCC) と `.subckt 名前 入力… 出力… gnd vcc` を書く。出力ごとに、その式が読む入力だけの `lut` (`td=`、`table=` は最初の入力が最下位)、入力を読まない定数は電源か GND からの `buf`。1 つの出力が読める入力は 12 本まで。出どころは generic、カテゴリはロジックIC。例: 半加算器・多数決・2→1 セレクタ。起動引数 `--new-part ic --form-logic-example`。試験 `logic.rs` (式の強さと語、誤りの文、半加算器を作って DC で 1+1 = 桁上がり、定数)。行の最後の `@ CLK`(入力ピン)でフリップフロップ: 式は `名前_d` の `lut`(遅延なし)に、`dff`(`td` はクロックから出力まで)がクロックの立ち上がりで覚える。フリップフロップの出力は、ほかの式の変数にもなる(`Logic::vars` = 入力 + フリップフロップの出力。真理値表は今の状態も列にし、出力の列は `Q+`)。`@` の無い出力を式で読むと「出力 Y は式に使えません」で断る(組み合わせのループを作らない)。例に 2 ビットカウンタ(`Q0 = !Q0 @ CLK`、`Q1 = Q1 ^ Q0 @ CLK`、過渡解析で数えることを試験)。クロックのあとに `clear [!]PIN`・`set [!]PIN`(`reset`・`clr`・`preset`・`pre` も。`!` は Low で働く)で、非同期の 0 / 1(`dff` の set・reset と `set_low`・`reset_low`。使わないほうは GND に結んで High で働く = 働かない)。例の 2 ビットカウンタは `clear !RST` 付き(試験: 途中で RST を Low にすると 0 に戻る)。
- **SolidCraft で形を作る**(`part_form/solidcraft.rs`、候補 E7、2026-11-15): 「④ 部品の形」の「STEP が無いとき: SolidCraft で形を作る」。データシートの窓(`datasheet_view.rs`)にピン表と同じドラッグの切り出しを足した(`cut_view`・`drawing_out`・`start_drawing_cut`・`take_drawing`。`cut_drawing` がページを 1 点 2〜6 ピクセル(横 1600 ピクセルほど)で描いて切り抜く)。切り出した図(`Drawing`: 上から / 横から、RGBA、印刷の幅 pt)は、小さく表示し、2 回のクリックと長さ (mm) で縮尺を決める(`width_mm`。決めないうちは印刷の大きさ)。「SolidCraft で開く」は作業フォルダ(一時フォルダの `circuitcad_solidcraft/部品名/`)に PNG と台本(`script`: たたき台の箱 `solid.box`(本体の幅・奥行き・高さ、半透明)、上から見た図は XY のキャンバス、横から見た図は x = +X・y = +Z の面を部品の後ろ(奥行きの半分 + 5 mm と上の図の幅の半分の大きい方)に立てたキャンバス)を書き、`solidcraft-cli run --save part.sc` で設計を作り、`solidcraft.exe part.sc` を開く。`solidcraft_poll` が毎秒、作業フォルダの `part.step` の更新を見て `step_load` する。SolidCraft の場所は `find_solidcraft`(`SOLIDCRAFT_DIR` → PATH → `C:\Program Files\SolidCraft`)、無ければ `SOLIDCRAFT_MISSING` の案内。撮影用の起動引数 `--form-drawing top|side "ページ,x0,y0,x1,y1"`(pt、`--form-pdf` のあと)。試験: 台本の形(箱の位置、横の図の面の向きと位置)、2 点の縮尺と PNG、SolidCraft が入っていれば台本から設計ができること(無ければ飛ばす)。SolidCraft の画面とブラウザに下絵が出ることは、XY の面と XZ の面の 2 枚で目で確かめた(2026-11-15)。いま横の図に使っている「y = +Z の面」は、設計ファイル(zip の `document.json`)の置き方で確かめただけで、画面ではまだ見ていない。
