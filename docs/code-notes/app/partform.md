- **曲線も選ぶ**(2026-11-17、B): `SheetView::start_graph` で目盛りが入ったら `Opened::pick_curve`(`datasheet::pick::pick` を「曲線に合わせる」と同じ 4 px/pt の絵で、欄は `Dest::curve`・`Dest::label_names`)。`Pick::One` は `GraphReader::auto_trace`(`add_trace` と、読んだ目盛りと曲線の名前の文)、`Several(n)` はクリックを頼む文。詳細は段階14。
- **表とグラフから全部読む**(2026-11-17): トランジスタ・ダーリントン・ダイオード・フォトカプラ・フォトダイオードの節のボタン(`PartForm::read_all_button`)。`read_all_graphs(dests)` は節の「PDF の表から読む」(`fill_from_pdf`、ダイオードは `dio_fill_from_pdf`)のあと、欄ごとに `SheetView::read_curve(dest)`(見出しの図を 3 枚まで順に: `figure_axes` → hFE の比 (縦の目盛り 5 以下) は飛ばす → `pick_curve_on` → `GraphReader::set_axes`/`auto_trace`/`values`。窓とページは動かさない)で読み、`take_read_curves` が `put_graph`(手で送るのと同じ入れ方)で欄に入れて 1 欄 1 行の結果 `graph_all`(読めた図のページ・点の数・どのラベルの曲線か、読めない理由)を出し、1 欄でも読めたら節のモデルを作る(`bjt_fit` など)。読めなかった欄は前の中身のまま。ダイオードの順方向は電流が 1.5 倍以上離れた点に間引く(`apart`、いちばん大きい電流は残す: 当てはめが近い点を断るため)。`--form-graph-all bjt|darl|diode|opto|pd|reg` は結果とモデル(読んだ点ごとのずれも)を標準エラーに出す(手元の PDF で通すため)。続けて `--form-save DIR` で、節の「② シミュレーション」に入れる(`use_model_and_save`)と保存ボタンと同じことをして `DIR` に部品を書いて終わる(`ccad --lib DIR` で回路に置いてシミュレーションするため)。
- **レギュレータのグラフ**: レギュレータの節にも「表とグラフから全部読む」(`Dest::RegDropout`・`RegRipple`・`RegNoise`、表は `RegulatorInput::fill_from_pdf`) と、1 枚ずつの「グラフから読む」のボタン。曲線は欄ではなく値に: `RegulatorInput::take_graph` が、ドロップアウトの点に直線を当てて `vdo0`・`rdo` (`dropout_line`)、リップル除去は欄の周波数 (空なら 120 Hz) の値、雑音は 1 kHz の密度 (`at_frequency`) を、表に値が無いときだけ入れる。`take_read_curves` はこの節の行に `take_graph` の行 (入れた値か理由) を出す。`read_curve` は周波数の図の横軸が対数でなければ飛ばす。`--form-graph-all reg` は表の行も「table:」で出す。`reg_roles` は「② シミュレーション」に入れるときのピンの役 (`--form-save` も)。
- **電圧違いの型番**: `RegulatorInput::variants` (`reg_fill::variants`、`PartForm::reg_find_variants` が表を読む 3 か所で作る)。ボタンで `reg_choose_variant`: 型番を部品名にして `fill_from_pdf` をやり直し、出力電圧が空なら型番の電圧。`--form-graph-all reg` は「variants:」の行も出す。
- **パッケージごとのピンの列**: 下書きの `pin_sources` は `Datasheet::find_pin_tables` (列ごとに `FoundPins::package`)。`pins_of_package` で選んだパッケージの列を `pin_pick` に (作るときとパッケージを変えたとき)。
- **比 (normalized) の hFE の図**: トランジスタの hFE は、縦の目盛りが 5 以下の図も読み(`GraphOut::normalized`)、`hfe_scale` で表の hFE に合わせる: 曲線の山にいちばん近い電流の行(部品名のランクの行)の typ、無ければ min・max の幾何平均(同梱の 2N3904 と同じ)を、その電流の曲線の比で割った倍率。どうしたかは `BjtInput::hfe_note` からモデルの注記へ(手で点を入れ直すと消える)。表に使える行が無ければ読めない理由の行。ダーリントンの比の図は使わない。
- **図の測定の VCE**: `read_curve` は hFE・VBE(on) の図の VCE (`Datasheet::figure_condition`。選んだ曲線のラベルにあればそれ、図に 1 つだけならそれ) を `GraphOut::vce` で返し、`take_read_curves` が `hfe_vce`・`on_vce` (トランジスタとダーリントン) に入れ、行に「(VCE = 5 V)」。
- **推奨の周辺部品** (候補 Q5、2026-11-17、`companion_fill.rs`): 定格の欄の下の「推奨の周辺部品」。1 行に「名前 | C・R・L | 値 | ピン (名前か番号) | GND か相手のピン | 注」(`companions_text`)、保存は `PartDef::companions` (ピンは番号、開くと名前に戻す)。「PDF から読む」(`fill_companions_from_pdf`) は `Datasheet::capacitors` の名前ごとにいちばん多く書かれた値を、名前の指すピン (`pin_for`: CIN → VIN・IN・INPUT…、COUT → VOUT・OUT・OUTPUT…、CADJ → ADJ、CBOOT → BOOT と SW、CFF → FB と出力) と GND の間に。C1・C2 は値だけ知らせる。回路図はプロパティの「推奨の周辺部品を置く (n)」(`Schematic::place_companions`)。`--form-companions` と、`--form-graph-all` なしの `--form-save DIR` (フォームのまま保存)。
- **ピンの種類** (候補 Q7・J6 の一部、2026-11-17): ピンの行の語 `kind=in` (`sch_core::PinKind::word`、`pin_tokens` の 4 つ目、表の「種類」の列 `PinRow::kind`)。「指定なし」のときは名前からの推測を「(出力?)」と薄く見せ、「名前から種類を入れる」(`guess_kinds`) で入る。ピン表の取り込み (`pin_import.rs` の `lines_with_kinds`: `datasheet::io_cells` の I/O の列 → 名前) と下書き (`FoundPins::io`) は推測を入れて出す。TI の表で電源ピンの I/O が「—」なのは何も言っていないので名前で決める。部品を開くと `kind=` を書き戻す。
- **熱の表から読む** (`heat_fill.rs`): `heat_from_rows(sheet.thermal())` が θJA・θjc・下げ始める温度と行ごとの一文を返し、`fill_heat_from_pdf` が `rt_ja`・`rt_jc`・`rt_derate` と「そのほかの情報」の行 (大きい基板の θJA・θJL。同じ名前の行があれば足さない) に入れる。定格の「PDF の熱の表から読む」と下書きの定格 (`draft.rs`) から。結果の行は `rt_heat_msg`。
- **ダーリントンの内蔵の抵抗**: `DarlingtonInput::put_resistors(sheet.darlington_resistors())` を表から読む 3 か所 (欄のボタン・`read_all_graphs`・下書き) で呼び、R1・R2 を入れて「無い」の行を出どころの行に替える。
- **曲線の候補**: `read_curve`・`start_graph` で `Pick::Several(curves)` のとき、`start_graph` は `GraphReader::show_candidates` で候補を色と番号で描き、`Mode::Trace` のクリックは `take_candidate` (5 pt 以内のいちばん近い候補を丸ごと) を先に試し、無ければ `trace_at`。
- **シミュレーション専用のピン**: ピンの行の語 `sim` (`pin_tokens` の 3 つ目、表の「sim」の列 `PinRow::sim`) が `PinDef::sim_only`。パッドの数 (`to_def` の `n`) に入れない。部品を開くと `sim` を書き戻す (`keep_hidden` で元の部品から写すのはやめた)。フォトダイオードは `add_light_pin` が、IRRAD・L・LIGHT のピンが無ければ `L IRRAD bottom sim` を足す (「② シミュレーション」に入れるときと `--form-save`)。

- **表から読む: レギュレータ**(2026-11-17、C): `part_form/reg_fill.rs` の `RegulatorInput::fill_from_pdf(name, values)`(`found` に 1 行ずつ)。行は記号 (onsemi: VO・Regline・Regload・IB・VI-VO・ISC・RR・Vn) と、名前の最初の語 (TI・AMS: Reference・Line・Load・Adjustment・Minimum・Current・Ripple・Dropout・Quiescent) の両方で探す。表に ADJ の電流があれば可変 (出力の欄は Reference / VREF)。部品名の電圧 (`nominal_from_name`: MC7805 → 5、UA78L12 → 12、AMS1117-3.3、MCP1700-3302 → 3.3、LP5907-18 → 1.8、7800 は家族名で無し) の行を取り、その行のページの値を先に使う (MC7800 は電圧ごとにページ)。ライン・ロードは条件の範囲 (`span`: 「7.5 Vdc ≤ Vin ≤ 25 Vdc」17.5、「5.0 mA ≤ IO ≤ 1.0 A」0.995) が読めた行だけ、% は数のまま (「0.01%/V」「0.1% 1.49」)。電流制限は条件の電圧が 1 つの行で、「VIN − VOUT =」ならその差、「Vin =」なら出力電圧を引く (1 行だけなら知らせる)。リップル除去は条件の周波数と (可変なら VOUT も)、雑音は「µV/VO」なら出力電圧を掛け、条件の帯域と。ドロップアウト (30 mV〜5 V)・グラウンド電流・ADJ の電流・最小負荷はありうる値の行だけ (表の 1 行ずれで AMS1117 の 5 mV を拾わない)。下書きの「特性の値」は分類「レギュレータ」で使い、見出し reg_box を開く。実物: MC7800 (ライン 500 µ/17.5 V・ロード 1.3 m/1.495 A・グラウンド電流 3.2 mA・リップル除去 83 dB/120 Hz)、LM317 (基準電圧 1.25・ADJ の電流 50 µ/100 µ・最小負荷 3.5 mA・電流制限 40 V で 0.4 A・64 dB/120 Hz/10 V。ライン・ロードは条件が読めず入れない)、AMS1117 (ライン・ロードは表の単位の読みが外れて違う値になる: 確かめが要る)。
