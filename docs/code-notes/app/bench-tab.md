# 実機のタブ (B12、`bench_tab.rs`)

一番上のタブの 3 つ目「実機」(`main.rs` の `Mode::Bench`)。届いた基板を組み立てて動かすときに開く場所を 1 か所にする。候補の方針 (`candidates.md` の「一番上の画面を 4 つのタブにする」) の 4 つ目のタブで、試作のタブ (B6 ①) ができたら 回路図 → 試作 → 基板 → 実機 の順に並ぶ。

## 形

- **左**: 手順の一覧 (1. 組み立て → 2. 電源投入 → 3. 測る → 4. 合否 → 5. 修理)。済んだ手順には ✔。下に選んだ手順の中身。
- **真ん中**: 基板の配置図 (外形・部品の箱・パッド・部品番号)。読むだけの絵で、編集はしない (基板エディタのキャンバスは使わない。操作と状態が多すぎるため)。手順ごとに光るもの:
  - 組み立て: 次に付ける部品 (付けていない部品のうち、いちばん低いものから 0.3 mm 以内の高さのもの)、付けた部品は緑、向きのある部品の 1 番ピン (`1`・`K`・`+`) に赤い点
  - 電源投入: コネクタ (J・CN・P・X・BT) と、電源投入のガイドの電源の部品 (`PowerOnGuide::supply_names`)
  - 測る・合否: スペック表の行のネットのパッド (一覧で点を選ぶとそのネットだけ)、GND は青 (黒い棒)、電流の行の部品
  - 部品をクリック・一覧で選ぶと、その部品がいちばん明るく光る
- 部品の箱は、パッドの外接と `model3d::body_extent` の和。裏の部品は薄く描く。

## 手順の中身 (決めたこと: 今の窓は作り直さず、中身を関数に分けて埋め込む)

| 手順 | 中身 | ✔ の条件 |
|---|---|---|
| 組み立て | 部品を背の低い順 (`model3d::part_boxes` の高さ、メーカーの 3D の形があればその高さ、フットプリントの `height`) に並べ、付けたら印。テストポイント (`assembly::is_bare_copper`) は除く。下に `bench_guide::GUIDES` の手順書への入口 | 全部に印 |
| 電源投入 | `PowerOnGuide::contents` (窓と同じ中身)。手順を開くと `ensure_run` で計算する。この手順を見ている間は、同じ窓を重ねて出さない (id がぶつかる) | 全部の電源の測った電流が正常の範囲 (`all_normal`) |
| 測る | DC 動作点のネットごとの電圧 (`SchEditor::bench_voltages`。故障を仕込んだ what-if の結果と、回路図が変わったあとの結果は使わない)。手順を開いたとき結果が無ければ 1 回だけ DC を計算する (`dc_asked`)。スペック表の行のネットを先に太字で。「測る項目を表に入れる」(`add_measure_rows`)、学習パスの「組み立てて、性能を測る」の窓、オシロの波形を重ねる (回路図の過渡解析へ) への入口 | スペック表に行がある |
| 合否 | 回路図の解析タブと同じスペック表 (`spec_table_ui`、「実測」欄で差と合い具合が出る) | 実測が 1 つ以上シミュレーションと比べられた |
| 修理 | 回路図の「症状から原因を探す」へ、修理の練習のレッスン (`repair_` で始まる id) と基板の修理のレッスンを始める | なし |

ボタンが頼むこと (タブの切り替え・レッスン・窓) は `BenchAction` で返し、`App::bench_action` が行う。

## 基板が無いとき (決めたこと)

真ん中に「基板がまだありません」と、基板の画面へのボタン。組み立ての手順も同じ案内。電源投入・測る・合否・修理は回路図だけで動く (ブレッドボードで組んだときにも使える)。

## そのほか

- ファイルのメニューと Ctrl+S などは、このタブでは回路図に効く (このタブで書き込むもの = スペック表の実測は回路図のデータ)。
- 付けた印は、アプリを閉じると消える (ファイルには書かない)。B3 で印刷できる組み立て表を作るときに、残すかを決める。
- 起動引数 `--bench-tab [assemble|power_on|measure|judge|repair]` でこのタブを開く (撮影用)。
- 「学ぶ」メニューの電源投入のガイド・`bench_guide` の窓・「組み立てて、性能を測る」の窓は、入口として今のまま残す。
- テスト: `bench_tab.rs` の `tests` (全部の手順を基板あり・なしで描く、低い順と印、引数の名前)。

## これから足すもの (候補)

B3 (はんだ付けの順番と組み立てのチェック表の印刷・極性の印) は組み立ての手順を育てる。B7 (写真と比べる)・N4 (計測器とつなぐ)・L2 (DMM の値を並べる) は測る・合否の手順に入れる。
