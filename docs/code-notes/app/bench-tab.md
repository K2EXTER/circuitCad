# 実機のタブ (B12、`bench_tab.rs`)

一番上のタブの 3 つ目「実機」(`main.rs` の `Mode::Bench`)。届いた基板を組み立てて動かすときに開く場所を 1 か所にする。候補の方針 (`candidates.md` の「一番上の画面を 4 つのタブにする」) の 4 つ目のタブで、試作のタブ (B6 ①) ができたら 回路図 → 試作 → 基板 → 実機 の順に並ぶ。

## 形

- **左**: 手順の一覧 (1. 組み立て → 2. 電源投入 → 3. 測る → 4. 合否 → 5. 修理)。済んだ手順には ✔。下に選んだ手順の中身。
- **真ん中**: 基板の配置図 (外形・部品の箱・パッド・部品番号)。読むだけの絵で、編集はしない (基板エディタのキャンバスは使わない。操作と状態が多すぎるため)。手順ごとに光るもの:
  - 組み立て: 次に付ける部品 (付けていない部品のうち、いちばん低いものから 0.3 mm 以内の高さのもの)、付けた部品は緑、向きのある部品の印のパッドに赤い丸と文字 (1・K・+)
  - 電源投入: コネクタ (J・CN・P・X・BT) と、電源投入のガイドの電源の部品 (`PowerOnGuide::supply_names`)
  - 測る・合否: スペック表の行のネットのパッド (一覧で点を選ぶとそのネットだけ)、GND は青 (黒い棒)、電流の行の部品
  - 部品をクリック・一覧で選ぶと、その部品がいちばん明るく光る
- 部品の箱は、パッドの外接と `model3d::body_extent` の和。裏の部品は薄く描く。

## 手順の中身 (決めたこと: 今の窓は作り直さず、中身を関数に分けて埋め込む)

| 手順 | 中身 | ✔ の条件 |
|---|---|---|
| 組み立て | 部品を背の低い順に並べ、付けたら印 (順と向きの印は `pcb_core::assembly_sheet`、下の「組み立て表」)。「組み立て表を印刷用に保存 (SVG)」。下に `bench_guide::GUIDES` の手順書への入口 | 全部に印 |
| 電源投入 | `PowerOnGuide::contents` (窓と同じ中身)。手順を開くと `ensure_run` で計算する。この手順を見ている間は、同じ窓を重ねて出さない (id がぶつかる) | 全部の電源の測った電流が正常の範囲 (`all_normal`) |
| 測る | DC 動作点のネットごとの電圧 (`SchEditor::bench_voltages`。故障を仕込んだ what-if の結果と、回路図が変わったあとの結果は使わない)。手順を開いたとき結果が無ければ 1 回だけ DC を計算する (`dc_asked`)。スペック表の行のネットを先に太字で。動き続ける回路 (発振・パルス) の時間で変わる点は「平均 xV (aV 〜 bV で変わる)」(`SchEditor::running_voltages`: `running_tran` の後半が DC と違うネット。過渡解析は前の結果がその回路のものならそれ、無ければ解析タブの時間で 1 回解く。回路ごとに 1 回だけ `BenchTab::running` に覚える)。電源投入の電流も同じ過渡解析で動かす (`PowerOnGuide::run` → `PowerOn::apply_running`)。「測る項目を表に入れる」(`add_measure_rows`)、学習パスの「組み立てて、性能を測る」の窓、オシロの波形を重ねる (回路図の過渡解析へ) への入口 | スペック表に行がある |
| 合否 | 回路図の解析タブと同じスペック表 (`spec_table_ui`、「実測」欄で差と合い具合が出る) | 実測が 1 つ以上シミュレーションと比べられた |
| 修理 | 回路図の「症状から原因を探す」へ、修理の練習のレッスン (`repair_` で始まる id) と基板の修理のレッスンを始める | なし |

ボタンが頼むこと (タブの切り替え・レッスン・窓) は `BenchAction` で返し、`App::bench_action` が行う。

## 基板が無いとき (決めたこと)

真ん中に「基板がまだありません」と、基板の画面へのボタン。組み立ての手順も同じ案内。電源投入・測る・合否・修理は回路図だけで動く (ブレッドボードで組んだときにも使える)。

## そのほか

- ファイルのメニューと Ctrl+S などは、このタブでは回路図に効く (このタブで書き込むもの = スペック表の実測は回路図のデータ)。
- 付けた印は、アプリを閉じると消える (ファイルには書かない。B3 で決めた: 残す記録は印刷した組み立て表で、紙に印をつけながら進める。基板のファイルに入れると、組み立てのたびに基板が「変更あり」になり、何枚も組むときに合わない)。保存のときに画面で印をつけた部品は、表に印がついた形で入る。
- 起動引数 `--bench-tab [assemble|power_on|measure|judge|repair]` でこのタブを開く (撮影用)。
- 「学ぶ」メニューの電源投入のガイド・`bench_guide` の窓・「組み立てて、性能を測る」の窓は、入口として今のまま残す。
- テスト: `bench_tab.rs` の `tests` (全部の手順を基板あり・なしで描く、低い順と印、引数の名前)。

## 組み立て表 (B3、`pcb_core::assembly_sheet`)

- `fitting_order`: テストポイント (`assembly::is_bare_copper`) を除いた部品を、本体の高さの低い順 (メーカーの 3D の形 → フットプリントの `height` → `model3d::part_boxes` の見積もり)、同じ高さは部品番号の自然な順 (R2 が R10 より前)。種類 (`kind_of`、部品番号の文字から) も付ける。
- `mark_of`: 向きの印のパッド。`K` のパッドがあればカソード (ダイオード・LED)、電解・タンタル (`CP_`・`elec`・`tantal`・`polar` を含むフットプリント) は `+` か `1` のパッドが + 側、IC・トランジスタ・ダイオードなど (U・IC・Q・D・LED・BT) は `1`。セラミックコンデンサ・抵抗は無し。
- `assembly_svg`: A4 の幅 (210 mm) の 1 枚の SVG。見出しと使い方 3 行、上から見た配置図 (裏の部品は破線、印は赤い丸と 1・K・+)、□ つきの一覧 (順・部品番号・値・種類・向き・高さ・フットプリント)。長さは一覧に合わせる (ブラウザの印刷で何ページにも分かれる)。PDF は作らない (ブラウザの印刷から PDF にできる。回路図の SVG と同じ扱い)。
- CLI: `board assembly [F.svg]` (順と印の一覧、ファイルを付けると表)。

## これから足すもの (候補)

B7 (写真と比べる)・N4 (計測器とつなぐ)・L2 (DMM の値を並べる) は測る・合否の手順に入れる。

## 測った値を入れる (L2 の ①②、2026-11-19)

- 「測る」の表は ネット・予測・実測・差・判定 の 5 列。実測の欄に打つと (`4.98`・`4.98V`・`4.98 ±0.02`・`4.98+-0.02`・`4.98, 0.02`、`schematic::parse_reading`)、回路図のシートの `"bench"` の `"dc"` (`[{"net","v","u"}]`、`BenchData::dc`・`DcReading`) に入り、回路図と一緒に保存される (読めない間は「読めません」で、前の値のまま)。空にすると消える。打った文字は `BenchTab::typed` に残す。
- 判定 `schematic::judge`: 許す幅 `allowance` = 不確かさ・予測の 5 %・20 mV の大きいほう。予測 (動き続けるネットは平均と変わる幅) からの外れが幅以内で ✔ 合う、3 倍以内で ▲ ずれ、それより外で ✖ 大きくずれ。差は 実測 − 予測。表の上に「n 点を測りました。合っているのは m 点」。
- 回路図の結果表 (ノードの電圧) にも、実測があれば「実測」「差」(判定の色) の列。
- CSV の読み込み (`bench_data::read_table`): 全部が数字の行に加えて、時刻 (`10:00:01.5`・`2026-11-19T10:00:01Z`) のある行は、時刻を最初の行からの秒にし、ほかの数字だけを拾う (日付・単位の文字は飛ばす)。自作の DMM の記録が過渡の波形に重ねられる。
- テスト `readings_are_kept_and_judged` (`bench_tab.rs`、保存して読み戻す)、`bench_data::tests` (`readings_parse_and_are_judged_against_the_prediction`・`a_meter_log_with_dates_and_units_is_read_by_its_clock`)。
- 残り (L2 の ③): 時間の記録 (ドリフト・温度の変化) を、過渡の波形とは別に時刻の軸で重ねる。列を名前で選ぶ。回路図のキャンバスのネットのそばに実測を出す。
