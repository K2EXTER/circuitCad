# フィルタの設計 (`sim-core/filterdesign.rs`、候補 V8、2026-11-18)

アクティブフィルタの部品を、種類・形・次数・周波数から決め、回路図に置いて AC 解析で目標と重ねる。

## 作った範囲

| 項目 | 範囲 |
|---|---|
| 種類 | バターワース・ベッセル・チェビシェフ (リップル 0.01〜3 dB) |
| 形 | ローパス・ハイパス (次数 1〜8)、バンドパス (プロトタイプの次数 1〜4 = 2〜8 次) |
| 回路 | 1 次の段は RC + ボルテージフォロワ。2 次はサレンキー (ゲイン 1) か多重帰還 (ゲイン −1)。バンドパスはいつも多重帰還 |
| 値 | コンデンサは E12 から先に決め (抵抗が 10 kΩ 前後になる値)、抵抗をちょうどの値で計算してから E24 か E96 に丸める |

残り (候補の行に書いた): 段のゲインを 1 以外にする、片電源 (VCC/2 の基準)、ノッチ (帯域除去)・オールパス、楕円 (連立チェビシェフ)、周波数の代わりに減衰量の指定から次数を決める、CLI で置く (`calc filter` は値だけ)。

## 計算

- 極 (`prototype_poles`): ローパスのプロトタイプ。バターワースは単位円、チェビシェフは ε = √(10^(r/10) − 1)、a = asinh(1/ε)/n の楕円の上 (リップルの端が 1 rad/s)。ベッセルは逆ベッセル多項式 a_k = (2n−k)! / (2^(n−k) k! (n−k)!) の根を Durand–Kerner で解き、|H| が −3 dB になる ω で割る (−3 dB が 1 rad/s)。
- 段 (`prototype_sections`): 実数の極は 1 次 (Q = 0)、複素数の極は上半分の 1 つで (|p|, Q = |p| / (−2 Re p))。Q の低い順に並べる (山のある段を後ろに)。
- ローパスは f0 = fc × |p|、ハイパスは s → 1/s で f0 = fc / |p| (Q は同じ)。
- バンドパスは s → (s² + 1)/(b s) (b = 帯域幅 / 中心) で、極 p ごとに s² − p b s + 1 = 0 の 2 根。上半分の根が 1 つの 2 次の段、実数の根は 2 つずつ組にして 1 段 (広い帯域のとき)。各段の中心の利得 A = min(1, Q²) (A < 2Q² が要る)。
- 段の部品 (`design_filter`):
  - サレンキー LP: C2 = 基準の C、C1 = 4Q²C2 以上の E12。R1 + R2 = 1/(ω0 Q C2)、R1 R2 = 1/(ω0² C1 C2) の 2 次方程式。
  - サレンキー HP: C1 = C2 = C、R1 = 1/(2Q ω0 C)、R2 = 2Q/(ω0 C)。
  - 多重帰還 LP: C2 (帰還) = C、C1 (GND) ≥ 8Q²C2 の E12、R1 = R2。
  - 多重帰還 HP: C がすべて同じ、R1 = 1/(3Q ω0 C)、R2 = 3Q/(ω0 C)。
  - 多重帰還 BP: C1 = C2 = C、R3 = 2Q/(ω0 C)、R1 = Q/(ω0 C A)、R2 = 1/(ω0 C (2Q − A/Q))。
- 応答 (`Stage::h`、`FilterDesign::response`) は段の部品の値から求める伝達関数の積 (`rounded` で丸めた抵抗)。目標はちょうどの値のもの。
- 利得の決まり: どの段も遠い所の利得が 1 (多重帰還は −1)。偶数次のチェビシェフは通過域が 0〜+r dB で、遮断周波数で 0 dB (奇数次は 0〜−r dB、遮断周波数で −r dB)。多重帰還の段の数が奇数なら出力は逆さ (行に書く)。

## 画面とつなぎ

- 値の計算の窓 (`schematic/wizard.rs`): 「アクティブフィルタ」は `CALCS` の 1 つ (`designcalc::filter_design`、入力 8 つ)。番号で選ぶ入力 (ラベルの末尾が「(0 = A, 1 = B)」) はドロップダウンで出す (`choices`。オペアンプの「反転増幅にする」も同じになった)。
- 「回路図に置いて AC で確かめる」(`schematic/filter_place.rs`): 段ごとに TL072 (無ければ LM358) と部品を、ネットラベルでつないで置く (ほかのサンプルと同じく短い線 + ラベル)。入力の電源 `SIN(0 1 1k) AC 1`、シートに VCC と VEE のラベルが無ければ ±5 V。貼るのはクリップボードと同じ `paste_fragment` (空いた所を探す。使う人のクリップボードは戻す)。ネット名は FIN・FOUT・FS1A…、2 つ目からは F2_IN…。置いたあと、AC の範囲を f/100〜100 f にして解析し、目標を「実測を重ねる」の AC の点 (`bench_data`、名前「目標 (…)」、信号 V(FOUT)) として描く。位相は AC の結果と同じく続けてつなぐ。
- AC 解析 (`ac.rs` の `run_ac`): 実測 (または目標) の点がある信号は、初めから選んでおく (点がその信号の色になるように)。
- CLI: `calc filter 0 0 4 1k 0 1 0 96` (`cli/src/design.rs`)。

## 試験

- `filterdesign::tests::the_sections_match_the_textbook_tables`: 極の大きさと Q を Williams & Taylor の表 (バターワース 2〜5 次、ベッセル 2〜5 次、チェビシェフ 0.5 dB 2 次・1 dB 2〜4 次) と 2e-3 で比べる。ベッセルは numpy で独立に解いた値とも合わせた (TI の表は 0.3 % ほど違う値を載せている)。
- `the_target_passes_the_cutoff_at_the_right_level`: 遮断周波数で −3.01 dB (バターワース・ベッセル)・−r / 0 dB (チェビシェフの奇数 / 偶数)、E96 に丸めても 0.3 dB 以内、バンドパスの端で −3.01 dB。
- `the_parts_wired_as_drawn_give_the_formula`: `netlist` のとおりに理想オペアンプ (VCVS) でつないで AC 解析した答えが、`Stage::h` の式と 1e-4 で合う (段の種類すべて)。
- アプリ `filter_place::tests::a_placed_filter_follows_its_target`: 4 次バターワースを TL072 で置き、2 kHz までは目標と 0.5 dB 以内、2 つ目は別のネットで電源を増やさない。サンプル `active_filter.schjson` は `write_active_filter_example` (`--ignored`) で作る。
