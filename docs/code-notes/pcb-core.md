# pcb-core 詳細メモ (`crates/pcb-core/src`)

CLAUDE.md の地図から参照される、各ファイルの詳しい説明。

- `model.rs` `Board`/`Track`/`Pad`/`Via`/`Zone`/`Rules` ほか全データ型。銅箔は `Side` (Top/Bottom/`Inner(n)`)で表し、`Board.inner_layers`(内層の数、0=2層)と `copper_layers()` が層の一覧(上から下)。トラックとゾーンだけが内層に置け、部品・パッド・シルクは `Side::outer()` で表裏のみ。スルーホールとビアは全層につながる(ブラインド/ベリードビアは未対応)。DRC・ラッツネスト・自動配線(`autoroute.rs` は N 層格子)・IR ドロップ・ガーバー(`Copper,L2,Inr`、`export.rs` が内層を `.G1`… で出す)・発注前チェックが対応。GUIは `board_editor/layers.rs`(層数 2/4/6/8、減らすと内層の銅があれば断る。`layer_overlay` は画面右上の折りたたみ式の層パネル=作業層の選択と層ごとの表示/非表示、Lキーで順送り)。`Hole`=めっきなしの穴(長穴 `slot`/`slot_v`、部品付きは `refdes`。部品の穴は `parts.rs` の `set_part` が出し入れして部品に追従)、`Pad.slot`=めっき長穴。`footprints.rs` の `Footprint.holes`(`FpHole`)と `package.rs` の `Explicit{pads,holes}`(`PadSpec.slot`/`HoleSpec`)が元。長穴は `excellon.rs` が `G85` で出し、`gerber_view.rs` の `parse_excellon_slots` が読み戻す。部品作成フォームの「追加のパッドと穴」(`part_form/` の `parse_extras`、脚/穴/パッド)が入力口、見本は `USB_DEMO_TH`
- `drc/` (`mod.rs`・`connectivity.rs`・`geo.rs`・`silk.rs`・`thermal.rs`・`pour.rs`・`decoupling.rs`・`acute.rs` に分割。公開関数は `drc::` から使える) `check`(全体)・`clearance`・`shorts`・`connectivity`(銅の接続グループ、ネット判定) — 自動配線もこれを使う
- `current.rs` 配線の太さと電流(IPC-2221: `width_for_current`/`current_for_width`、`Board.net_currents` との照合 `net_widths`、`widen_net`) / `drc/silk.rs` の `silk_checks` はシルク注意、`decoupling_checks` はICの電源ピンのバイパスコンデンサ(無い/8mm超で警告、`MAX_DECOUPLING_DISTANCE`)、`acute_angle_checks` は90°未満の鋭角(酸のたまり。パッドやビアの上にある角は、銅で埋まるので除く)、`thermal_via_checks` は放熱パッド(`heat_pads`: 表面実装で 4mm² 以上、他のパッドの 2 倍超)の中のサーマルビアの数(2.5mm² に 1 個、最低 2 個)。同じネットのベタ(実際の銅の形で100mm²以上=`POUR_SPREAD_AREA`)が接していれば半分(`thermal_via_need`)、小さい/切れ切れなら半分にしない。`add_thermal_vias` が足りない分を格子状に置く(DRCが悪化するなら置かない、GUIは基板エディタの「サーマルビアを置く」)、`zone_checks` はベタの細いかけら(スリバー)と、どこにもつながらない銅の島(`zonefill` の実際の形で調べる)、`mask_dam_checks` は異なるネットのパッドの間のソルダーマスクの帯(0.1mm 未満で警告、`MIN_MASK_DAM`)、`missing_ground_fill` はGNDベタが無いときのヒント。どちらも発注前チェックで警告 / DRCの指摘は日本語で原因と直し方を書く
- `irdrop.rs` 配線の電圧降下(トラック・ビア・パッドを抵抗の網にして、入口のパッド(コネクタ優先)から各パッドまでの抵抗を解く。`net_drop`/`net_drops`、`Board.net_currents` の電流で mV を出す。ベタは「ハブ」に抵抗でつなぐ近似、各パッドが電流の全部を引く最悪見積り。節点が 900 を超えると計算しない)。GUIは `board_editor/width.rs` の「配線の電圧降下」(`--ir <net> <A>`)
- `body.rs` 部品の本体 `BodySpec`(四角/円+向きの印 点/棒/＋、部品JSONの `body`)→ シルク線 `body_lines`(パッドに重なる所は切る)。`PartDef::footprint` が `Footprint.silk` にして、`parts.rs` の `set_part` がシルクとして置く(`footprints.rs` の `outline` は内蔵フットプリントの本体)。部品作成フォームは `part_form/` の「本体の外形」「放熱パッド」(放熱パッドは中心の追加パッドになる)と、形のプレビュー `footprint_preview`(パッド・穴・シルク)
- `outline.rs` 曲線の外形(`round_corners`・`rounded_rect`・`ellipse`。外形は多角形のまま、曲線は細かい線分にする) / `model3d.rs` 3Dプレビュー用の部品の立体(`part_boxes`が部品ごとに複数の箱/円柱を返す。チップ+電極、ICの足、ヘッダのピン、円柱。種類は `part_kind`、高さは `part_style` でフットプリントから推測)。向きの印: ICの1番ピン側の白い点(`pin1_dot`、ピン名が「1」の部品)、ダイオード/LEDのカソード(ピン名 `K`)、電解コンデンサの−側の縞。高さは `Footprint.height`(部品JSONの `height`、`PartDef::footprint` が載せる)があればそれを使い(`part_height_on`)、無ければ名前から推測
- `zonefill.rs` ベタの銅を図形として求める(`zone_fill`: ゾーン ∩ 外形 − 他ネットの配線・パッド・ビア・取付穴・基板端のクリアランス。`i_overlay` で計算、曲線は誤差 `CURVE_TOLERANCE` 以下の短い線分)。エディタの描画(`board_editor/draw.rs`、`geometry_key` でキャッシュ)とガーバー(`gerber.rs` の `zones`)が同じ結果を使う / `outline.rs` の曲線は `ARC_TOLERANCE` で半径に応じて細かくする / `gerber_view.rs` の `Preview` は 2×2 で描いて平均する(縁がなめらか)
- `diffpair.rs` 差動ペア(`DiffPair{p,n,gap,max_skew}` は `Board.diff_pairs` に保存)。`pair_report`(長さ・スキュー・並走の長さ・間隔)、`check_pairs`(片方だけ配線/長さの差/間隔のずれ/並走が少ない。DRC実行と発注前チェックに出る)、`tune_length`(短いほうに蛇行を足す。DRCが悪化するなら何もしない)、`suggest_pairs`(`USB_DP/USB_DM` `D+/D-` などネット名から探す)。ペア配線は `autoroute::route_pair`(＋側を引いてから、－側は `RouteOptions.follow` で＋側の隣のセルが安くなる)。GUIは `board_editor/pairs.rs`(配線パネルの「差動ペア」)、「全部」自動配線もペアを先に引く。
- `shove.rs` 押しのけ配線(`add_tracks`=新しい配線を足して邪魔な別ネットの配線を脇へ寄せる、`move_track_shoving`=配線を1本動かす、`rip_up_net`=ネットの配線を全部消す。パッド/ビアに付いた端は動かさず、両端が固定の配線は `dogleg` で5本に分けて途中を45°の斜めで脇へ膨らませる(障害物の端から `√2×必要間隔` 手前から斜めを始める。短くて斜めが入らない・障害物が配線と同じ向きに近いなら押しのけない)、最大 `MAX_SHOVE`、DRC違反が減らず接続が切れるなら採用せず普通に足す)。GUIは `board_editor/shoving.rs`(経路プレビュー `route_preview`=橙の線で押しのけられる配線の今の位置(細い線)と動く先(太い線)をカーソルに合わせて出す/赤=違反。基板は変えない。1回の計算が60ms(`PREVIEW_BUDGET`)を超える基板では、結果を250ms保って間引く=約450本の配線(release)から。小さい基板は毎回計算、選択ツールで配線をドラッグ、選択パネルの「このネットの配線を全部消す」。ツール設定の「押しのけ配線」で切替)
- `smooth.rs` 配線を整える(`smooth_tracks`。同じ太さの2本がつながる角を円弧(`radius`、22.5°ごとの短い線)にし、太さが違う所(差が0.1mmより大きい時)は太い側の端を中間の太さの段差が0.08mm以下になる本数(2本以上)でなだらかにする。各配線は1つの端につき長さの半分までしか使わない=短い配線は半径が小さくなる。パッド・ビアの上でつながる2本・3本以上の分岐は触らない。パッド・ビアに入る配線の根元(`pad_taper`。パッドの縁(配線が出ていく辺)の長さと同じ幅から配線の太さへ、パッドの縁から太さの差の1.5倍の長さで段階的に細くなる涙型(四角いパッドは縁の位置でぴったり。丸い端がパッドの奥行きに収まるよう、幅は奥行きの2倍まで。丸・長円のパッドとビアは平らな縁がないので、中心から直径の幅で始める。端が中心から0.05mm以上ずれていれば何もしない)。短い配線は何もしない)。全部まとめて試してDRC違反が増える/接続が切れるなら、1つずつ試して無害なものだけ採用)。GUIは `board_editor/smoothing.rs`(「③ 配線」の「配線を整える」)
- `ratsnest.rs` 未配線(`Airwire`) / `autoroute.rs` 格子A*の自動配線 (`autoroute`, `route_airwire`、DRCで検証して採用)
- `netlist.rs` 回路図→基板の取込 / `parts.rs` `place_part` / `footprints.rs`・`package.rs` フットプリント
- `fab.rs` 発注先プリセット(`PRESETS`)と発注前チェック(`preflight`) / `gerber_view.rs` 書き出したガーバー・ドリルを読み戻して絵にする(`Preview`)
- `export.rs` 製造一式 (zip) / `gerber.rs` / `excellon.rs` / `assembly.rs` BOM・部品配置CSV / `strokefont.rs` シルク文字
