# データシート窓 設計メモ(部品作成フォームにPDFを組み込む)

状態: 段階1(窓: PDFを開く・描く・ページ送り・拡大縮小・ドラッグ&ドロップ)と段階2(語の位置・検索・枠の重ね描き・ヒット一覧)、段階3の最初(日英の見出しボタン・部品名と分類の候補・部品名の「PDFから選ぶ」)まで実装済み。段階3の残り(寸法・定格の欄ごとの入力先)と段階4以降は未着手。調べた結果は末尾の「事前調査」。

## 目的
- データシートのPDFを、部品作成フォームの横で開いて見ながら入力できるようにする。
- PDFの文字を検索し、該当箇所を絵の上に枠で示す。クリックした数値をフォームの欄に入れる。
- 入れた値・ピン表が、PDFの内容と合っているかを点検する。**AIは使わない**(外部に何も送らない)。
- 自動で部品を作るのが目的ではない。人が確認して確定する。確認の手間を減らすのが目的。

## 構成
### 新しいクレート `datasheet` (GUI非依存)
`app` から使う。`part-lib` には入れない(描画の依存が重く、`cli` や他が引きずられるため)。

| 関数・型 | 内容 |
|---|---|
| `Datasheet::open(bytes)` | PDFを開く。パスワード付き(空のパスワードで開けないもの)は日本語で断る |
| `Page::render(scale) -> Rgba` | ページを絵にする (`hayro::render`) |
| `Page::words() -> Vec<Word>` | `Word { text, rect }`。`rect` はページ座標(左上原点、pt)。文字ごとの位置を、同じ行で隣り合うものを1語にまとめる |
| `Page::lines()` | 語を行にまとめる(表の行の復元に使う) |
| `search(&Datasheet, query) -> Vec<Hit>` | 全ページから検索。大文字小文字・全角半角・ハイフン類を同一視 |
| `parse_value(text) -> Option<Value>` | 数値と単位(mm・in・mil・µm)。`0.65 BSC` `1.27±0.1` `.050` も読む。mm に換算して返す |
| `pin_table::find(&Page) -> Vec<PinTable>` | 「Pin / No. / Name / ピン」の見出し行から表を探し、`(番号, 名前)` の行を返す。見つからなければ空 |

- 描画は `hayro`、文字と位置は `hayro-interpret` の `Device::draw_glyph_run`(実験で確認済み)。
- 文字が1つも取れないPDF(スキャン)は「このPDFは画像です。文字は検索できません」と出し、絵の表示だけは使えるようにする。
- 絵のキャッシュは `(ページ, 倍率)` ごと。1ページ約10msなので同期で描く。重ければ別スレッドにする。

### `app/src/part_form/datasheet_view.rs` (窓)
- フォームとは別の `egui::Window`(フォームの幅が 760〜1040 で固定されているため、横に足さない)。「データシートを開く」ボタンと、PDFのドラッグ&ドロップで開く。
- 上部: ページ送り・拡大縮小・検索欄・ヒット一覧(クリックでそのページと位置へ)。
- 本体: ページの絵。検索ヒットは黄色の枠。ドラッグで移動、ホイールで拡大縮小。
- 「入力先」モード(下記)のときだけ、語にカーソルを合わせると薄い枠で候補を示す。
- `PartForm` に `pub sheet: Option<datasheet_view::SheetView>` を足す。フォームを閉じたら捨てる。最後に開いたPDFのパスは `Prefs` に保存する。

## フォームとのつなぎ方: 「入力先」
各欄の横に小さなボタン(アイコン、`on_hover_text` は「データシートから選ぶ」)を置く。押すと `sheet.target = Some(Target::…)`:
1. データシート窓の上に「**ピッチ** の数字をクリックしてください」と出る(Escで取り消し)。
2. 語をクリックすると `parse_value` で読み、フォームの欄に入れる(単位が in/mil なら mm に換算して、換算したことを知らせる)。
3. 入れた欄に「p.12」の小さな印が付く(クリックでそのページへ戻る)。

対象の欄: ピッチ・列間隔・パッド長・パッド幅・対向パッド間隔・穴径・本体の幅と高さ・高さ・定格(最大電圧など)。

### ピン表の取り込み
1. 窓で「ピン表を選ぶ」→ 表を四角でドラッグして囲む(`pin_table::find` が見つけた候補は、最初から枠で示す)。
2. 囲んだ範囲の語を、行ごとに「番号 名前」にまとめた**案**を表で出す。名前の上線(`RESET` の否定)、`/` 区切りの別名なども、そのまま見せる。
3. 人が直して「ピン表に入れる」を押すと `pins_text` に入る。向きは既存の規則(前半が左、後半が右)に任せる。

## 点検(AIなし)
`Problem { message, hint, severity }` の形で、フォームの下かタブの ⚠ に出す(既存の ERC と同じ書き方。hint に原因と直し方を書く)。
- **ピンの点検**: `pins_text` と、PDFのピン表を突き合わせる。番号の過不足、名前の食い違い、本数の違い。表が見つからなければ「確認できません」(合格とは出さない)。
- **寸法の点検**: 入れた値(ピッチ・パッド・外形)が、PDFの**「推奨ランドパターン」付近の数字の中にあるか**を調べる。ない値は「データシートに見つかりません。単位(in/mm)や転記を確認してください」。値が合うことの確認で、寸法の意味までは判断しない。
- 全部の寸法が見つかるか、人が「確認した」を押したときに、`land_unverified` を外せる(外すのは人。自動では外さない)。

## 保存するもの
- `PartDef.datasheet`: 今は URL のメモ。ファイルのパスも入れられるようにする(相対パスは部品ファイルからの位置)。
- 任意で `PartDef.sources: Vec<{field, page}>`(どの値をどのページから取ったか)。後回しでよい。

## 段階(各段階で動く状態にする)
1. **窓**: `datasheet` クレート(開く・描く)+ 窓(ページ送り・拡大縮小・ドラッグ&ドロップ)。 `THIRD_PARTY_LICENSES.txt` を作り直す。
2. **検索と枠**: `words`・`search`・ヒット一覧・枠の重ね描き。
3. **入力先**: `parse_value`・欄ごとのボタン・出どころの印。
4. **ピン表**: `pin_table::find`・囲んで取り込む・案の表。
5. **点検**: ピンの点検・寸法の点検・`land_unverified` の扱い。
6. (任意)`ccad datasheet find <pdf> <語>` を CLI に足す。エージェントが同じ検索を使えるようにする。

## テスト
- 小さなPDFをテスト内で組み立てる(1ページ・既知の文字列・既知の位置)。語の位置とヒットの位置、`parse_value` の表(`1.27` `.050in` `0.65 BSC` `±0.1` など)を確かめる。
- 実物のデータシートでの確認は、手元のPDFを使う `--ignored` テスト(部品ごとに期待のピン表を持つ)。PDFは再配布できないので、リポジトリには入れない。

## リスクと未確認
- 実験した範囲は2つのPDFだけ(AO3400A、LM393)。埋め込みなしの標準フォント (Helvetica) の文字は取れることをテストで確認した。そのほかの埋め込みなしフォント (日本語のMSゴシックなど) は未確認。
- 枠の幅はグリフの送り幅(`advance_width`)から出す。埋め込みなしの標準フォント (Helvetica) で、幅がフォントの定義どおりに出ることはテストで確認した。Type3 フォントは送り幅が取れないので、フォントサイズの半分で概算する。縦書き・回転した文字は、1文字ずつの語になる。
- ページの回転(`/Rotate`)がある場合に、座標の変換が合うかは未確認。
- 公式の説明で、Unicode抽出は「実験的」とされている。結合文字や特殊なフォントで文字が欠ける可能性がある。
- パスワードを聞く窓は作っていない(空のパスワードで開けるPDFだけ開ける)。
- 追加する依存で、ライセンス一覧は463→483クレートに増えた(brotli・skrifa など。ビルドは約1分増)。バイナリの増加量は未測定。
- 画像として入った図の中の寸法は読めない。人が目で見て入れる(窓はそのために絵を出す)。

## 事前調査(2026-11-02)
- hayro 0.8(純Rust、unsafeなし、MIT/Apache)で、描画は1ページ約10ms。pdfium と見た目はほぼ同じ(差は縁の処理だけ)。
- 文字と座標は hayro-interpret で取れ、絵に重ねた枠と一致した。pdfium は不要(DLLの同梱もなし)。
- 検証コードは作業用の一時フォルダにあり、リポジトリには入れていない。
