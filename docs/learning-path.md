# 学習パス: 安定化電源を作ろう

「学ぶ → 学習パス: 安定化電源を作ろう…」で開く、入門から実機までの道筋です。目標は、**ACアダプタや電池の電圧を、負荷が変わっても一定の 5V にする電源を、原理から理解して、回路図・基板・実機まで自分で作れる**ことです。

進み具合 (完了したレッスン) は、`%APPDATA%\circuitCad\progress.json` に保存されます (Windows 以外は `~/.circuitcad/progress.json`)。消したいときは、窓の「進み具合をリセット」を押すか、このファイルを削除します。

## 安全のきまり (実機の実験)
- 実験は **12V 以下の低い電圧**だけで行います。電池、ACアダプタ (直流出力) など、市販の絶縁された電源を使います。
- **商用電源 (100V) の配線は行いません。** 整流のレッスンのシミュレーションは 100V を使いますが、実機では、小さなトランスの低電圧の出力など、絶縁された交流だけを使います。
- 電源には、直列に小さな抵抗やヒューズを入れて、ショートしても電流が流れすぎないようにします。
- 電解コンデンサは、極性と耐圧 (使う電圧の 2 倍以上) を確かめます。逆につなぐと破裂することがあります。
- 発熱する部品 (レギュレータ、パワー抵抗) は、熱くなります。触って確かめる前に、温度計を使います。

## 実験に使う道具 (目安)
テスタ、ブレッドボードとジャンパ線、抵抗セット (E24)、LED、ダイオード (1N4148 / 1N4007)、ツェナー (5.1V)、電解コンデンサ (100µF〜1000µF、25V 以上)、トランジスタ (2N3904 など)、オペアンプ (LM358)、基準電圧 (TL431 など)、三端子レギュレータ (7805)、ヒューズ、ACアダプタ (直流 9〜12V)。あると便利なもの: オシロスコープ、温度計 (放射温度計)、パワー抵抗 (負荷の代わり)。

## 実験の記録 (これから作るもの)
いま、新しい3つのレッスン (ダイオード・ツェナー・エミッタフォロワ) には、レッスンの窓の「実機で確かめよう (実験)」に、用意するもの・配線・測り方・期待される値・安全上の注意が付いています。他のレッスンにも、順に付けます。そのあと、次の機能を足す予定です。

1. 目的 / 用意するもの / 回路 (シミュレーションと同じ) / 測り方 / 安全上の注意
2. **シミュレーションの予想値**を示し、**測定値を入力すると差を表示**する
3. 差の理由の手がかり (部品の誤差、電池の内部抵抗、テスタの精度、モデルの限界) を出す

## 作る順序 (このパスの実装)
1. ✔ 土台: 学習パスの窓、完了の保存、メニューの ✔ 表示、道筋の定義 (`crates/app/src/learn.rs`)
2. ✔ 入門・基礎のレッスン: ダイオードの特性 / ツェナー / エミッタフォロワ (リップルは、整流のレッスンに含めました)
3. 応用のレッスンを足す (✔ 直列レギュレータ (レッスン 18: ツェナー 3.3V + LM358 + 2N3904、生成 `write_series_regulator_example`) → ✔ 78xx (レッスン 19: 7805、生成 `write_78xx_example`) → ✔ 熱と定格 (レッスン 20: 7805 の回路で発熱を見積もる。「値の決め方」に「熱 (温度と放熱板)」を追加) → ✔ 保護 (レッスン 21: 逆接続をダイオード・P チャネル MOSFET で止める、ショートの大電流、「値の決め方」に「ヒューズの選び方」を追加。生成 `write_protection_example`) → ✔ 故障の連鎖 (レッスン 22: コイルのレアショート。故障パネルの「連鎖故障を追う」で、コイルだけが焼ける場合と駆動のトランジスタまで壊れる場合を比べ、ヒューズで止める。生成 `write_coil_example`)) → ✔ 可変電源 (レッスン 23: トランス+整流+LM317、R2=ダイヤルで出力が変わる式と、入力の余裕で出せない電圧。生成 `write_variable_supply_example`)

## 道筋を変えるには
`crates/app/src/learn.rs` の `PATHS` に、段階 (`Stage`) と項目 (`Item`) を足します。レッスンの項目は、レッスンの `id` (`crates/app/src/schematic/lessons.rs`) で指定します。準備中の項目は `planned(...)` で書きます。道筋に書いたレッスンが存在することは、テストが確認します。

## 作ってみよう (チャレンジ)
レッスンの窓の「チャレンジを始める」、または学習パスの「作ってみよう」で始めます。

- **むずかしさ**: 「配線だけ」(部品は置いてある) と「部品も置く」(電源だけ置いてある)。
- **判定する**: ERC にエラーがないか、出力のネット (ラベル `VOUT`) があるか、負荷 1kΩ / 330Ω で出力が目標の範囲か、入力が変わっても保たれるか、部品が定格を超えないか、を順に調べます。✖ の項目には、直し方のヒントが出ます。
- **ヒント**: 3 段階 (何を作るか → 値の決め方 → 答えの目安)。**答えの回路を見る**で、できあがりを見られます (Ctrl+Z で自分の回路に戻せます)。
- 通過すると、学習パスの「✔ 作ってみよう」になります。

| チャレンジ | 目標 | 判定で見るもの |
|---|---|---|
| 分圧 (レッスン 1) | 5V から 3.3V | 無負荷で 3.2〜3.4V、100kΩ の負荷でも 3.1〜3.5V、電源の電流 5mA 以下 |
| LED (2) | 約 10mA で光らせる | LED の電流 7〜13mA、20mA 以下 (定格) |
| RC フィルタ (3) | カットオフ約 1kHz | 1kHz で −2〜−4dB、100Hz で −1dB 以上、10kHz で −15dB 以下 |
| ツェナー (16) | 9V から約 5V | 負荷 1kΩ / 330Ω、入力 8〜10V、定格 |
| エミッタフォロワ (17) | 約 4.4V を重い負荷でも | 負荷 220Ω / 47Ω で 4.2〜4.6V、定格 |
| 反転増幅 (14) | ゲイン −10 | 入力 0.1V / 0.2V で、出力 −1.0V / −2.0V |
| 直列レギュレータ (18) | 9V から約 5V (ツェナー 3.3V + LM358 + 2N3904 + 分圧) | 負荷 100Ω / 47Ω で 4.8〜5.2V、入力 8〜12V、定格 |

| 最終課題 (学習パスの「安定化電源を自分で設計する」、レッスン 21 からも) | 9〜12V から 5V。逆接続でも出力に逆電圧が出ない | 負荷 100Ω / 22Ω で 4.8〜5.2V、入力 9V / 12V、入力を −12V にしても出力 0V 付近、コンデンサ 2 個以上、定格。答えは 7805 + 1N5819 + 330n・100n。ヒューズは判定できないので、「ヒューズの選び方」で自分で決める |

## 樹形図のパス: Arduino 互換ボード (`ARDUINO_PATH`)

安定化電源のパスは直線ですが、Arduino 互換ボードのパスは**樹形図**です。電源のバイパス・水晶・リセット・ピンの LED はほぼ独立しているので、`requires` で前提を書き、順番を強制しません(鍵はかけず、「先に済ませると分かりやすい」を出すだけ)。電源パスの項目 (`divider` `led` `board`) を前提にできます。

- 土台(スキル): データシートの読み方 / プルアップ・プルダウン / バイパスコンデンサ
- マイコンが動く条件: 水晶とクロック / リセット回路
- つなぐ: ピンで LED / 3.3V と 5V のレベル変換 / シリアルと USB 変換(発展)
- 設計して基板に: 回路図を描く(最終課題) / 基板の置き方の勘所 / 基板にして発注の準備
- 作って動かす: 表面実装のはんだ付け / ブートローダと LED の点滅

レッスン24 水晶 `crystal`(USB の電気の基本は、段階「3b. 発展: USB につなぐ」の 32 `usb_power`・33 `usb_speed`・34 `usb_signal`、基板レッスン5 `board_usb`)、25 リセット `reset`、26 バイパスコンデンサ `decoupling`、27 プルアップ `pullup`、28 ピンの LED `pin_led`、29 レベル変換 `levels`、30 シリアル `serial`、31 データシート `datasheet`、最終課題 `draw_arduino`(「作ってみよう」)、基板レッスン4 `board_arduino`(置き方の勘所と配線)があり、はんだ付け以降は道すじだけ(`plan` = 準備中)。レッスンを書いたら、`plan(...)` を `lesson(...)` に替え、`requires` を `Item { requires: Some(&[...]), ..lesson(...) }` で付ける。サンプル回路は `docs/examples/arduino_minimal.schjson`(水晶の部品 `XTAL_16MHz_3225` つき)。

## 安定化電源のパスも樹形図 (`POWER_PATH`)

安定化電源のパスも、各項目の `requires` で前提を書いた樹形図です(もとは 25 項目の直線)。段階 (1〜4) は見出しとして残り、順番は強制しません。

- 根: `divider`(電圧を分ける)と `led`。この2つは、並行して学べます。
- 入門の枝: `divider` → `coin_cell`・`opamp_noninv` → `opamp_inv`。
- 部品の枝: `led` → `diode_curve` → `rectifier`・`zener`、`led` → `bjt_switch`。`zener` と `bjt_switch` が揃うと `emitter_follower`。
- 合流: `opamp_inv` と `emitter_follower` が揃うと `series_regulator`。`emitter_follower` の先に `regulator_78xx` → `heat`・`protection` → `coil_layer_short`、`rectifier` と合わせて `variable_supply`、`regulator_78xx` と `heat` で `buck`。
- 最終課題 `draw_psu` は、`series_regulator`・`regulator_78xx`・`protection` が前提。そのあと `board` → `board_copper`・`board_fix` → `build_psu`。
- Arduino のパスの「LED と抵抗」「電圧を分ける」「基板」は、この木の項目を前提にしています(別のパスの項目も指せる)。
- 進み具合の記録は項目の id のままなので、直線のときの記録がそのまま使えます。`requires` を書かない項目は、従来どおり「直前の項目が前提」になります(テストは小さな直線のパスで確かめる)。
- 追加のレッスン(樹形図の枝): `tl431_ref`(37、TL431。`zener` の先。基準電圧を好きな値にする)と `ldo`(36、LDO。`regulator_78xx` の先。入力の余裕と発熱)。
