# 基板エディタの使い方

回路図 → ネットリスト → 基板パターン → 製造ファイル、の順に作業します。


## 左パネルの構成
左パネルは、作業の流れに合わせて並んでいます。
- **ツール** (選択・配線・ビアなど) と、元に戻す / やり直し。
- **作業の設定**: 銅箔の層数、グリッド、選んでいるツールの設定 (パッド径、取付穴、ゾーンなど)。
- **① 部品を並べる**: 回路図から取り込み、部品を並べる、基板の外形。部品か外形が決まるまでは開いていて、決まると、最初から閉じています。
- **② 自動で配線**: (チェック「表面も GND のベタで埋める」(最初はオン)のとき、「GND ベタ」は裏面に加えて表面の空いた所も GND の銅で埋め(表面の GND パッドごとのビアは要らず、表と裏をつなぐビアは1個だけ。スルーホールの GND パッドがあれば0個)、自動配線はその上を通る形で配線します。ベタは配線から隙間をあけて塗られ、ルール違反が増えるときは表面には置きません) 自動配線 (「未配線を全部つなぐ」「選んだネットだけ」) と、「引き方」(45°・自動経路・押しのけ・パッドに垂直・線幅・ビア)。
- **③ 整える**: パッドの根元をそろえる、配線を整える (角の丸み・涙型・分かれ目)。最初は閉じています。
- **高度な配線** (中級者向け。「配線」ツールを選ぶと、その設定枠の中に出ます): 配線の太さ (電流から)、差動ペア、長さ合わせ。最初は閉じています。
- **④ 確認して発注**: DRC、3D、発注の準備。

## 流れ
1. **回路図モード**で回路を描く。部品のフットプリントは部品ごとに選べます(既定: 抵抗 `R_0805` など)。
2. **基板パターン**に切り替え、「回路図から取り込み」。部品が基板の外側(右側)に並び、パッドにネットが付きます。
   回路図を直したら、もう一度取り込めば差分だけ反映されます(位置と向きは保たれます)。
3. 「部品を並べて外形を決める」(自動配置) を押すと、つながりの強い部品が近くなるように並び、外形も部品に合わせて決まります。
   向きも、黄色の線が短くなるように半回転させて決めます。叩き台なので、このあと手で整えます。手で決めるなら: 基板外形を決める(矩形 / 多角形 / 幅と高さの数値入力)。部品を選択ツールでドラッグして配置。`R` で回転。
4. 配線する。未配線は黄色の線(ラッツネスト)で表示され、つなぐと消えます。
5. 必要なら銅箔ゾーン(GNDベタ)を描く。
6. 「DRC を実行」。違反の一覧をクリックすると、その場所へ移動します。
7. 「発注の準備…」(左パネル、または「ファイル → 発注の準備・製造ファイルの書き出し」)で、発注先を選び、チェックして、書き出します。DRC 違反や未配線が残っていると書き出せません。

## 操作
| 操作 | |
|---|---|
| 左クリック | 配置 / 選択 / 配線の折れ点 |
| 右クリック | 描いている配線・多角形を確定 (3点以上の多角形は閉じる)。何も描いていないときは選択ツールに戻る (AutoCAD と同じ) |
| Esc | 配線・多角形の入力を中断 |
| 中ドラッグ、ホイール | 移動、拡大縮小 (選択ツール以外では右ドラッグでも移動) |
| Alt + 左ドラッグ | 移動 (ホイールボタンが使えないマウス・タッチパッド向け。どのツールでも使えます) |
| 選択ツールで左ドラッグ | 完全に囲んだものを範囲選択 (Shiftで追加) |
| 配線・ビアのツール | クリックする点は、グリッドより、すでにあるパッドの中心・ビアの中心・同じ面の配線の端 (自動配線の線の端も) を優先して吸い付きます (緑の丸が出ます)。自動配線の格子は、グリッドの約数 (0.5mm なら 0.25mm) なので、グリッドの点も使えます |
| 選択ツールで右ドラッグ | 少しでも触れたものも範囲選択 |
| ネットを光らせる | 選択ツールで、パッド・配線・ビア・ベタにカーソルを合わせると、同じネットの銅が水色に光り、ネット名が出る。大きなベタにはネット名の文字が出る(「ネット名」の目のスイッチに従う) |
| 配線ツールの「幹で引く (2パッド→太い1本)」 | QFN の2本の LX ピンのように、同じネットで隣り合う2つのパッドから、太い1本を引き出す。パッドを2つクリックして、最後に幹を伸ばす先をクリックする。パッドの近くは、細い首 (線幅と同じ太さ、パッドの短い辺より細くはならない) が約 0.4mm、そのあとが、2つのパッドの外側の縁までの太さの幹になる。合流の所に空きができず、すき間を埋める必要がない形。近くに別のネットがあって、間隔が足りなくなるときは、引かずに理由を出す(ツールの説明の欄)。右クリックで選んだパッドを取り消し。縦か横の1列に並んだ、表面実装のパッドが対象(配線ツールの設定のチェックで切り替える) |
| 部品番号の文字 (シルク) | 選択ツールで文字をつかんで、好きな所へドラッグできる(配線やパッドに重なるとき)。部品を動かすと、文字も同じ間隔のまま付いてくる。Delete か左パネルの「元の位置に戻す」で、自動の位置(部品の上)に戻る。基板ファイルに保存され、ガーバーにも動かした位置で出る |
| 部品を 2 個以上選ぶ | 左パネルに「整列」(左・右・上・下揃え、縦・横の線に中心、等間隔)。端や中心はパッドを囲んだ四角が基準。固定した部品は動かない。配線は動かないので配線の前に使う |
| 画面右上の「物の表示とロック」 | 種類(部品・パッド/穴・配線・ビア・ゾーン・シルク・未配線・ネット名・定規・反対の面)ごとに、目で表示/非表示、鍵でロック(選べず動かせない)を切り替える。配線やビアを囲んで動かすときは、部品とパッドをロックすると巻き込まない。「反対の面」は初期状態でロック中(作業中の面の物だけ選べる) |
| 「作業中の面だけ」(初期はオン) | 枠の色の面にある物だけを選べる。薄く表示している反対の面の配線や部品は、選ぶことも動かすこともできない。ビアとスルーホール部品はどちらの面でも選べる |
| 部品の「固定」(選択パネル、または「部品を全部固定」) | 配置が済んだ部品を、ドラッグ・回転(R)・面の付け替え(B)・範囲選択での移動から守る。固定した部品には鍵のマークが付き、基板ファイルに保存される。選ぶことはできるので、そこから「固定を外す」で戻せる |
| Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z) | 元に戻す / やり直し |
| Delete | 選択項目を削除(部品は回路図側で削除) |
| R | 選択した部品を回転 |
| B | 選択した部品を表面⇔裏面に移す |
| L | 作業層(表面/裏面)の切替 |
| F | 全体表示 |
| 配線中に V | その点までの配線 → ビアを置く → 反対の層で続ける |
| 配線中に Space | 曲がり方(直線→斜め / 斜め→直線)を反転 |
| 多角形 | クリックで頂点、ダブルクリック・Enter・最初の点をクリックで確定 |

画面の上と左の**定規 (mm)** で、実際の寸法が読めます。拡大すると目盛りが細かくなり (5mm → 1mm → 0.2mm ...)、オレンジの印がカーソルの位置です。左パネルの「表示 → 定規 (mm)」で消せます。

配線モードは「45°」「直角」「自由」。配線の端は、パッドとビアの中心に吸着します。
配線・パッド・ビアのどれかを選ぶと、同じ電気的なつながりが白く強調されます。

## 発注の準備
「発注の準備…」を開くと、次の順に進めます。

1. **発注先を選ぶ**: 標準 (安全側) / JLCPCB / PCBWay / OSH Park から選びます。数値は各社が公開している 2層・板厚 1.6mm・銅箔 1oz の最小値の目安で、
   「ルールをこの発注先に合わせる」を押すと、DRC の最小線幅・間隔・穴径・アニュラリング・基板端との間隔と、配線の太さ・ビアの大きさの初期値がその値になります
   (1回だけ「元に戻す」で戻せます)。最新の値は、必ず発注先のページ(リンクあり)で確認してください。
2. **発注前のチェック**: 基板の外形、部品が基板の上にあるか、未配線、DRC、発注先の最小値、シルクの重なり、ICのバイパスコンデンサ、配線の鋭角、放熱パッド (QFN や ESOP の中央のパッド、SOT-223 のタブ) のサーマルビアの数、ベタの細いかけらや孤立した島、パッドの間のソルダーマスクの帯 (0.1mm 未満だと、製造時に剥がれてはんだがつながることがあります)、部品表の空欄、一番小さい穴、取付穴の有無を調べます。
   ✖ は直さないと書き出せません。場所のある注意には、行の頭に [1] [2] … の番号が付き、基板の上にも同じ番号の印 (✖ は赤、▲ は橙) が出ます。同じ注意が複数の場所にあるときは、すべての場所に印が出ます。行をクリックすると、その場所へ拡大して移動し、印が大きく脈打って、注意の文が横に出ます。
3. **出来上がりを見る**: 書き出すファイルを実際に読み戻して、基板の絵にします (表/裏、ソルダーマスク、シルクの切替、穴の一覧つき)。
   金色 = むき出しの銅、緑 = マスクをかぶった配線、黒 = 穴、白 = シルク。配線の抜けや穴の位置、ゾーンの隙間を目で確かめられます。
4. **書き出す**: 出力先のフォルダを選ぶと、ガーバー・ドリル・部品表 (BOM)・部品位置 (CPL)・まとめの zip を作ります。ファイルの中身の説明も出ます。
5. **注文する**: 書き出したあとに、選んだ発注先の注文手順を表示します。

窓のいちばん下の「部品の購入リスト (買うもの)」では、基板に載せる部品を、値・形・使う場所ごとにまとめた表で見られます。基板の枚数を入れると、その分の必要数が出ます。「予備を足す」を入れておくと、小さなチップ部品 (抵抗・コンデンサ・コイル・LED) に、2個か全体の1割の多いほうを足した「買う数」が出ます (ICやコネクタには足しません。目安です)。右の店のボタンは、部品に店の型番が登録されていればその店の部品のページ、無ければ値と大きさでの検索ページを開きます。買う前に、店のページで値と大きさを確かめます。「CSVに保存…」で、表計算ソフトで開ける形に保存できます。

## レッスン
「学ぶ → 基板編. 回路図から基板をつくる」で、取り込み → 配置 → 配線 → DRC → 発注の準備、の流れを案内つきで体験できます。

## GND ベタ(ボタン)
- 左パネル「② 自動で配線」の「GND ベタ」: 基板の裏面ぜんぶを GND の銅箔(ゾーン。基板の端から 0.5mm 内側まで)にして、表面の GND パッド(SMD)ごとに、まっすぐな短い線で近くのビアへつなぎます。スルーホールのパッドと裏面のパッドは、ベタに直接つながります。GND の長い配線が要らなくなります。
- 部品を並べて外形を決めたあと、「全部」の自動配線の前に押します。自動配線は、GND 以外の線だけを引きます。ビアは、DRC 違反にならない一番近い所に置きます(置けなかったパッドは、自動配線が線でつなぎます)。
- 四角い外形の基板で使えます。ほかの形は「銅箔ゾーン」ツールで描きます。もう置いてあれば何もしません。「元に戻す」で、ベタとビアをまとめて取り消せます。

## 自動配線
- 左パネルの「自動配線 → 全部」で、未配線(黄色の線)をまとめて配線します。先に部品を基板の上に並べてください。
  パッドを選んで「(ネット名) だけ」を押すと、そのネットだけ配線します。重要な線を手で引いてから残りを任せる使い方ができます。
- 2層・45°配線で、線幅とビア径は左パネルの設定を使います。ほかのネットとの間隔は DRC の最小間隔を守り、
  ルール違反になる配線は採用されません。通せなかった接続は黄色の線のまま残ります(部品を動かすか手動で)。
- 1回の実行は「元に戻す」で全部取り消せます。

## 基板の外形に曲線 (角丸・円)

左パネルの「基板外形」で、外形を曲線にできます。

- **角R**: 角の丸みの半径 (mm)。0 より大きくして「矩形に設定」を押すと、角丸の矩形になります。「基板外形(矩形)」ツールでドラッグして作る外形にも効きます。
- **円・長円に設定**: 幅と高さに収まる円 (幅=高さ) や長円の外形にします。
- **いまの外形の角を丸める**: 多角形も含め、いまの外形のすべての角を「角R」で丸めます。辺が短くて入らない角は、入る大きさまで自動で小さくなります。

曲線は細かい直線の連なりとして保存・出力されます (ガーバーの外形は直線の線分で表せるため、発注先に特別な対応は要りません)。角を丸めると、ケースに入れたときや手で持つときに角が当たりにくく、角の銅やシルクが欠ける心配も減ります。DRC の「基板の端との間隔」も曲線に沿って調べます。

## 3Dで見る

「3Dで見る…」を押すと、基板を立体で見られます。

- 出来上がりの色 (緑のレジスト、金色のパッド、白いシルク、穴) は、**書き出す製造ファイルから作った絵**を貼っています。発注先に届くものと同じ形で確認できます。
- 部品は、パッドの位置と大きさから、フットプリントに合わせた形と高さで表示します。チップ部品は両端に銀色の電極、ICは足つき、コネクタ(ピンヘッダ)は黒い樹脂と金色の長いピン、アキシャル抵抗やダイオード・電解コンデンサ・5mm LED は円柱の形です。高さはフットプリントからの目安で、実物の寸法ではありません。
- 左ドラッグで回し、右ドラッグ(または中ドラッグ)で動かし、ホイールで拡大縮小します。ダブルクリックで初期の向きに戻ります。「自動回転」でゆっくり回せます。
- 部品にカーソルを合わせると、黄色く縁取られて、部品番号・値・フットプリント・高さの目安が出ます。クリックすると、基板エディタでその部品が選ばれます。
- 上に、基板の大きさと、表側・裏側で最も高い部品が出ます (ケースに入る高さの確認に)。「上から」「斜め」「横から」「裏から」で向きを切り替えます。
- 「部品」「部品名」「ソルダーレジスト」「シルク」で、表示するものを選べます。基板を編集したあとは「更新」を押します。

## 配線の太さ (電流から)

左パネルの「配線の太さ (電流から)」を開くと、基板にあるネットが一覧で出ます。ネットごとに **流す電流 (A)** を入れると、必要な線幅を IPC-2221 の式 (銅箔 35µm・温度上昇 10℃・表面) で計算し、いま引いてある配線の最小の太さと比べて表示します。

- 赤 = 足りない。「推奨幅にする」で、そのネットの細い配線を必要な幅 (0.05mm 刻みで切り上げ) まで太くします (Ctrl+Z で戻せます)。「足りないネットをすべて推奨幅にする」もあります。
- 「線幅に」を押すと、これから引く配線の線幅がその値になります。
- 太くすると隣との間隔が減るので、そのあと **DRC を実行** して確かめます。
- 発注の準備のチェックにも出ます (電流を入れたネットで細い配線があると警告)。
- 電流が分からないときは、「学ぶ → 値の決め方」の「基板の配線の太さ」で、電流・温度上昇・銅箔の厚さから幅を計算できます。

電流の設定は基板ファイルに保存されます。

## DRC とシルクのチェック

DRC (設計ルールチェック) の指摘は、原因と直し方がわかる日本語で出ます (線が細い、銅どうしが近い、穴やアニュラリングが小さい、基板の端に近い、基板の外に出ている、ネットの短絡)。行をクリックするとその場所へ移動します。

「発注の準備」のチェックには、DRC のほかに **シルク (白い印刷) の注意** も出ます。パッドの上に重なったシルク線 (製造時に削られ、はんだ付けにも邪魔)、細すぎる線 (0.15mm 未満)、小さすぎる文字 (高さ 0.8mm 未満) です。

## 銅箔ゾーン (ベタ)
- 多角形を描くと、選んだネット(例: GND)の銅箔になります。ゾーンのネットのパッドとビアは、ゾーンの中で自動的につながります
  (ラッツネストも消えます)。別のネットの配線・パッド・ビアの周囲には、設定した隙間(既定 0.3mm)が空きます。
  基板の端と取付穴の周囲にも隙間が空きます。
- スルーホールのパッドは、サーマルリリーフ(4本のスポーク)でつながります。SMD パッドはベタに直接つながります。
- 製造ファイルでは、領域を描いたあとに「クリア極性」で隙間を切り抜く方式で出力します。画面にも同じ隙間が出ます
  (サーマルのスポークは画面には出ません)。
- 孤立した銅箔の島の除去は行いません。ゾーンが基板外形からはみ出しても、銅は外形で切り取られるので問題ありません(外形を縮めたときも同じ)。基板と全く重ならないゾーンだけ DRC が報告します。同じ層で別のネットのゾーンどうしが重なったときは、あとから作ったほうが優先され、先のゾーンは隙間をあけて引き下がります。ゾーンを選ぶと出る「最前面へ / 最背面へ」で優先を入れ替えられます。

## 部品の裏面実装
- 部品を選んで `B` キー(または左パネルの「裏面に移す」)で、反対の面に移せます。位置・向き・ネットはそのままです。
- 裏面に移した部品は、基板を縦軸で裏返したものとして、左右が反転します(ピン1の位置も反転)。パッドは裏面の銅箔とマスクに、
  シルクと部品番号は裏面のシルクに出ます。スルーホール部品は、両面の銅箔に出ます。
- 回路図から取り込み直しても、すでにある部品の面は保たれます。新しい部品は表面に置かれます。
- 表と裏の部品は、同じ場所に重ねても構いません(別の層なので、間隔の検査は互いに干渉しません)。
- 裏面の文字は左右反転して出力します。Gerber は表から見た向きで出し、製造所が裏面の層を反転して読みます。

## シルク文字
部品番号が自動で部品の上(部品と同じ面)に出力されます(1mm の線フォント。英大文字・数字・記号)。部品を動かすと一緒に動きます。

## 書き出されるファイル

### 注意
- BOM の「Comment」には回路図の値が入ります。電源など値が波形の式の部品は、書き出し後に書き換えてください。LCSC の部品番号欄は空です。
- CPL の回転角は、部品の向き(反時計回りに 90° 刻み)です。製造所によっては、フットプリントごとに基準の向きが違い、
  回転の補正が必要です。部品配置の確認画面で、向きを必ず確かめてください。
- 裏面の部品の回転角も、表から見た向きで出します。製造所ごとの基準(裏面の補正)に合わせた調整は、していません。
- 発注前に、書き出した zip を製造所のプレビューで一度確認してください。

## 多層基板 (4層・6層・8層)
「作業の設定」の「銅箔の層数」で 2 / 4 / 6 / 8 層を選びます。内層は「内層1」「内層2」…の名前です。作業層は、**画面の右上の「層」パネル**で切り替えます (L キーでも順に切り替わります)。パネルは白っぽい半透明で、最初はたたまれていて「層: 表面」のように作業層の名前だけが出ます。三角を押すと、層の一覧が開きます。各行のチェックで、その層の銅を表示 / 非表示にできます。
- 内層には**配線とベタ (ゾーン)** を置けます。部品とシルクは表面か裏面だけです (内層を選んでいるときに置くと表面になります)。
- スルーホールの部品とビアは、**全部の層につながります**。ブラインドビア・ベリードビアは未対応です。
- 自動配線は内層も使います。表と裏が塞がれていても、内層を通って抜けられます。
- 層数を減らすとき、消える内層に配線やベタがあると、断って理由を出します。先に消すか移してください。
- 書き出しは内層のファイルが増えます。発注前チェックに、層数と積層を発注先で指定する注意が出ます。
- 電源・GND を内層のベタにすると、表と裏の配線が減り、戻り電流の道が短くなります。

## 差動ペア
USB の D+ / D- のように、2本で1つの信号を運ぶ配線です。配線パネルの「差動ペア」で扱います。
1. 「名前から探す」(`USB_DP`/`USB_DM`、`TX_P`/`TX_N`、`D+`/`D-` などを自動で見つける)か、2つのネットを選んで「ペアに追加」。
2. 「間隔」(2本の縁どうしの目標) と「長さの差」(許容) を決める。
3. 「ペアで配線」: ＋側を引いたあと、－側をそのすぐ隣に引きます。「全部」の自動配線でも、ペアが先に引かれます。
4. 長さの差が大きいときは「長さを合わせる」: 短いほうにジグザグ (蛇行) を足します。
5. 手で引いた配線も、長さ・並走・間隔の表示と DRC / 発注前チェックの対象になります。

## 押しのけ配線・配線の移動
- **押しのけ配線** (「② 自動で配線」の「引き方」のチェック): 配線を引くとき、別のネットの配線が近すぎると、その配線を脇へ寄せます。引いている線のプレビューが**橙色**なら押しのけ、**赤**なら間隔が足りずルール違反になります。押しのけられる配線は、いまの位置が**細い橙の線**、動く先が**太い橙の線**で、カーソルを動かすたびに出ます (クリックするまで、実際の配線は動きません)。配線がとても多い基板で計算が重いときは、少し遅れて表示します。
- パッドやビアに付いた端は動かしません。両端が固定された配線は動かせないので、そのときは普通に引きます (ルール違反は DRC に出ます)。寄せる距離は最大 4mm です。寄せても違反が減らない、または接続が切れるときも、寄せません。
- **配線のドラッグ** (選択ツール): 配線を1本つかんで、平行に動かします。つながった配線は伸び縮みし、パッドやビアに付いた端には短い配線が足されます。邪魔な別ネットの配線は押しのけます。1回のドラッグが取り消し1回分です。
- **このネットの配線を全部消す** (配線を選ぶと出るボタン): ネットの配線とビアを消して、引き直せるようにします。パッドは残り、未配線の線が戻ります。

## 配線を整える
左パネル「③ 整える」の「配線を整える」は、市販の基板のような仕上がりにします。
- **整えた形の表示・出力**: 配線そのものは変えずに、下の設定で整えた形を表示し、ガーバーに書き出します (スイッチはなく、いつも整えます)。あとから配線を動かしても、整えた形が自動でついてきます。DRC と発注前チェックも整えた形で調べます。元の配線の形で見たいときは、下の3つ (角・段差・分かれ目) をすべて切ります。
- **角を丸める**(半径は既定 0.5 mm)、**太さの段差をなだらかに**(太さが変わる所と、パッドやビアに入る根元の涙型)、**分かれ目を丸める**(1つの点から2本が 8〜60° で出ている所の、間の細いくぼみの先を、凹んだ丸い形にする)。
- **整えた形を配線に確定する**: 角の丸みと段差を、配線そのものに書き込みます (分かれ目の丸みとパッドの根元の肉づけは、線では表せないので確定できません。残したいときは確定せず、そのままにします)。ルール違反が増える所と、接続が切れる所は変えません。元に戻すで取り消せます。
- **ネットごとの整え方**: 銅をクリックして開くネットの設定窓の、ネットクラスの「整え方」で、そのクラスのネットだけ、角・段差・分かれ目を「入れる/切る」にしたり、角の半径を変えたりできます。USB・高周波・インピーダンスを決めた線など、形が大事な線は、3つとも「切る」にします (確定も、パッドの根元をそろえるボタンも、そのネットは変えません)。古いファイルの「整えないネット」は、開くときにネットクラスの「3つとも切る」に変わります。

## パッドに垂直に出入りする
配線ツールには、パッドの周りの引き方をそろえる機能があります (「② 自動で配線」の「引き方」の「パッドに垂直に出入り」、既定でオン)。
- **垂直な出入り**: パッドから配線を出すとき、パッドへ入れるときに、パッドの辺に垂直な短い区間 (既定 0.5 mm) が付きます。そのあとは、いつもの 45° などで行き先へ向かうので、斜めに入る根元ができません。丸いパッド、「自由」の配線、パッドどうしが近すぎるときは、何もしません。
- **自動配線にも、いまある配線にも**: 自動配線は、探索の最初から、パッドの辺に垂直に出入りする経路を探します (パッドの前に空きがないときは、これまでどおりの経路です)。その直後に、念のため、新しい配線の根元をそろえ直します。すでに引いてある配線は、左パネル「③ 整える」の「パッドの根元」の「全部の配線をそろえる」(または、配線を選んで「選んだ」)で、根元だけを垂直にそろえます。配線の経路は、パッドの近くだけ少し変わります。同じ点から2本が出ている幅広パッドは、両端から並べて出します。ルール違反が増える所と、接続が切れる所は変えません。「整えないネット」は除きます。
- **パッドの両端に吸い付く**: 2本の配線が並べられる四角いパッドでは、パッドの両端にも吸い付きます (近づくと小さな緑の輪が出ます)。同じパッドの両端から2本を引けば、鋭角のくぼみができず、電流もパッドの幅いっぱいに分かれます。

## 自動経路 (パッドまで探す)
「② 自動で配線」の「引き方」の「自動経路 (パッドまで探す)」を入れると、配線ツールで、出発点からカーソルまでの経路を、障害物をよけて自動で探します。
- **行き先がパッド・ビア・配線の端のとき**: カーソルをそこに合わせると、水色の線で、よけて通る経路が出ます。クリックすると、その経路が配線されます。パッドには垂直に出入りします。
- **探せないとき・行き先が何もない所のとき**: いつもの曲げ方の線になります。「押しのけ配線」が入っていれば、邪魔になる別のネットの配線を脇へ寄せて通します (橙色)。ルール違反になるときは赤です。
- **切ったとき**: 押しのけは使わず、手で決めたとおりの配線になります。ルール違反やショートになるときは、プレビューが赤くなります。
- 探すのは、出発点とカーソルを囲む範囲だけで、時間がかかる場合は途中で諦めます。ビアを使う経路は探しません (ビアは V キーで)。

## 長さ合わせ (蛇行配線)
同時に届いてほしい線 (バス、クロックとデータ、差動ペアの2本など) の長さを、配線の一部に蛇行を入れてそろえます。配線ツールの設定枠の「高度な配線」の「長さ合わせ (蛇行)」から使います。
- そろえるネットにチェックを入れます (それぞれの配線の長さが出ています)。
- 「選んだネットを一番長いものに合わせる」で、いちばん長いネットに、ほかのネットの長さをそろえます。「目標 ○ mm」と「指定の長さに合わせる」では、指定した長さにそろえます。
- 蛇行は、短いネットの、まっすぐで長い配線に入ります。まわりの配線とぶつかるとき (ルール違反になるとき) は、反対側を試し、それでも入らなければ入れません。元に戻すで取り消せます。
- 角の形は、四角・面取り (45°)・丸から選べます。山の高さの上限も決められます。
