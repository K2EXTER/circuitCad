## 1. 学習指導要領(H30)と解説で、電気回路・電子回路・電子技術の単元はどういう順か

### Takeaway
「電気回路」は (1)電気回路の要素 → (2)直流回路 → (3)交流回路(記号法・三相交流) → (4)電気計測 → (5)各種の波形(非正弦波・過渡現象) の5項目。「電子回路」は (1)電子回路素子 → (2)増幅回路 → (3)各種の電子回路(電源・発振・パルス・変調復調) の3項目。「電子技術」は (1)概要 → (2)半導体と電子回路 → (3)通信システム → (4)音響・映像機器 → (5)電子計測 の5項目。3科目とも内容の取扱いで「演習を重視」「実習などを通して具体的に」が求められている。

### Inferences
- 学習指導要領の順は「素子と量 → 直流 → 交流(フェーザ・複素数 = 記号法) → 計測 → 非正弦波・過渡」。過渡現象は最後の単元で、教科書では2冊目(「電気回路2」や「下」)の後半にあることが多い。初学者向けのソフトの学習パスもこの順に合わせると、工業高校の生徒が授業と対応させやすい。
- 「電子回路」は増幅が中心で、デジタル(論理回路)はこの科目の指導項目に無い。論理回路は「電子技術」の教科書(ディジタル回路の章)や、別の科目(工業情報数理・ハードウェア技術など。今回は調べていない)で扱われる。
- 「電子技術」は電子回路を広く浅く1科目で扱い、通信・音響映像・センサに広げる科目。電子科以外(電気科・電子機械科など)で使われることが多いと思われるが、確かめた出典は無い。

### Gaps

- 「工業技術基礎」「実習」「製図」などの原則履修科目の指導項目は、今回は出典を取れていない。

## 2. 代表的な教科書の目次(章の順)

### Takeaway
令和8年度に東京都で調べられた「電気回路」の教科書は8冊(実教3・オーム2・コロナ3)。どれも学習指導要領の5項目の順に並び、違いは交流の数学(ベクトル・複素数)の説明のしかたと、実験(LED・RC 回路の波形観測・オシロスコープ)を入れているかどうか。「電子回路」(実教745)の目次は、素子 → 増幅の基礎(バイアス・小信号・設計) → いろいろな増幅(負帰還・差動/オペアンプ・電力・高周波) → 発振 → 変調・復調 → パルス → 電源 の順。

### Cited Findings
**「電気回路」の教科書の一覧(令和8年度用の調査対象)** — [東京都 R8 電気回路](https://www.kyoiku.metro.tokyo.lg.jp/documents/d/kyoiku/04-r8-research-and-survey-on-electric-circuit)

## 3. 高専モデルコアカリキュラム(電気・電子系)が求める回路の内容

### Takeaway
MCC(令和5年4月28日改訂)の電気・電子系分野では「V-C-1 電気回路」で、直流 → 回路網の定理 → 交流(瞬時値・実効値・フェーザ・複素数表示・インピーダンス・電力と力率) → 共振 → 結合回路 → 過渡現象(RL・RC・RLC、時定数) を到達目標にしている。「V-C-3 電子回路」はダイオード・BJT・FET の等価回路、増幅の基礎事項、バイアス回路、オペアンプが中心。実験(VI-C)では、直流・交流の実測、ダイオードとトランジスタの静特性、オペアンプの利得と周波数特性を「実測やシミュレーターにより」求めることが明記されている。

### Cited Findings
- MCC は「卒業までにすべての学生が達成すべき到達目標等を示す」もの。高専教育の特長は「15 歳から始まる 5 年一貫の体験重視型教育」で、講義・演習で「頭を動かす」体験と、実験・実習で「手を動かす」体験を組み合わせる — [国立高専機構 モデルコアカリキュラム(令和5年4月)](https://www.kosen-k.go.jp/wp/wp-content/uploads/2023/12/2c383e29-7e20-4b20-af19-ca3737450665.pdf)
- V-C-1 電気回路の目標: 「直流回路と交流回路の取扱い方や電気回路の過渡現象の解析方法を習得」する。(1) R・L・C の電圧と電流の関係、(2) キルヒホッフの法則や重ねの理などの定理、(3) 「瞬時値、フェーザ、複素数表示を理解し、これらを正弦波交流回路の計算に用いることができる」、(4) 共振回路や結合回路、(5) 過渡応答を計算し特徴を説明する。一般的な科目名は「電気回路、交流回路、過渡現象論」 — 同上
- V-C-1 の学習内容と目安の項目: 電気回路の基礎(電荷・電圧・電流・電力・電力量・オームの法則・合成抵抗・分圧則・分流則)/ 回路網(キルヒホッフ・重ね合わせの理・テブナンの定理・ブリッジの平衡条件)/ 交流回路の基礎(正弦波・瞬時値・周波数・位相・平均値・実効値・フェーザ・複素数表示・インピーダンス・アドミタンス・皮相・有効・無効電力・力率)/ 共振回路(直列・並列)/ 結合回路(相互誘導回路・理想変圧器)/ 過渡現象(RL 直列・RC 直列・RLC 直列・直流応答・時定数) — 同上

- VI-C 電気・電子系の実験・実習(一般的な科目名は「電気電子工学実験」): 計測技術(電気諸量や抵抗・インピーダンスの測定法、オシロスコープの使い方、安全教育)/ 電気回路(「キルヒホッフ、重ね合わせ理、分圧則、分流則などの実測」、「RLC のインピーダンス、インピーダンスの大きさや位相、周波数特性などの実測」)/ 電子回路(「半導体や増幅回路の電気的特性を実測やシミュレーターにより求め」る。ダイオード・トランジスタの静特性、オペアンプの増幅器の利得や周波数特性。論理回路の動作を「実測やシミュレーターにより」。マイコンや PC を使う制御実験) — 同上

### Inferences
- MCC は「シミュレーター」を実測と並べて書いているので、高専の実験では回路シミュレータが正式な手段になっている。シミュレーションと実測を同じ画面で比べる機能は、高専の実験レポートの形(実測 → 考察)に合う。

### Gaps

## 4. 技能検定「電子機器組立て」の 3級・2級で試されること

### Takeaway
3級(初級)の実技は「作業の段取り・電子機器の組立て・電子回路の点検」の3つ。過去の課題の例は、プリント板(表面実装と挿入実装)と金属のシャーシに部品を付け、配線し、テスタで調整して動作を確かめるもので、作業時間は1時間30分。2級(中級)はこれに「電子機器の修理」が加わり、1級は「工数見積り」も加わる。学科には電気回路(直流・交流・ベクトル・過渡現象 CR)、電子回路、回路図と配線パターン図の読図、はんだ付けなどの組立て法、計測、品質管理、安全衛生がある。

## 5. 実習は理論とどう組み合わされているか・どこでつまずくと言われているか

### Takeaway
学習指導要領は3科目とも「実践的・体験的な学習活動」を目標に掲げ、電子回路では「実習などを通して具体的に理解」とまで書いている。教科書は本文の中に実験(オームの法則・LED の誘導起電力・RC 直列回路の位相差の波形観測・過渡現象の充放電・オシロスコープの実習)を入れて、理論と同じ単元で手を動かす形にしている。高専の MCC は実験に「実測やシミュレーター」と書いている。つまずきについては、交流の数学(ベクトル・複素数)を図で補う工夫を各出版社がしていることから山場と読めるが、つまずきを調べた実践報告の一次資料は今回見つからなかった。

### Cited Findings
- 精選電気回路(実教)は、RC 直列回路の波形観測で位相差を学び、「理論だけではなく視覚的に理解が深まり、交流波形を扱う力が身に付く」。過渡現象の実験で「充電特性や放電特性を扱う力」 — [東京都 R8 電気回路](https://www.kyoiku.metro.tokyo.lg.jp/documents/d/kyoiku/04-r8-research-and-survey-on-electric-circuit)

- オーム社とコロナ社の本は、交流でのベクトル(コロナ『わかりやすい電気回路』は複素数も)の「数学的な要素を図や解説を用いて理解を深める」工夫をしている — 同上

### Inferences
- 工業高校では、理論の科目(電気回路・電子回路)の中に小さな実験を入れつつ、本格的なはんだ付け・測定は「実習」の科目で行う二本立てと読める。そのため、理論の授業で使う「画面上で測って波形を見る」道具の需要がありそう(授業中に実機を出せない単元を補う)。
